忘记了银河麒麟的登录密码，首先可以试试系统自带的“安全问题”找回功能。如果你的账户没有设置过这个，就需要用系统维护的方法来重置了。另外，因为你的账户已经被“永久锁定”，在重置密码前，可能也需要先解除锁定。

### 🔑 首先试试：安全问题重置
如果之前设置过安全问题，在登录界面点击“忘记密码”就可以通过回答问题来重置。

### 🛠️ 备选方案：进入救援模式重置
如果上面的方法不行，或者你想重置后直接解除锁定，可以按下面的步骤操作。这个方法不需要密码，但需要你在电脑前操作。

**操作步骤如下**：
1. **进入GRUB菜单**：重启电脑，在出现启动界面（银河麒麟Logo之前）时，快速按下键盘上的 **`E`** 键或 **`Shift`** 键，进入GRUB引导菜单。
2. **选择恢复模式**：在菜单中，用方向键选择 **`Advanced options for Kylin V10 SP1`**（高级选项），按回车。然后选择带有 **`(recovery mode)`** 字样的内核选项，再按回车。
3. **进入命令行**：系统会加载恢复模式。当屏幕提示 **`Press Enter for maintenance`** 时，按一下回车键，就会进入一个可以输入命令的界面。
4. **重置密码与解锁**：在命令行中，依次输入下面的命令（每输完一行按一次回车）。**请将命令中的 `jhb123` 替换成你实际的用户名**：
   ```bash
   # 1. 重置密码（输入后按提示输入两次新密码，输入时屏幕不会显示）
   passwd jhb123

   # 2. 解除账户锁定（如果解锁命令报错，可以跳过这步，直接看第3步）
   pam_tally2 --user=jhb123 --reset
   ```
   如果 `pam_tally2` 命令提示找不到，可以尝试用 `faillock --reset --user=jhb123` 来替代，或者直接进入下一步。

5. **重启电脑**：输入 **`reboot`** 命令重启电脑，然后就可以用新设置的密码登录了。

### 💎 补充建议
在重置密码并成功登录后，建议你到系统设置中，**开启“安全问题”功能**。这样以后再忘记密码，就可以自己通过回答问题来重置，不用这么麻烦了。

如果在操作过程中卡在某个步骤（比如进不去GRUB菜单，或者命令报错），可以告诉我具体的情况，我再帮你看看。
