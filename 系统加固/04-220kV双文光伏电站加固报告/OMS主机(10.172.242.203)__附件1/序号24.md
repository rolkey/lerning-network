# 账户锁定策略（A4）

## 问题

- 运行"gpedit.msc"计算机配置->Windows设置->安全设置->帐户策略->账户锁定策略应为：
  - 复位帐户锁定计数器 -> 3分钟
  - 帐户锁定时间 -> 5分钟
  - 帐户锁定阀值 -> 5次无效登录

---

A4 是 A3 的配套防线：**密码错几次就锁账号、锁多久**。密码策略管"密码本身强不强"，锁定策略管"别人能不能无限试你的密码"。

### 🔍 风险原理

账户锁定策略专门对付在线口令猜测。没有锁定时，攻击者可以对一个账号无限制地尝试密码——哪怕密码强度一般，海量尝试下迟早被试出来。启用锁定后，连续失败 5 次账号就锁死 5 分钟，暴力破解的节奏被压到"5 次/5 分钟"，对 8 位复杂度密码来说，这个速率下试遍整个密码空间在数学上不可行。

三个参数是配合关系：

- **帐户锁定阀值 5 次**：连续 5 次无效登录触发锁定。这是触发条件。
- **帐户锁定时间 5 分钟**：锁多久。到期自动解锁，不需要管理员手工干预。
- **复位帐户锁定计数器 3 分钟**：失败计数在 3 分钟后清零。这个值必须小于锁定时间——如果计数器复位时间比锁定时间长，会出现账号解锁后失败计数还没清零、再错一次立刻又锁上的别扭状态。

### 配置（加固方法）

运行 `gpedit.msc`，进入：

```
计算机配置 -> Windows 设置 -> 安全设置 -> 帐户策略 -> 账户锁定策略
```

1. 双击"帐户锁定阀值"，设为 **5 次无效登录**。
   设置阀值时 Windows 会弹出提示框，自动建议把锁定时间和复位计数器设为默认值（30 分钟），确认即可。
2. 双击"帐户锁定时间"，改为 **5 分钟**。
3. 双击"复位帐户锁定计数器"，改为 **3 分钟**。

最终三项应显示：锁定阀值 5 次无效登录 / 锁定时间 5 分钟 / 复位计数器 3 分钟。

本地安全策略即时保存，可用 `gpupdate /force` 刷新，重启后必然生效。

### 特殊情况处理

- **内置 Administrator 账号不适用锁定**：Windows 默认对本机内置管理员账号（RID 500，无论是否重命名）不做账户锁定，防止管理员自己被锁在门外。所以锁定策略主要作用于普通账号，验证时不要拿内置管理员账号测试。
- **自动化脚本触发锁定**：站内如果有巡检脚本、采集程序用普通账号登录，脚本里密码配错会连错 5 次把账号锁死，造成"业务无故中断"。排查登录异常时先看事件查看器（`eventvwr.msc`）安全日志里的 4625 事件。
- **锁定时间与复位计数器的大小关系**：保持 3 分钟 < 5 分钟。若有人把复位计数器改得比锁定时间大，账号解锁后计数器还没复位，属于配置错误。

### 📌 加固后的验证

- 策略界面三项值与要求一致：5 次无效登录 / 5 分钟 / 3 分钟。
- 命令行执行 `net accounts`，输出中可见：锁定阀值 5、锁定持续时间 5 分钟、锁定观察窗口 3 分钟。
- 实测：用一个普通账号故意输错密码连续 5 次，第 6 次输入正确密码也提示账号已被锁定；等待 5 分钟后恢复正常登录。
