# 处置 CVE-2019-0708 远程桌面漏洞（BlueKeep）

## 问题

> CVE-2019-0708 windows远程桌面漏洞 KB4499175

---

### 🔍 漏洞原理与风险

CVE-2019-0708，也就是 BlueKeep，是 Windows 远程桌面服务（RDP）的预认证远程代码执行漏洞。问题出在 RDP 的 termdd.sys 内核驱动上：攻击者**不需要任何账号密码**，直接向目标 3389 端口发送特制的 RDP 连接请求，就能在内核态执行任意代码。

它最危险的地方是**可蠕虫化**——利用成功后可以在内网自主扫描、自主传播，一台中招、整段遭殃。2019 年 5 月披露时，微软罕见地连早已停止支持的 Windows XP、Windows Server 2003 都补发了修复补丁，严重性可见一斑。

Windows 7 / Server 2008 R2 是重灾区；Windows 8 及以后的系统默认启用网络级身份验证（NLA），攻击者需要先通过认证，风险降低，但并非免疫。本机是 Windows 10，仍按调度指令清单要求打补丁，不留尾巴。

### 处置方法

1. 安装 KB4499175 补丁。
   - 联网环境："设置 → 更新和安全 → Windows 更新 → 检查更新"。
   - 内网环境：离线安装包，命令行执行：

     ```text
     wusa.exe KB4499175-x64.msu /quiet /norestart
     ```

2. 重启主机，使补丁完整生效。
3. 配合本表序号70的端口策略：3389 已被禁用，攻击面进一步收缩，即使补丁尚未装完，外部也无法直连 RDP。

### 特殊情况处理

- 补丁必须与系统版本匹配（x64 的 Win10 对应 x64 补丁包）。
- 若短期无法重启，先做临时缓解：打开"系统属性 → 远程"，勾选"仅允许运行使用网络级别身份验证的远程桌面的计算机连接"；或直接按序号70策略禁用 3389。
- 安装补丁过程中远程桌面连接会中断，本机本地操作不受影响。

### 📌 处置后的验证

- "控制面板 → 程序和功能 → 查看已安装的更新"中出现 KB4499175。
- 命令行核对：

  ```text
  wmic qfe list | findstr KB4499175
  ```

  或 PowerShell：

  ```text
  Get-HotFix -Id KB4499175
  ```

  返回对应补丁条目。
- 运行 `netstat -an` 确认 3389 无对外监听（按序号70策略已禁用）。
- 重启后系统正常，无蓝屏或服务故障。
