# 网站安全狗（Apache版）V4.0.23957 webshell 绕过漏洞

## 问题

- 漏洞编号：指令清单调度20190622-001
- 漏洞名称：网站安全狗（Apache版）V4.0.23957 webshell绕过漏洞
- 作业结点："网站安全狗（Apache版）V4.0.23957存在webshell绕过漏洞【对象】Windows服务器下网站安全狗Apache版"
- 加固方法："在Windows操作系统应用程序中查看是否安装Apache版的安全狗，通过控制面板——卸载程序，找到安全狗的程序，查看当前安装的安全狗版本"

---

### 🔍 漏洞原理与风险

网站安全狗是装在 Windows 服务器上的 WAF 类防护软件，靠特征库拦截 webshell 的上传和访问。问题出在 V4.0.23957 这个版本：存在 webshell 绕过漏洞，攻击者可以用特定构造的请求绕过安全狗的检测规则，把 webshell 传到服务器上。

一旦 webshell 落地，后面就是执行命令、提权、内网横移一条龙，安全狗等于形同虚设。本次排查的对象是 Windows 服务器下安装的 Apache 版安全狗。

### 处置方法

源表单这一步是**排查确认**，操作在 Windows 界面上完成：

1. 打开控制面板 → 程序和功能（卸载程序）。
2. 在程序列表里查找安全狗的程序条目，确认是否安装了 Apache 版安全狗。
3. 点击该条目查看版本号，核对是否为受影响的 V4.0.23957。
4. 如果确认是受影响版本，需要到安全狗官网下载并升级到修复后的新版本；如果服务器上没有安装 Apache 版安全狗，则不受该漏洞影响，可跳过处置。

### 特殊情况处理

- 升级安全狗一般不需要重启服务器，但会短暂影响 Apache 服务或防护进程，安排在业务低峰期操作。
- 升级前先备份安全狗的配置文件（规则、白名单），升级后如果有自定义规则丢失可以恢复。
- 如果服务器上还装了其它版本（如 IIS 版）的安全狗，需要分别核对版本，不能只看一个。

### 📌 处置后的验证

- 卸载程序列表中确认安全狗版本已高于 V4.0.23957。
- 打开安全狗主界面，确认防护服务运行正常、规则库已更新。
- 可以做一个简单验证：模拟上传一个测试 webshell 文件，安全狗应能拦截。
