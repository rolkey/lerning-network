# IE 浏览器远程代码执行漏洞

## 问题

> 信息通报19-37期：IE 远程代码执行漏洞
>
> 影响版本：Windows 10、Windows 8.1、Windows 7、Windows Server 2012/R2、Windows Server 2008、Windows Server 2016、Windows Server 2019 的 IE11 版本，Windows Server 2012 的 IE10 版本以及 Windows Server 2008 的 IE9 版本。
>
> 加固方法：在 IE 浏览器的"工具" - "关于 Internet Explore(A)"，弹出相应窗口，红圈标注的即为 IE 浏览器版本。卸载或者更新到最新版本。

---

### 🔍 漏洞原理与风险

IE 在解析特制的网页内容（脚本、CSS、DOM 对象）时存在内存破坏类缺陷，攻击者只要诱导用户打开一个恶意网页或恶意文档，就能让 IE 崩溃并借机执行任意代码。这种漏洞的利用门槛低：钓鱼邮件里放一个链接，点开就中招，执行权限就是当前登录用户的权限。

值得注意的一点：IE 早已停止功能开发，只保留安全补丁。Windows 10 内置的 IE11 补丁随月度累积更新一起发布，而通报里点名的 IE9、IE10 出得更早、防护更少。只要机器上还留着没打过补丁的 IE，就是一个随时可能被公开利用的入口。运维人员往往不主动用它，但攻击者会。

### 处置方法

**第一步：确认本机 IE 版本**

1. 打开 IE 浏览器，点击右上角的齿轮图标（即"工具"菜单），选择"关于 Internet Explorer(A)"。
2. 弹出的窗口里会显示版本号，例如"Internet Explorer 11, 版本 11.0.9600.xxxxx"，这就是通报里说的红圈标注位置。
3. 拿版本号对照上面的影响范围。只要属于列出的 IE9/IE10/IE11 且补丁版本偏旧，就按下面两种方式之一处理。

**第二步：卸载或更新（二选一）**

- 方式一：卸载 IE
  1. 打开控制面板 → "程序和功能" → 左侧"启用或关闭 Windows 功能"。
  2. 找到"Internet Explorer 11"，取消勾选，点确定，按提示重启。
- 方式二：更新到最新
  1. 打开"设置" → "更新和安全" → "Windows 更新"，点"检查更新"，安装 IE 相关的累积安全更新。
  2. 内网无法联网的机器，到微软更新目录（catalog.update.microsoft.com）下载对应系统的 IE 累积更新补丁，拷入机器双击安装。

Windows 10 上 IE11 没有独立的"升级包"，补丁全部通过 Windows 更新下发，所以方式二本质上就是把系统补丁打齐。

### 特殊情况处理

- 不少电力监控类的老平台页面只认 IE，甚至依赖 IE 的 ActiveX 控件（比如某些 SCADA 画面插件）。卸载前先跟业务确认，别一卸掉业务页面就打不开了。
- 如果业务必须保留 IE，就采用"更新"方式并保持补丁及时打，同时限制 IE 只用于访问业务内网页面，不拿它上外网。
- Windows 10 的默认浏览器是 Edge，IE 只剩兼容用途；卸载 IE 不影响 Edge 和日常上网。

### 📌 处置后的验证

- 走卸载路线的：重新打开"启用或关闭 Windows 功能"，确认"Internet Explorer 11"已不勾选；开始菜单里搜 IE 应该也找不到了。
- 走更新路线的：再次打开"工具 → 关于 Internet Explorer(A)"，确认版本号对应的是打过最新累积补丁的版本；再到"设置 → 更新和安全 → 查看更新历史记录"里确认 IE 相关补丁安装成功。
- 确认后重启一次，保证补丁和功能变更完全生效。
