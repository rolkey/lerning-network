# Firefox 远程代码执行漏洞

## 问题

> 信息通报19-39期：Firefox 远程代码执行漏洞（低于 67.0.3）
>
> 漏洞名称：Firefox 远程代码执行漏洞
> 对使用了 Firefox 浏览器的服务器采用以下策略：
> 1. 卸载所有低于 Firefox 67.0.3 和 Firefox ESR 60.7.1 的所有平台的版本，或者升级到最新的 67.0.4。

---

### 🔍 漏洞原理与风险

Firefox 66/67 系列存在内存破坏类漏洞，攻击者构造一个恶意网页，用户只要访问，浏览器解析页面时就会被触发漏洞，进而在本机执行攻击者指定的代码。ESR（长期支持版）是给企业用的稳定分支，同样受影响的判定标准是 60.7.1。

服务器或工作站上装着一个老版本 Firefox，就相当于系统里留了一条公开已知的入口：内网有人误点了恶意链接，或者恶意页面被放在内网门户里，都可能直接中招。这个漏洞的信息公开后，利用代码很快会扩散，处置窗口其实很窄。

### 处置方法

**第一步：确认版本**

打开 Firefox → 点击右上角三条横线的菜单 → "帮助" → "关于 Firefox"。弹出的窗口会直接显示当前版本号，是普通版还是 ESR 版也能看出来。

**第二步：按版本采取处置（卸载或升级，二选一）**

- 处置标准：版本低于 Firefox 67.0.3、或低于 Firefox ESR 60.7.1 的，一律处理。
- 方式一：卸载
  1. 打开控制面板 → "程序和功能"。
  2. 在列表中找到"Mozilla Firefox"，选中后点"卸载"，按提示完成。
- 方式二：升级
  1. 在"关于 Firefox"窗口里点"检查更新"，让它升到 67.0.4 及以上。
  2. 内网机器连不上更新服务器的，到 Mozilla 官网下载 67.0.4 或更高的完整安装包，拷到机器上覆盖安装。

### 特殊情况处理

- 卸载前先确认没有业务依赖 Firefox：部分老系统的网页只兼容 Firefox 内核，卸载了页面可能显示异常。有依赖就选升级路线。
- 服务器上如果只是历史遗留装的 Firefox、根本没人用，直接卸载最干净。
- 升级后旧的书签、配置一般会保留；覆盖安装前关闭正在运行的 Firefox 进程。

### 📌 处置后的验证

- 走升级路线的：再次打开"帮助 → 关于 Firefox"，确认版本号为 67.0.4 或更高。
- 走卸载路线的：打开控制面板"程序和功能"，确认列表里已没有"Mozilla Firefox"；开始菜单搜索 Firefox 也找不到。
- 验证完成后重启一次机器，确认系统状态正常。
