# 限制系统无用的默认帐号登录

## 问题

- "限制系统无用的默认帐号登录, 防止某些恶意用户利用系统默认帐号用进行破坏。"

---

操作系统装好就自带一批服务帐号：`daemon`、`bin`、`sys`、`adm`、`uucp`、`lp`、`nobody` 等等。它们的本意是给各子系统跑服务用，不需要人登录。但如果它们带着可用 shell、甚至空口令，就成了现成的后门——恶意用户可以用这些"没人管"的账号登录进来搞破坏。

### 🔍 风险原理

- 默认服务帐号通常不设口令，也不该能交互登录。如果 `/etc/passwd` 里它们还挂着 `/bin/bash`、`/bin/sh` 之类的 shell，配合空口令，任何人都能无口令登录；
- 这些账号常年不审计、不用改密码，攻击者用它登录不会惊动管理员，适合做长期驻留；
- 部分默认帐号（如 `nobody`）还被网络服务引用，若服务被远程利用，权限直接落在"合法"系统账号上，排查困难。

处理原则：能删的删，不能删的锁死登录能力。锁定比删除更常用，因为有些账号虽然不登录，但仍被服务进程引用，删了反而可能破坏业务。

### 配置/加固方法

**1、删除用户（确认完全无用的账号）**

```bash
# 删除用户
userdel username
```

注意 `userdel` 默认不删除家目录和邮件目录，确认要一并清理时加 `-r`。删除前先确认没有进程以该用户运行：`ps -u username`。

**2、锁定用户（源文给出的三种方式）**

```bash
# 1) 修改 /etc/shadow，在用户名后的口令字段加 NP，表示该账号无有效口令、禁止登录
vi /etc/shadow

# 2) 将 /etc/passwd 中的 shell 域改成 /bin/noshell 或 /bin/nologin
usermod -s /bin/nologin username
# 或直接编辑
vi /etc/passwd

# 3) 用 passwd 锁定
passwd -l username
```

三种方式的区别源文写得很清楚：`passwd -l` 锁定后，用 `passwd -d` 解锁会清掉原口令，之后登录必须重设新密码；而直接改 `/etc/shadow` 加 `NP` 能保留原口令信息，恢复时原样改回即可。

**3、源文要求锁定的账号清单**

```
daemon bin sys adm uucp lp snapp nobody invscout nuucp lpd imnadm ipsec ldap
```

**凝思 Linx 6.0 对应说明**：`NP` 是 HP-UX 一系 shadow 的写法，Linux 上锁定账号的口令字段是 `!` 或 `*`（`passwd -l` 就是加 `!`），效果相同。`/bin/noshell` 在凝思 Linx 6.0 上一般不存在，统一用 `/sbin/nologin`。凝思 Linx 6.0 自带的默认服务帐号大致对应清单：

```
bin daemon adm lp sync shutdown halt mail operator games ftp nobody ...
```

逐个锁定：

```bash
for u in bin daemon adm lp sync shutdown halt mail operator games ftp nobody; do
    usermod -s /sbin/nologin "$u" 2>/dev/null
    passwd -l "$u" 2>/dev/null
done
```

### 特殊情况处理

- 正在被服务使用的账号（如 NFS 的 `nobody`、`rpc`）不要删除，锁 shell 即可；锁定前先确认相关服务运行正常。
- 源文清单里 `invscout`、`nuucp`、`imnadm` 是 HP-UX 特有计划/网络管理账号，凝思 Linx 6.0 上不存在，直接跳过，不要照抄创建。
- 个别应用厂商要求用某个系统账号跑服务并交互登录的，以厂商要求为准，但要在整改记录里注明原因，不要默默放开。

### 📌 加固后的验证

```bash
# 1、检查指定账号的 shell，应当为 /sbin/nologin
awk -F: '/^(daemon|bin|sys|adm|uucp|lp|nobody)/ {print $1": "$NF}' /etc/passwd

# 2、检查锁定状态，期望输出包含 "LK"（locked）
passwd -S daemon; passwd -S bin; passwd -S adm

# 3、确认这些账号的口令字段非空（已被锁定标记占位）
awk -F: '/^(daemon|bin|sys|adm|uucp|lp|nobody)/ {print $1": ["$2"]"}' /etc/shadow
```

期望结果：清单内账号的 shell 全部为 `/sbin/nologin`（或 `/bin/noshell`），`passwd -S` 显示 `LK`，shadow 口令字段为 `!`/`*`（或 `NP`）。试着 `su - daemon -s /bin/bash` 应被拒绝。
