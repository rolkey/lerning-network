# PMU2 加固学习资料索引

本目录是 **220kV 双文光伏电站 PMU2（198.120.1.253，同步相量测量装置主机，凝思 Linx 6.0.80）** 的加固学习资料，由《PMU2(198.120.1.253)_附件1：主站系统并网网络安全管控表单V2-6(正式).xlsx》中的作业项整理而成。

- 文件名 `序号N.md` 中的 **N 对应 Excel 表中的行号**（例如「序号17.md」对应表单第 17 行，作业编号 B3）。
- 每篇结构：`问题（原表要求）` → 风险原理 → 配置/加固方法 → 特殊情况处理 → 加固后的验证。
- 本文档为 **Linux（凝思 Linx 6.0.80，RHEL 6 系）安全加固**，服务管理用 SysV init（`service` / `chkconfig`），防火墙用 `iptables`，时间同步用 `ntpd`，日志用 `rsyslog`，账户锁定用 `pam_tally2`——与 CentOS 7（systemd / firewalld / chrony / pam_faillock）不同，操作命令按 RHEL 6 系口径给出。
- 原表路径：`项目资料/04-220kV双文光伏电站加固报告/PMU2(198.120.1.253)_附件1：主站系统并网网络安全管控表单V2-6(正式).xlsx`
- 参照样例：[序号27.md](序号27.md)
