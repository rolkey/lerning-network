# 记录管理员操作日志

## 问题

- "已配置记录防火墙管理员操作日志。"

---

"谁在什么时间、登录了防火墙、改了哪条策略、删了哪个账号"——这些操作记录是安全审计、事故溯源、责任认定的核心证据。如果防火墙不记录管理员操作日志，一旦发生误操作或恶意篡改，事后完全无法还原"发生了什么"。本作业项要求开启并配置管理员操作日志，确保每一次登录、每一条配置变更都被完整记录。

### 🔍 风险原理

- **事故无法溯源**：策略被错误修改导致业务中断、或被恶意放行导致渗透时，没有操作日志就无法确定责任人、时间和具体动作，应急处置和整改都无从下手。
- **内部威胁难发现**：拥有管理权限的内部人员若进行越权或违规操作，操作日志是唯一能发现并追责的依据。无日志等于给内部违规"开绿灯"。
- **审计合规缺失**：电力监控系统安全防护和等保测评都明确要求设备具备并开启操作日志，缺日志会被判定为不符合项。
- **证据链断裂**：安全事件调查需要完整的操作时间线，日志缺失会让攻击者的关键动作（如篡改策略、关闭日志）无从还原，导致无法定性和追责。

操作日志是防火墙"可审计"的根基，必须开启、必须记录到位、必须防止被删除篡改。

### 配置/加固方法

**1. 开启管理员操作日志**

```text
操作路径（通用）：
系统管理 → 日志管理 / 审计日志 → 操作日志
  开启"记录管理员操作"；
  记录范围（建议全选）：
    [√] 登录/登出（成功与失败）
    [√] 配置变更（策略增删改、账号增删改、系统参数修改）
    [√] 权限变更、备份/恢复、重启等关键操作
```

**2. 配置日志记录的关键字段**

```text
确保每条操作日志至少包含：
  时间戳（含精确到秒）、操作人账号、来源 IP、
  操作类型（登录/修改/删除/重启）、操作对象、操作结果（成功/失败）、
  修改前后的关键值（策略类建议记录 diff）。
```

**3. 日志防篡改与保护**

```text
操作日志应：
  仅审计员角色可查看，普通操作员不可删改；
  与远程日志服务器联动（见"远程日志功能"作业项），
  日志实时/准实时外发，防止本机日志被清理。
```

**4. 日志级别与容量规划**

```text
按需设置日志级别（如记录到"配置变更"级别即可，避免刷屏）；
估算日志量与本地存储，配置轮转策略，防止日志写满后覆盖早期记录。
```

### 特殊情况处理

- 操作日志会占用设备本地存储，需配合日志轮转和远程日志，避免本地日志写满后覆盖早期记录。
- 登录失败也应记录（暴力破解线索），但要防止攻击者通过海量失败登录"刷爆"日志，可配合登录失败锁定策略。
- 设备重启、时钟调整等系统事件要一并记录，因为攻击者常通过改时间、重启来干扰审计。
- 审计员账号与操作员账号分离，确保操作员无法删除自己留下的日志。

### 📌 加固后的验证

```text
# 验证要点
1. 用某账号登录并修改一条策略（或新建测试账号），然后在日志中能查到完整操作记录；
2. 故意输入错误口令，日志中能查到登录失败记录；
3. 用操作员账号尝试删除日志，应被拒绝（无权限）；
4. 日志时间戳与 NTP 同步后准确，字段完整（含账号、IP、操作对象、结果）。
```

期望结果：管理员登录、配置变更等操作均被完整记录；日志含时间、账号、来源 IP、操作内容与结果；操作员无法删除日志。
