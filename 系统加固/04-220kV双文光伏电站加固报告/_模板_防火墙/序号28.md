# 开启防源地址欺骗功能

## 问题

- "防火墙各逻辑接口配置开启防源地址欺骗功能。"

---

源地址欺骗（IP Spoofing）是攻击者伪造数据包源 IP 来冒充可信主机、绕过访问控制、发起反射放大攻击的常用手法。防火墙如果不对源地址做合法性校验，就可能在"看似来自内网可信网段"的伪造流量面前被欺骗。本作业项要求在每个逻辑接口上开启防源地址欺骗（反欺骗 / RPF）功能，让接口只接收源地址合法、方向正确的流量。

### 🔍 风险原理

- **绕过访问控制**：攻击者伪造一个"属于内网可信网段"的源 IP 从外部发起访问，防火墙若不做源地址校验，可能误认为这是内部主机，从而放行本应被拒绝的流量。
- **反射放大攻击**：伪造受害者 IP 作为源地址发送请求，让响应流量打向受害者，实现 DDoS 放大。开启反欺骗可在入口丢弃这些伪造源地址的包。
- **溯源困难**：一旦攻击者使用伪造源地址，事后溯源查到的 IP 是假的，无法定位真实攻击者，安全事件处置陷入被动。
- **隐藏真实来源**：木马、僵尸网络常伪造源地址回连，规避检测和封堵。

防源地址欺骗通过"源地址必须与本接口网段匹配"的校验，从源头掐断伪造流量。

### 配置/加固方法

**1. 各逻辑接口开启防源地址欺骗**

```text
操作路径（通用）：
网络配置 → 接口管理 → 逐接口配置：
  每个逻辑接口（含安全区接口、VLAN 子接口）勾选：
    [√] 启用防源地址欺骗（反欺骗 / Anti-Spoofing / RPF 校验）
  校验模式（按需）：
    严格模式：源地址必须与本接口路由方向一致（推荐用于边界）
    松散模式：源地址路由存在即可（用于多路径/非对称场景）
```

```text
# 逻辑示意（通用，非厂商私有命令）
interface <接口名>
  anti-spoofing enable        # 开启该接口防源地址欺骗
  ip verify source            # 启用源地址反向路径校验
```

**2. 覆盖所有逻辑接口**

```text
注意"各逻辑接口"是重点：不只物理口，还包括每个安全区接口、
VLAN 子接口、管理接口。任一接口遗漏，伪造流量就能从该口钻入。
```

**3. 与策略联动核查**

```text
开启后检查是否有合法非对称路由业务受影响（如下联双链路），
对确需非对称转发的接口可改用松散模式并做记录。
```

### 特殊情况处理

- 严格模式在非对称路由（去回路径不同）场景下会误杀合法流量，需结合网络拓扑选择严格/松散模式，不能一刀切。
- 开启前先梳理各接口的合法源网段，确保反欺骗的"源地址范围"配置正确，否则正常业务流量会被丢弃。
- 管理接口也应开启反欺骗，防止伪造源地址访问管理通道绕过源地址限制。
- 多机热备、VRRP 等场景下虚拟 IP 的源地址校验需单独确认，避免主备切换后误判。

### 📌 加固后的验证

```text
# 验证要点
1. 查看各逻辑接口配置，确认防源地址欺骗均已开启；
2. 从外部用伪造内网源 IP 构造探测包（如伪造 1.1.1.5 作为源），
   应被防火墙在入口丢弃、无转发；
3. 正常业务流量不受影响（抽查关键业务通道连通性）；
4. 查看接口统计，确认有伪造源地址丢弃计数增长。
```

期望结果：防火墙所有逻辑接口均已开启防源地址欺骗；伪造源地址流量被入口丢弃，正常业务不受影响。
