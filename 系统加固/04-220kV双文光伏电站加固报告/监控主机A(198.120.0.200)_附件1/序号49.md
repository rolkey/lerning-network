# 网站安全狗（Apache版）V4.0.23957 webshell 绕过漏洞

## 问题

> 漏洞编号：调度20190622-001 —— 网站安全狗（Apache版）V4.0.23957 webshell绕过漏洞
>
> 加固方法：网站安全狗（Apache版）V4.0.23957存在webshell绕过漏洞。对象：Windows服务器下网站安全狗Apache版

---

### 🔍 漏洞原理与风险

网站安全狗是网站防护类软件（WAF），本职工作是拦截 webshell 上传和命令执行。这个 Apache 版 V4.0.23957 存在 webshell 绕过漏洞，意味着攻击者可以构造特定请求躲过安全狗的检测，把 webshell 传上去并执行。

防护软件自身失效，比单个应用漏洞更麻烦：站点依赖它兜底，它一绕过，后面的所有防护都形同虚设。所以这条作业的重点是**确认主机上是否装了受影响版本**，装了就处理掉，没装就闭环。

### 处置/加固方法

作业对象注明是 Windows 服务器下的 Apache 版，但给出的排查命令是 Linux 写法。按实际环境执行：

Linux 环境：

```bash
find / -name *safedog* 2>/dev/null
```

没有输出，说明未安装安全狗，不涉及此问题。

Windows 环境：在服务列表、"程序和功能"以及安装目录中排查"网站安全狗"（safedog）相关条目。

若确认安装了 V4.0.23957 这一版本，建议卸载该版本，或升级到修复此问题的版本（以厂商发布为准）。升级前先通过软件"关于"页面或安装目录的版本文件核对当前版本号，确认就是受影响版本再动手。

### 特殊情况处理

- `find` 无输出就是未安装，此项作业直接闭环。
- 卸载 WAF 会让站点直接暴露，卸载前确认有替代防护手段（网络侧防火墙策略、其他 WAF）兜底。
- 别只看服务名就下结论，版本号对不上（比如已经是更高版本）就不属于本漏洞范围。
- 排查时注意区分 Apache 版和 IIS 版，作业范围只涉及 Apache 版。

### 📌 处置后的验证

- Linux：再次执行 `find / -name *safedog* 2>/dev/null`，应当无输出。
- Windows：服务列表和程序列表中不再有安全狗相关条目。
- 若走升级路线：软件"关于"页面显示的版本号不再是 V4.0.23957。
