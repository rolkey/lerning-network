# 禁止多余 USB 接口的使用（物理封堵）

## 问题

- "除鼠标键盘等必要的外设接入USB外，其余USB口用封条封死（原则上保留一个数据拷贝接口）"

---

B25 是一项**物理层面**的加固，不动系统配置：把主机上多余的 USB 口用封条封死，只留键盘、鼠标这类必需外设的口，另外原则上保留一个受控的数据拷贝接口。为什么电力监控系统的主机要在物理上动手，而不是只靠软件禁用，值得单独说清楚。

### 🔍 风险原理

USB 口是内网主机和外部世界之间最容易被人忽视的"后门"。风险来自几个方向：

1. **摆渡攻击（air-gap crossing）**：生产控制大区的主机往往不联网或只连调度数据网，恶意程序进不来、数据出不去。U 盘就是绕过这道隔离的物理通道——插一个带毒的 U 盘，病毒进内网；插一个干净 U 盘把数据拷走，数据出内网。震网（Stuxnet）当年进伊朗核设施走的就是 U 盘这条道，这是工控安全里教科书级的案例。
2. **HID 注入**：市面上有"橡皮鸭"（USB Rubber Ducky）这类设备，插上后系统把它识别成键盘，在几秒内自动敲出一串恶意命令。它不需要系统有漏洞，因为系统把它当合法外设。
3. **人员无意识**：运维人员的个人 U 盘、手机充电线、无线网卡、随身 WiFi 都插过工作主机。每一次"顺手插一下"都是一次不受控的数据交换。
4. **封条的管理意义**：软件禁用（BIOS 关 USB、udev 禁 usb-storage）可以被有 root 权限的人改回来，物理封条一旦破坏**肉眼可见**，日常巡视一眼就能发现谁动过机器。

### 加固方法

这一项没有命令。执行要点：

- 梳理主机上所有 USB 口（前面板、后面板、主板扩展口都算），列出必须保留的：键盘、鼠标等必要外设。
- 其余 USB 口用封条（或热熔胶、环氧树脂胶等现场常用手段）物理封死，保证不破坏封条就无法使用。
- **原则上保留一个数据拷贝接口**：日常总有拷贝日志、备份配置、导入升级包的正当需求，留一个口集中管理。这个口不是"随便谁都能插"，而是专人保管、使用登记，用完即恢复封堵或插上受控设备。
- 封堵情况记入台账：哪个口封了、封条编号、封堵日期、谁执行的，和物理巡视记录挂上钩。

### 特殊情况处理

- **键盘鼠标本身也是 USB**：有些主机 PS/2 口已经没有了，键盘鼠标全走 USB。这时候"保留必要外设"就是保留键盘鼠标占用的口，其余照封。
- **软件手段作为辅助**：物理封堵之外，如果现场还需要一层技术兜底，可以在 BIOS 里禁用未使用的 USB 控制器，或者在系统里屏蔽 U 盘存储驱动：

```bash
# 禁止加载 usb-storage 模块（屏蔽 U 盘/移动硬盘，不影响键盘鼠标）
echo 'install usb-storage /bin/true' > /etc/modprobe.d/disable-usb-storage.conf
```

注意这条会连带把"保留的数据拷贝接口"也一起禁掉，执行前先跟现场确认拷贝需求怎么满足。源表只要求物理封堵，软件这层属于可选项。

- **封条别把散热口/指示灯盖了**：封的是 USB 金属接口，注意别把机箱其它部位糊上。

### 📌 加固后的验证

- 逐台核对：除键盘、鼠标及保留的数据拷贝接口外，其余 USB 口封条完好、无破损痕迹。
- 抽查一次巡视记录，确认封条状态纳入了日常巡视项目。
- 用受控 U 盘在保留接口上做一次拷贝测试，确认该口功能正常、有登记记录。

物理封堵这件事本身不产出系统输出，验证靠的是台账和肉眼，这一点在迎检时反而最直观。
