# OMS 主机加固学习资料索引

本目录是 **220kV 双文光伏电站 OMS 主机（10.172.242.203，Windows 10，设备名 OMS）** 的加固学习资料，由《OMS主机(10.172.242.203)__附件1：主站系统并网网络安全管控表单V2-6(正式).xlsx》中的作业项整理而成。

- 文件名 `序号N.md` 中的 **N 对应 Excel 表中的行号**（例如「序号20.md」对应表单第 20 行，作业编号 A3）。
- 每篇结构：`问题（原表要求）` → 风险原理 → 配置/加固方法 → 特殊情况处理 → 加固后的验证。
- 本文档为 **Windows（Win10）安全加固**，操作均在 Windows 语境下（`gpedit.msc`、`secpol.msc`、`services.msc`、`regedit`、`net share` 等）。
- 原表路径：`项目资料/04-220kV双文光伏电站加固报告/OMS主机(10.172.242.203)__附件1：主站系统并网网络安全管控表单V2-6(正式).xlsx`
