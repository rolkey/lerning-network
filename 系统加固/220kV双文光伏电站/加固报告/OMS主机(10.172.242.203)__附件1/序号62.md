# SYN Flood 攻击防护参数加固

## 问题

> HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters 注册表下已添加设置 syn 相关参数（SynAttackProtect=2、TcpMaxPortsExhausted=5、TcpMaxHalfOpen=500、TcpMaxHalfOpenRetried=400、EnableICMPRedirect=0）。

---

### 🔍 风险原理

SYN Flood 是经典的 DDoS 手法：攻击者批量发送 SYN 报文但不完成三次握手，主机为每个半开连接分配资源，资源被耗尽后正常连接被拒。`Tcpip\Parameters` 下的这几个参数控制主机什么时候判定“正在被攻击”，以及判定后如何收缩行为：

- `SynAttackProtect=2`：启用 SYN 攻击保护的最高档。检测到攻击时缩短重传超时、延后 Winsock 通知、阻止 RAW 套接字，把半开连接对资源的占用压到最低。
- `TcpMaxHalfOpen` / `TcpMaxHalfOpenRetried`：半开连接数（后者指已重传过 SYN 的半开连接）达到阈值即触发攻击保护。
- `TcpMaxPortsExhausted`：被拒绝的连接请求达到该数量同样触发保护。
- `EnableICMPRedirect=0`：关闭 ICMP 重定向。攻击者可伪造 ICMP Redirect 报文，把本机流量改道到自己的主机上做中间人窃听，因此必须关闭。

这些参数全部是 REG_DWORD 类型，位于 TCP/IP 协议栈的全局参数区，对整个系统的 TCP 行为生效。

### 配置（加固方法）

1. `Win+R` 运行 `regedit`。
2. 进入 `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters`。
3. 在右侧新建/修改以下 DWORD（32 位）值，数值按十进制填写：

| 值名称 | 类型 | 数值 |
| --- | --- | --- |
| `SynAttackProtect` | REG_DWORD | 2 |
| `TcpMaxPortsExhausted` | REG_DWORD | 5 |
| `TcpMaxHalfOpen` | REG_DWORD | 500 |
| `TcpMaxHalfOpenRetried` | REG_DWORD | 400 |
| `EnableICMPRedirect` | REG_DWORD | 0 |

### 特殊情况处理

这些 Tcpip 参数大多在系统启动时读取，改完需要重启主机才完全生效。数值是合规基线给定值，即使主机业务并发较大，也按基线配置执行，不要自行放宽阈值。`EnableICMPRedirect` 与 SYN 参数在源表里同组列出，它防的是重定向劫持而非洪水攻击，但同属 TCP/IP 栈加固，一并核对即可。若注册表里已有同名值，直接改数值，不要重复新建。个别安全软件或网络设备管理程序会覆盖这些参数，重启后要复查一次。

### 📌 加固后的验证

- 注册表复查，用命令输出核对五项值：

  ```text
  reg query HKLM\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters
  ```

  期望看到：`SynAttackProtect REG_DWORD 0x2`、`TcpMaxPortsExhausted REG_DWORD 0x5`、`TcpMaxHalfOpen REG_DWORD 0x1f4`、`TcpMaxHalfOpenRetried REG_DWORD 0x190`、`EnableICMPRedirect REG_DWORD 0x0`。
- 重启主机后再次查询，确认参数在系统启动后仍然生效。
