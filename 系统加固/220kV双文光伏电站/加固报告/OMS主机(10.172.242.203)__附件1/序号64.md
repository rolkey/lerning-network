# 登录终端操作超时锁定与屏保密码保护

## 问题

> 作业结点（A22）：网络安全：设置超过登录时间后强制注销，已启用；microsoft 网络服务器：设置启用登录时间用完时自动注销用户，已启用。
>
> 加固方法：1.启用远程会话挂起时间限制。进入“控制面板->管理工具->本地安全策略”，在“本地策略->安全选项”：“Microsoft 网络服务器”设置为“在挂起会话之前所需的空闲时间”为 15 分钟。
>
> 屏幕保护部分（续行）：屏幕保护程序，设置等待时间为“3分钟”，启用“在恢复时使用密码保护”。加固方法：2.屏幕保护时间为 15 分钟，勾选唤醒服务器密码。进入“控制面板－>显示－>个性化－>屏幕保护程序”：启用屏幕保护程序，设置等待时间为“15分钟”，启用“在恢复时显示登录屏幕”。

---

### 🔍 风险原理

操作终端（控制台、远程桌面）是值班场景里最容易“人走机不锁”的地方。没有超时锁定和屏保密码保护，任何人路过都能在已登录的会话里操作 OMS，出了事还记在别人的账号头上。本项分三层防线：

- “网络安全：超过登录时间后强制注销”与“Microsoft 网络服务器：登录时间用完时自动注销用户”：账号的“允许登录时间”到期后，挂着的 SMB 会话被强制切断，防止账号过期后会话仍然活跃。
- “Microsoft 网络服务器：挂起会话前所需的空闲时间”：限制空闲 SMB 会话的生命期（本项设为 15 分钟）。
- 屏幕保护程序 + “在恢复时显示登录屏幕”：操作员离开后超时进入屏保，恢复时必须重新输入口令，等效于自动锁屏。

### 配置（加固方法）

**步骤 1：安全选项（本地安全策略）**

控制面板 → 管理工具 → 本地安全策略 → 本地策略 → 安全选项（或 `Win+R` 运行 `secpol.msc`），逐项设置：

| 策略 | 设置 |
| --- | --- |
| 网络安全：超过登录时间后强制注销 | 已启用 |
| Microsoft 网络服务器：登录时间用完时自动注销用户 | 已启用 |
| Microsoft 网络服务器：挂起会话前所需的空闲时间 | 15 分钟 |

**步骤 2：屏幕保护程序**

控制面板 → 显示 → 个性化 → 屏幕保护程序：

1. 下拉选择一个屏保并启用；
2. 设置等待时间：作业结点要求“3分钟”，加固方法写“15分钟”，以现场实际设置的分钟数为准并记录在案；
3. 勾选“在恢复时显示登录屏幕”（即恢复时使用密码保护）；
4. 确定保存。

### 特殊情况处理

屏保密码保护只在账号设有密码时才有意义：账号无口令时，恢复屏保直接进桌面，等于没锁。先给所有本地账号配强口令，再谈屏保。运行监控画面的机器设了屏保后会定时锁屏，交接班要保证值班员手里有口令；若画面需要长期无人干预地显示，另建一台带门禁的专用监视终端，不要为了显示方便把屏保关掉。源表里作业结点（3 分钟）与加固方法（15 分钟）的屏保等待时间不一致，落地按现场执行值记录，核心要求是“已启用 + 恢复时密码保护”。若主机在域环境中，还可通过 `gpedit.msc` → 用户配置 → 管理模板 → 控制面板 → 个性化，用组策略统一下发屏幕保护相关设置，避免逐台手配。

### 📌 加固后的验证

- `secpol.msc` 复查：三项策略状态分别为“已启用”“已启用”“15 分钟”。
- 屏保设置窗口复查：已启用、等待时间已填、“在恢复时显示登录屏幕”已勾选。
- 实测：控制台放置不动，等待设定的超时时间，确认进入屏保；动鼠标/键盘后弹登录界面要求输口令，而非直接回到桌面。
- 执行 `gpupdate /force` 后重复核对一次。
