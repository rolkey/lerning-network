# 物理封堵多余 USB 接口

## 问题

> 除鼠标键盘等必要的外设接入 USB 外，其余 USB 口用封条封死（原则上保留一个数据拷贝接口）。

---

### 🔍 风险原理

USB 口是移动介质进出主机的主要通道：U 盘、移动硬盘在办公网与生产网之间摆渡，是电力监控系统病毒传入最常见的路径；攻击者还能插入伪装成键盘的 BadUSB 设备，直接向主机注入按键。软件层面的设备管控总有绕过余地（驱动更新、BIOS 版本差异、白名单维护不及时），物理封堵是最直接的手段——封条封死后，插入任何设备都必须先破坏封条，破坏会留下可见痕迹，巡检时能被发现。因此基线要求：除鼠标键盘等必要外设外，其余 USB 口一律封死，仅保留一个数据拷贝接口用于受控的数据交换。

### 配置（加固方法）

1. 清点主机全部 USB 口：前面板、后面板、主板引出及延长线接口逐个确认。
2. 保留鼠标、键盘等运行必需外设所占用的接口；其余接口贴一次性防拆封条封死。
3. 原则上保留一个数据拷贝接口，并纳入移动介质管理：拷贝须审批登记，外来 U 盘先经专用查杀机查杀，登记后接入。
4. 封条建议用易撕毁的一次性标签，编号登记，建立台账（哪个口、封条号、封堵日期、巡检记录）。

源表该项没有单独的“加固方法”列，作业结点本身就是执行要求。

### 特殊情况处理

保留的那个拷贝接口是整个管控的关键点：接口开放不代表流程开放，审批、登记、先查杀后接入缺一不可，否则等于把堵上的风险全挪到了一个口上。封条要定期巡检，发现脱落、破损立即处理并核查使用记录。后续确需增加外设（如更换打印机、加串口转换器），先走变更流程、登记后再启封，不允许现场自行撕封。物理封堵之外，系统层面可辅以设备安装限制（`gpedit.msc` 的设备安装限制策略，或 BIOS 中禁用未使用的 USB 控制器），作为纵深防御的补充手段。

### 📌 加固后的验证

- 逐口核对：除保留口和必需外设接口外，其余 USB 口封条完好，编号与台账一致。
- 插拔测试：保留口能正常拷贝数据；被封的口无法插入任何设备。
- 台账与实物一致，巡检记录连续无缺档。
