# 端口描述与业务用途规范

## 问题

- "已将使用的端口、VLAN添加符合实际应用的描述。"

---

网络设备上线后，端口和 VLAN 往往只有编号没有语义。运维人员面对 `GigabitEthernet0/1`、`Vlan 10` 这类名称时，无法判断它连接的是哪台服务器、承载的是哪条业务。给端口和 VLAN 加上与"实际应用相符"的描述，是网络台账规范化的第一步，也是后续故障定位、安全审计和变更管理的基础。

### 🔍 风险原理

- **误操作风险**：没有描述时，运维人员无法一眼区分业务口和空闲口。变更时可能把"业务生产口"当"测试口"直接 shutdown，造成业务中断；或把"待用口"当成"在用口"，误接设备引发环路或地址冲突。
- **审计与溯源困难**：等保、安全评估和故障排查都需要回答"这台交换机 1 口接的是谁、VLAN 20 跑的是什么业务"。没有描述，只能靠现场拔线、对 IP、查 MAC 逐项反推，效率极低且容易出错。
- **异常接入难以识别**：非法设备接入交换机后，如果所有端口描述都为空或千篇一律，无法快速判断"这个口本来不该有流量"。有准确描述作基准，异常流量、非法接入更容易被察觉。
- **合规要求**：并网安全管控表单把端口描述作为一项独立检查点，说明管理方明确要求网络资产与业务映射清晰可查。

### 配置/加固方法

H3C Comware V7 平台（MSR3620 路由器、S5130 交换机）使用 `description` 命令给接口和 VLAN 接口添加描述。建议先统一命名规范，例如 `业务方向-对端设备-用途`。

**1、给物理端口加描述**

```text
<H3C> system-view
[H3C] interface GigabitEthernet 1/0/1
[H3C-GigabitEthernet1/0/1] description TO-堡垒机-1.1.1.5
[H3C-GigabitEthernet1/0/1] quit
```

**2、给 VLAN 接口（三层网关）加描述**

```text
[H3C] interface Vlan-interface 10
[H3C-Vlan-interface10] description 生产监控业务网段-网关
[H3C-Vlan-interface10] quit
```

**3、给 VLAN 本身加描述**

```text
[H3C] vlan 10
[H3C-vlan10] description 生产监控业务-VLAN10
[H3C-vlan10] quit
```

**4、批量给连续端口加描述（接口范围）**

```text
[H3C] interface range GigabitEthernet 1/0/2 to GigabitEthernet 1/0/10
[H3C-if-range] description 预留空闲端口
[H3C-if-range] quit
```

逐条说明：`description` 命令写入的是设备运行配置，描述字符串建议控制在 80 字符以内，避免影响 `display interface` 输出可读性；命名要全站一致，不要同一台设备上出现"堡垒机口""Bastion"两种写法。

### 特殊情况处理

- **描述内容要"名副其实"**：描述必须与实际接线、VLAN 规划一致，不能为了应付检查随手写。描述与实况不符比没有描述更危险。
- **中文字符支持**：Comware 支持中文描述，但现场终端、串口工具和日志采集系统可能存在编码差异，建议中英文混用时先确认 display 输出正常显示，必要时统一用英文或拼音缩写。
- **改动需同步台账**：端口描述改了，网络拓扑图、接线表、资产台账要同步更新，避免"设备上有描述、台账里没记录"两张皮。
- **空闲端口也要标注**：已 `shutdown` 的空闲口建议标为"预留/禁用"，与在用的业务口明确区分，便于 D19"关闭未使用接口"一起核对。
- **描述不要含敏感信息**：不建议把密码、账号等敏感内容写进描述，`display current-configuration` 会把描述明文展示出来。

### 📌 加固后的验证

```text
<H3C> display interface description
```

期望结果：每个在用的物理端口都有与实际业务相符的描述，例如 `UP` 状态的端口描述为"TO-堡垒机-1.1.1.5"，而非空或默认值。

```text
<H3C> display vlan brief
```

期望结果：各 VLAN 的用途清晰，VLAN 接口描述与业务网段对应。

```text
<H3C> display current-configuration interface GigabitEthernet 1/0/1
```

期望结果：配置中能看到 `description TO-堡垒机-1.1.1.5` 字样，且与台账一致。
