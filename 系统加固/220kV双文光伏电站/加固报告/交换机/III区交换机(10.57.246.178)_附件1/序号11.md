# 启用 SSH 加密远程管理

## 问题

- "已启用SSH协议，远程维护的设备使用SSH加密协议。"

---

交换机、路由器传统的远程管理走 Telnet，账号口令和所有操作内容都以明文在网络上传输。任何能在链路上抓包的人，都可以直接截获管理员口令并远程登录设备。SSH（Secure Shell）把登录认证和后续操作全部加密，是远程维护设备的标配安全通道。本项要求设备启用 SSH 协议，禁用或替代明文 Telnet 登录。

### 🔍 风险原理

- **口令明文泄露**：Telnet 不加密，管理员登录时输入的用户名、密码以明文封装在 TCP 报文中。在共享网段、被镜像的端口或任意中间设备上抓包即可还原口令，设备控制权瞬间旁落。
- **操作被窃听篡改**：即使口令没被截获，Telnet 会话里的所有配置命令、show 输出也是明文，攻击者可窃听网络拓扑、ACL 策略、敏感配置，甚至发起会话劫持注入恶意命令。
- **中间人攻击**：无加密通道无法校验对端身份，攻击者可架设假服务器或篡改响应，诱导管理员把配置下发到错误位置或泄露更多信息。
- **合规底线**：电力监控系统安全防护要求远程维护必须采用加密协议，Telnet 明文登录在等保测评中属于高危项。

### 配置/加固方法

在 H3C MSR3620 / S5130 上启用 SSH，需要先开启 SSH 服务、生成主机密钥，再把 VTY 登录协议限制为 SSH。

**1、开启 SSH 服务并生成 RSA 主机密钥**

```text
<H3C> system-view
[H3C] ssh server enable
[H3C] public-key local create rsa
```

首次执行 `public-key local create rsa` 会提示输入密钥长度，建议用 2048 位（默认 1024），直接回车按默认亦可。

**2、将 VTY 登录协议限制为 SSH**

```text
[H3C] user-interface vty 0 4
[H3C-line-vty0-4] authentication-mode scheme
[H3C-line-vty0-4] protocol inbound ssh
[H3C-line-vty0-4] quit
```

`protocol inbound ssh` 让 VTY 只接受 SSH 连接，Telnet 登录被直接拒绝。

**3、创建 SSH 登录用户（配合 AAA 本地认证，见 D3）**

```text
[H3C] local-user admin class manage
[H3C-luser-manage-admin] password cipher Admin@2026
[H3C-luser-manage-admin] service-type ssh
[H3C-luser-manage-admin] authorization-attribute user-role network-admin
[H3C-luser-manage-admin] quit
```

`service-type ssh` 限定该账号只能通过 SSH 登录，不能用于 Telnet 或其他服务。

逐条说明：`ssh server enable` 是总开关，未开启时即便 VTY 配了 `protocol inbound ssh` 也无法建立 SSH 会话；`public-key local create rsa` 生成的主机密钥用于 SSH 握手阶段的密钥交换和身份标识，必须生成后才能正常登录。

### 特殊情况处理

- **老版本设备命令差异**：部分早期 Comware V5 设备使用 `stelnet server enable` 开启 SSH，需先 `display ssh server status` 确认当前平台的实际命令。
- **密钥已存在**：如果设备已生成过 RSA 密钥，再次执行 `public-key local create rsa` 会提示是否覆盖，覆盖后已建立的 SSH 会话会中断，生产环境操作前先确认无管理员在线。
- **VTY 范围要覆盖全部虚终端**：默认 VTY 是 0~4 共 5 个，若设备通过 `vty 5 15` 扩展过虚终端，记得对全部范围统一配置 `protocol inbound ssh`，否则留一两个 Telnet 口就前功尽弃。
- **迁移期保留 Telnet 的做法**：正式切换前如需临时保留 Telnet，务必限定来源 ACL 并尽快关闭，切勿长期并存。
- **客户端支持**：登录端需使用支持 SSHv2 的客户端（SecureCRT、Xshell、OpenSSH），旧版只支持 SSHv1 的客户端会被拒绝。

### 📌 加固后的验证

```text
<H3C> display ssh server status
```

期望结果：`SSH server: Enabled`，即 SSH 服务处于开启状态。

```text
<H3C> display ssh server session
```

期望结果：有管理员会话时能列出当前 SSH 连接；同时用 Telnet 连接设备应被拒绝或无法建立。

```text
<H3C> display user-interface vty 0 4
```

期望结果：VTY 的 `Protocol inbound` 显示为 `SSH`，认证方式为 `scheme`（AAA）。
