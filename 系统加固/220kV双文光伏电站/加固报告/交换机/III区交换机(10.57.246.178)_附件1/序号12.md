# VTY 启用 AAA 本地认证

## 问题

- "VTY启用设备AAA本地认证方式。"

---

AAA（Authentication 认证、Authorization 授权、Accounting 计费）是网络设备统一管理"谁能登录、登录后能干什么、干了什么"的框架。VTY 是设备的远程虚拟终端接口，直接决定 Telnet/SSH 远程登录时用什么方式验证身份。把 VTY 认证方式改为 AAA（本项为本地认证），登录时必须先通过账号口令校验，避免"无密码"或"固定口令"的裸奔状态。

### 🔍 风险原理

- **无认证裸奔**：VTY 若配置为 `authentication-mode none`，任何人只要能网络可达，就能直接进入设备命令行，等于把控制台钥匙挂在门上。
- **单一固定口令不可追溯**：`authentication-mode password` 只设一个共享口令，所有人用同一个密码登录，无法区分"谁做了什么"，出事后无法定位到具体个人，也不符合 D6"按用户分配账号"的要求。
- **缺乏授权边界**：没有 AAA 账号体系，就无法给不同人分配不同的操作权限，临时工、外包人员可能拿到与管理账号相同的全权限。
- **审计缺失**：AAA 的计费/审计能力（配合日志）能记录每次登录的账号、时间、来源 IP，是事后溯源的关键。认证模式不对，审计就无从谈起。

### 配置/加固方法

本项采用"AAA 本地认证"：在设备本地创建账号库，VTY 使用 `authentication-mode scheme` 调用该认证。

**1、创建本地账号（含权限角色）**

```text
<H3C> system-view
[H3C] local-user admin class manage
[H3C-luser-manage-admin] password cipher Admin@2026
[H3C-luser-manage-admin] service-type ssh
[H3C-luser-manage-admin] authorization-attribute user-role network-admin
[H3C-luser-manage-admin] quit
```

`class manage` 表示管理类账号；`authorization-attribute user-role network-admin` 赋予其网络管理员角色（最高权限），普通运维账号应改用 `network-operator` 只读角色。

**2、VTY 启用 scheme 认证（走 AAA）**

```text
[H3C] user-interface vty 0 4
[H3C-line-vty0-4] authentication-mode scheme
[H3C-line-vty0-4] quit
```

`authentication-mode scheme` 让登录认证交由 AAA 处理，默认使用本地认证域 `system`，账号校验即读取上面创建的 `local-user` 库。

**3、确认默认认证域为本地（如需）**

```text
[H3C] domain system
[H3C-isp-system] authentication login local
[H3C-isp-system] quit
```

逐条说明：本地认证的账号口令、角色权限都存于设备自身，不依赖外部服务器，适合站点内独立运行的网络设备；若要集中管理可改用 RADIUS/TACACS 服务器认证，但本项要求"本地认证方式"，故保持 `authentication login local`。

### 特殊情况处理

- **scheme 与 password 的区别**：`authentication-mode password` 是"单一口令"，不区分账号；本项要求的是 `authentication-mode scheme`（AAA 多账号）。两者别混淆。
- **账号口令同步 D7/D8 要求**：本地账号口令要以密文存储（`password cipher`）并满足复杂度要求，见序号16、序号17。
- **至少保留一个可用管理账号**：切换认证模式前，务必先建好 `local-user` 并测试能登录，否则一旦 VTY 改成 scheme 而账号库为空，远程登录会被锁死，只能 Console 口救援。
- **Console 口不受影响**：本项针对 VTY 远程登录，Console 口认证方式单独配置（见序号14），两处需分别处理。
- **VTY 范围全覆盖**：所有 `user-interface vty` 段都要改成 scheme，避免遗漏扩展段导致部分虚终端仍为弱认证。

### 📌 加固后的验证

```text
<H3C> display user-interface vty 0 4
```

期望结果：VTY 的 `Authentication` 显示为 `Scheme`（AAA 认证）。

```text
<H3C> display local-user
```

期望结果：能列出已创建的本地账号及其服务类型、角色（user-role）。

```text
<H3C> display current-configuration | include authentication-mode
```

期望结果：`user-interface vty` 下显示 `authentication-mode scheme`，无 `authentication-mode none` 残留。
