# 静态口令密文存储

## 问题

- "查看配置文件，静态口令以密文形式存放。"

---

设备配置文件中若把账号口令、特权口令以明文保存，任何人只要能看到配置（如备份文件泄露、配置下发过程被截获、巡检时屏幕被围观），口令就直接暴露。本项要求所有静态口令——本地账号口令、特权模式口令、SNMP community 等——一律以密文形式存储，配置里看不到明文。

### 🔍 风险原理

- **配置文件泄露即口令泄露**：设备的 `running-config`/`startup-config` 会被导出备份、上传网管平台、复制到运维终端，链路中任一点泄露，明文口令就随之扩散。
- **屏幕围观与日志回显**：巡检或故障处理时 `display current-configuration` 的屏幕内容可能被无关人员看到，明文口令一眼即被记下。
- **版本对比泄露**：配置备份多份长期保存，明文口令在历史版本、审计快照中反复出现，泄露面成倍扩大。
- **不满足合规**：等保和行业规范明确要求口令以密文存储，明文口令属于高危项，也是安全评估必查内容。

### 配置/加固方法

H3C Comware V7 提供多种密文口令形式：`cipher`（可逆加密）、`hash`（不可逆散列，更推荐）。配置时优先用 `cipher` 或 `hash`，避免 `simple`（明文）。

**1、本地账号口令用密文**

```text
<H3C> system-view
[H3C] local-user admin class manage
[H3C-luser-manage-admin] password cipher Admin@2026
[H3C-luser-manage-admin] quit
```

执行后配置中该口令显示为一串以 `$c$3` 开头的加密串，而非 `Admin@2026`。

**2、特权模式口令用不可逆散列**

```text
[H3C] super password role network-admin hash $h$6$...
```

`hash` 方式直接写入口令的散列值，配置中完全不保存可还原的口令；若现场设备不支持直接粘贴 hash，可先用 `super password role network-admin cipher` 让设备生成密文。

**3、Console/AUX 口令用密文**

```text
[H3C] user-interface console 0
[H3C-line-console0] set authentication password cipher Console@2026
[H3C-line-console0] quit
```

**4、SNMP community 用密文**

```text
[H3C] snmp-agent community read cipher Test@2026
```

逐条说明：`cipher` 是"加密后存储、可解密还原"，`hash` 是"单向散列、不可还原"，安全性 `hash` > `cipher` > `simple`。凡能接受输入原口令的场景，让设备自动 `cipher` 加密即可满足"密文存放"要求。

### 特殊情况处理

- **`simple` 会回显明文**：若误用 `password simple xxx`，配置里就是明文，必须改成 `cipher` 重新设置，别只改关键字不重设口令。
- **`cipher` 与 `hash` 的显示区别**：`display current-configuration` 中 cipher 口令显示为 `$c$3$...` 形式，hash 显示为 `$h$6$...` 形式，二者都是密文，均满足要求。
- **迁移旧配置**：存量设备中若有 `simple` 口令，逐个改用 `cipher` 重设，不要遗漏 Console、AUX、SNMP、BGP 邻居等非账号类口令。
- **口令别写进描述**：接口 `description`、`header` 横幅里不要夹杂密码，`display` 会明文回显这些内容。
- **备份文件同样受控**：配置文件导出后本身也含密文口令，导出文件仍需按敏感资料管理，防止整体泄露。

### 📌 加固后的验证

```text
<H3C> display current-configuration | include password
```

期望结果：所有账号口令均显示为 `cipher $c$3$...` 或 `hash $h$6$...` 密文，无任何明文口令。

```text
<H3C> display current-configuration | include simple
```

期望结果：无 `password simple`、`set authentication password simple` 等明文残留。

```text
<H3C> display local-user verbose
```

期望结果：账号 `Password` 字段为密文形式，无法直接读出原始口令。
