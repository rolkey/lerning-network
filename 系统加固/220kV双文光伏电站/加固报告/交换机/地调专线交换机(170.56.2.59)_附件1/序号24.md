# 关闭不必要的 IP 功能

## 问题

- "禁用IP源路由、PROXY ARP、直播功能、IP重定向、IP掩码响应、CDP。"

---

路由器和交换机在接口层面默认开启了一批"历史遗留"的辅助功能：IP 源路由、代理 ARP、定向广播转发、ICMP 重定向、ICMP 掩码响应、CDP 邻居发现等。这些功能在现代网络中大多已无必要，却可能被攻击者利用来探测网络、伪造路由、发动放大攻击或嗅探拓扑信息。本项要求逐一关闭这些非必要功能。

### 🔍 风险原理

- **IP 源路由**：允许发送方在报文中指定转发路径，攻击者可借此绕过路由策略、绕过 ACL、探测内部网络，甚至把流量导向受控节点。现代网络默认应丢弃带源路由选项的报文。
- **代理 ARP（Proxy ARP）**：设备替不在本网段的主机应答 ARP，容易被利用进行 ARP 欺骗、中间人攻击或放大探测范围，让不同网段主机被错误关联。
- **定向广播（直播功能）**：转发发往某网段广播地址的报文，可被用于 Smurf 等反射放大 DDoS，把一台主机的小请求放大成全网段的响应洪流。
- **ICMP 重定向 / 掩码响应 / CDP**：ICMP 重定向可被诱导篡改主机的路由表实现流量劫持；ICMP 掩码响应泄露网络掩码信息辅助攻击者测绘；CDP 邻居发现会广播设备型号、接口、地址等敏感信息，是攻击者信息收集的利器。

### 配置/加固方法

H3C Comware V7 中，代理 ARP、ICMP 重定向、ICMP 不可达、CDP 等在接口或全局视图有明确开关，逐项关闭。

**1、接口下关闭 ICMP 重定向与 ICMP 不可达**

```text
<H3C> system-view
[H3C] interface GigabitEthernet 0/0
[H3C-GigabitEthernet0/0] undo ip redirects
[H3C-GigabitEthernet0/0] undo ip unreachables
[H3C-GigabitEthernet0/0] quit
```

`undo ip redirects` 停止发送 ICMP 重定向；`undo ip unreachables` 停止发送 ICMP 不可达（关闭"IP掩码响应"相关的 ICMP 响应面）。

**2、接口下关闭代理 ARP**

```text
[H3C] interface Vlan-interface 10
[H3C-Vlan-interface10] undo proxy-arp enable
[H3C-Vlan-interface10] quit
```

**3、关闭 CDP（Cisco 发现协议，H3C 兼容支持）**

```text
[H3C] undo cdp enable
```

**4、关闭 IP 源路由与定向广播（视版本）**

H3C Comware 默认丢弃带源路由选项（option 131/137）的报文，且默认不转发定向广播，多数版本无独立总开关。部分版本支持：

```text
[H3C] undo ip option source-route
```

若现场设备无该命令，说明源路由已由系统默认丢弃，可用 ACL 进一步兜底过滤带 IP 选项的报文。

逐条说明：这些接口级功能需在**每个三层接口**上分别执行（或配合 `interface range` 批量下发）；`undo cdp enable` 是全局关闭 CDP，关闭后邻居设备间不再交换 CDP 信息。

### 特殊情况处理

- **接口级命令需全覆盖**：`undo ip redirects`、`undo proxy-arp enable` 只对当前接口生效，路由器多接口、交换机多 VLAN 接口都要逐一处理，容易遗漏。
- **"直播功能"即定向广播**：表单中"直播功能"对应 IP 定向广播转发（directed broadcast），Comware 默认不转发，确认未配置 `ip forward-broadcast` 即可。
- **ICMP 掩码响应的对应**：Comware 无 `ip mask-reply` 独立命令，ICMP 掩码响应默认关闭，通过 `undo ip unreachables` 收紧 ICMP 响应面作等价加固。
- **源路由无命令时别硬造**：若 `ip option source-route` 不存在，不要照抄别的平台命令，如实说明"设备默认丢弃源路由报文"并用 ACL 兜底。
- **影响评估**：关闭 CDP 会影响依赖 CDP 的拓扑发现工具，关闭 ICMP 重定向一般不影响正常路由，但变更前确认无依赖这些功能的运维系统。

### 📌 加固后的验证

```text
<H3C> display current-configuration | include "ip redirects|ip unreachables|proxy-arp"
```

期望结果：接口下无 `ip redirects`、`ip unreachables`、`proxy-arp enable` 等开启配置（已被 undo）。

```text
<H3C> display cdp
```

期望结果：CDP 状态为 Disabled。

```text
<H3C> display current-configuration | include forward-broadcast
```

期望结果：无 `ip forward-broadcast` 配置，定向广播转发未开启。
