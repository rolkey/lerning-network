# 修改默认登录横幅

## 问题

- "修改缺省BANNER。"

---

设备默认的登录横幅（Banner）往往是厂商名、型号或空白提示，既不产生任何法律威慑，也不向登录者告知"这是受保护的系统"。本项要求把默认横幅替换为自定义的警示语，在登录前明确告知访问者"未经授权禁止访问、操作将被审计"，为安全管理和法律追责提供依据。

### 🔍 风险原理

- **无法律威慑**：默认横幅不声明"未授权禁止访问"，攻击者被抓后可以"不知道这是受保护系统"为由辩解，削弱法律追责的效力。明确警示横幅是执法追诉的重要前提。
- **默认横幅泄露信息**：默认横幅常包含厂商、型号、软件版本，等于主动向探测者透露设备指纹，方便其针对性利用已知漏洞。
- **无法传达安全政策**：缺少横幅，就无法在登录入口统一传达安全策略、审计告知等要求，降低整体安全治理的严肃性。
- **合规要求**：并网安全管控把"修改默认 BANNER"列为检查项，要求以警示语替代默认提示。

### 配置/加固方法

H3C Comware V7 提供 `header` 命令设置登录横幅，分为登录提示（login）和消息提示（motd）两种，均可自定义。

**1、设置登录横幅（认证前提示）**

```text
<H3C> system-view
[H3C] header login "WARNING: This system is for authorized use only. Unauthorized access is prohibited and will be prosecuted."
```

**2、设置消息横幅（登录后 MOTD 提示）**

```text
[H3C] header motd "Unauthorized access is prohibited. All activities are monitored and recorded."
```

逐条说明：`header login` 的内容在用户输入账号前显示，适合放置"未授权禁止访问"的警示语；`header motd` 在登录成功后显示，适合放置运维提醒、系统公告。横幅文本用双引号包裹，可含空格；部分版本支持 `%` 分隔符写法（如 `header login %文本%`），以实际设备提示为准。

### 特殊情况处理

- **横幅内容要合规**：警示语应包含"仅限授权使用、未经授权禁止访问、行为将被监控审计、违者追究法律责任"等要素，措辞简洁明确。
- **不要泄露敏感信息**：横幅里不要写设备型号、软件版本、内部拓扑、管理员联系方式等，避免给攻击者提供情报。
- **中英文编码**：若写中文横幅，需确认登录终端编码支持，避免乱码；纯英文横幅兼容性最好。
- **login 与 motd 都要改**：只改一个不算完成，登录前提示（login）和登录后提示（motd）都应替换掉默认内容。
- **多设备统一**：全站设备横幅建议统一措辞，便于审计和检查时保持一致口径。

### 📌 加固后的验证

```text
<H3C> display current-configuration | include header
```

期望结果：能看到自定义的 `header login "..."` 和 `header motd "..."`，内容为警示语而非默认空白。

验证效果：重新 SSH 或 Console 登录设备，登录前应先显示自定义警示横幅，登录成功后显示 MOTD 提示。

```text
<H3C> display current-configuration | include header
```

期望结果（复核）：横幅文本中不含设备型号、版本等敏感信息。
