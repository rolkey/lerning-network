# 关闭不必要的网络服务

## 问题

- "禁用高危服务列表：TCP/UDP small服务、Figer服务、HTTP服务、HTTPS服务、BOOTP服务、FTP服务、DNS查询功能。"

---

网络设备在出厂默认配置下可能开启一批管理类和辅助类服务，其中不少并不被日常运维需要，却给攻击者提供了额外的攻击面。每多开一个服务，就多一种可能的漏洞、多一条暴力破解或信息泄露的路径。本项要求把这些高危或非必需服务逐一关闭，只保留运维确实需要的 SSH、SNMP（受限）、NTP 等。

### 🔍 风险原理

- **HTTP/HTTPS Web 管理面**：图形化管理页面常存在历史漏洞，且是口令爆破、CSRF、XSS 的高发区；若不用 Web 管理，应彻底关闭，减少攻击面。
- **FTP/TFTP 明文传输**：FTP 上传下载配置文件、版本文件不加密，账号口令明文传输，且目录遍历、匿名访问漏洞频发，是设备被植入恶意配置的常见通道。
- **DNS 查询功能**：设备作为 DNS 客户端对外发起解析请求，可被用于 DNS 隧道外带数据、或让设备误连恶意域名，生产网内通常无需设备主动解析域名。
- **small 服务 / Finger / BOOTP**：echo、chargen、daytime 等 small 服务可被用于反射放大攻击；Finger 泄露用户信息；BOOTP 可能被利用进行未授权引导。这些默认多处于关闭，但需确认未被人为打开。

### 配置/加固方法

H3C Comware V7 中，Web 服务、FTP 服务、DNS 解析有明确的开启/关闭命令，逐一执行 `undo` 关闭即可。

**1、关闭 HTTP / HTTPS Web 管理服务**

```text
<H3C> system-view
[H3C] undo ip http enable
[H3C] undo ip https enable
```

**2、关闭 FTP 服务**

```text
[H3C] undo ftp server enable
```

**3、关闭 DNS 查询（解析）功能**

```text
[H3C] undo dns resolve
[H3C] undo dns proxy
```

**4、确认 small 服务 / Finger / BOOTP 处于关闭**

H3C Comware 默认不开启 TCP/UDP small 服务（echo/chargen/discard/daytime）、Finger 与 BOOTP 服务，无独立总开关。可用下列命令确认设备未启用相关特性，并确保 DHCP 服务不响应 BOOTP：

```text
[H3C] dhcp server bootp ignore
```

`dhcp server bootp ignore` 让 DHCP 服务忽略 BOOTP 请求，防止 BOOTP 客户端被设备响应。

逐条说明：`undo ip http enable` / `undo ip https enable` 关闭 Web 管理面后，设备只能通过 SSH/Console 管理，符合"远程维护用 SSH"（序号11）的基线；`undo ftp server enable` 关闭 FTP，文件传输改用 SCP/SFTP（基于 SSH）更安全。

### 特殊情况处理

- **确实需要 Web 管理时**：若业务必须保留 HTTPS 管理，务必限定访问来源 ACL、使用强口令，并在测评记录中说明保留原因，否则一律关闭。
- **FTP 关闭后传文件**：需要升级版本、导出配置时改用 SFTP/SCP（`sftp server enable`，基于 SSH 加密），不要因嫌麻烦重新打开 FTP。
- **DNS 关闭影响**：`undo dns resolve` 后设备无法解析域名，若设备配置中用了域名（如 NTP 服务器写域名、loghost 写域名），应改为直接写 IP，避免功能异常。
- **默认关闭≠无需检查**：small 服务、Finger、BOOTP 默认虽关，但排查时仍需用验证命令确认未被历史配置打开。
- **逐台核对**：本项针对每台网络设备单独检查，不要因为"模板里关了"就假设所有设备都关了。

### 📌 加固后的验证

```text
<H3C> display ip http
```

期望结果：HTTP 服务状态为 Disabled。

```text
<H3C> display ftp server
```

期望结果：FTP 服务为 Disabled（或 `display ftp-server` 显示关闭）。

```text
<H3C> display dns server
```

期望结果：无配置的动态域名服务器，DNS 解析功能未启用。

```text
<H3C> display current-configuration | include "http enable|https enable|ftp server enable|dns resolve"
```

期望结果：无上述 `enable` 相关开启配置残留。
