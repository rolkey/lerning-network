# 动态路由协议认证

## 问题

- "启用动态IGP（RIPV2、OSPF、ISIS等）或EGP（BGP）协议时，启用动态路由协议认证功能，如MD5加密。"

---

动态路由协议（OSPF、RIP、IS-IS、BGP 等）默认不校验邻居身份，任意一台能接入链路的设备都可能伪造路由更新报文，向路由器注入错误路由，从而劫持流量、制造路由黑洞或环路。为路由协议邻居关系加上认证（如 MD5），可确保只有掌握相同密钥的合法邻居才能交换路由，是路由层面的关键防护。

### 🔍 风险原理

- **伪造路由注入**：攻击者接入路由器所在网段后，伪造 OSPF/RIP/BGP 更新报文，宣称自己拥有某网段或是最优下一跳，把业务流量牵引到受控设备上窃听或阻断。
- **路由环路与黑洞**：恶意或误配置的路由更新可造成路由环路、次优路径甚至路由黑洞，导致大面积业务中断，影响电力监控系统的实时性。
- **邻居会话被劫持**：BGP 邻居若未认证，攻击者可伪造 TCP 会话与路由器建立邻居，下发恶意路由；即使只扰乱邻居关系（DoS），也会造成路由震荡。
- **无认证 = 默认信任**：路由协议默认信任所有对端，缺乏"这个邻居是不是真的"的校验，认证是补上这一信任边界的最小代价手段。

### 配置/加固方法

**1、OSPF 认证（区域级启用 MD5，接口级配密钥）**

```text
<H3C> system-view
[H3C] ospf 1
[H3C-ospf-1] area 0
[H3C-ospf-1-area-0.0.0.0] authentication-mode md5
[H3C-ospf-1-area-0.0.0.0] quit
[H3C-ospf-1] quit
[H3C] interface GigabitEthernet 0/1
[H3C-GigabitEthernet0/1] ospf authentication-mode md5 1 cipher Ospf@2026
[H3C-GigabitEthernet0/1] quit
```

**2、RIP 认证（MD5）**

```text
[H3C] rip 1
[H3C-rip-1] version 2
[H3C-rip-1] quit
[H3C] interface GigabitEthernet 0/1
[H3C-GigabitEthernet0/1] rip authentication-mode md5 rfc2453 cipher Rip@2026
[H3C-GigabitEthernet0/1] quit
```

**3、BGP 认证（邻居 MD5）**

```text
[H3C] bgp 100
[H3C-bgp] peer 10.0.0.2 password cipher Bgp@2026
[H3C-bgp] quit
```

逐条说明：OSPF 认证在区域视图 `authentication-mode md5` 开启，在接口视图配具体密钥（key-id 1 + 密钥串）；RIP 认证在接口视图用 `rip authentication-mode md5 rfc2453 cipher ...` 配置；BGP 认证用 `peer <对端IP> password cipher ...`。所有邻居两端必须配置相同的密钥，否则邻居关系建立失败。

### 特殊情况处理

- **两端密钥必须一致**：认证密钥、key-id、认证类型（md5/simple）在邻居两端都要完全一致，任何一项不一致都会导致邻居建立失败、路由中断，变更时需两端同步并确认邻居恢复。
- **IS-IS 认证命令不同**：IS-IS 用 `isis authentication-mode md5`（接口级）或区域/域级认证，本模板以 OSPF/RIP/BGP 为例，IS-IS 环境按对应命令配置。
- **MD5 优于明文**：需求明确"如 MD5 加密"，优先用 md5；simple/明文认证只防误配、不防窃听，不建议用于生产。
- **密钥强度与轮换**：认证密钥同样要满足口令强度要求，并定期轮换；轮换时先加新密钥、两端生效后再删旧密钥，避免中断。
- **密钥别进配置明文**：用 `cipher` 关键字让认证密钥密文存储，呼应序号16的要求。

### 📌 加固后的验证

```text
<H3C> display ospf interface GigabitEthernet 0/1
```

期望结果：OSPF 接口认证方式为 MD5，邻居状态为 Full。

```text
<H3C> display rip 1
[H3C] display current-configuration | include rip authentication-mode
```

期望结果：RIP 接口配置了 `rip authentication-mode md5 rfc2453 cipher ...`。

```text
<H3C> display bgp peer 10.0.0.2 verbose
```

期望结果：BGP 邻居状态 Established，且显示配置了 MD5 口令认证。

综合验证：路由协议邻居关系正常建立，且抓包可见路由更新报文带有认证字段，无认证的第三方设备无法加入邻居。
