# 加密装置与主站加密管理装置建立远程管理

## 问题

- "加密装置是否与主站加密管理装置，建立远程管理。"（作业结点）
- "与加密装置主站（地调或中调）联系，与主站加密管理装置建立连接"（加固方法）

---

厂站侧的纵向加密装置不是孤立的，它应当纳入调度主站（地调或中调）的集中管理之下：由主站侧的加密管理装置对全网加密装置统一注册、统一下发策略和证书、统一监控运行状态。这项作业就是要与主站（地调或中调）联系，把本站加密装置登记到主站加密管理装置，建立远程管理连接，让装置从"站内单点自管"变成"主站集中可控"。

### 🔍 风险原理

- **装置"离线"，主站看不见。** 未建立远程管理时，本站加密装置在主站侧是"失联"状态，主站无法远程监控其运行状态、隧道健康度和告警，异常只能靠站内人员现场发现，响应慢、盲区大。
- **策略/证书无法统一下发。** 加密装置需要主站定期下发策略更新和证书（证书到期不换会导致隧道中断）。没有远程管理通道，策略和证书只能靠现场手工同步，容易出现本站与主站策略不一致、证书过期未换而业务中断的情况。
- **故障处置依赖现场，效率低。** 建立远程管理后，主站可远程读取装置状态、协助排查和远程下发配置，故障处置更快；否则只能等运维人员到场，延误恢复时间。

### 配置/加固方法

**1. 与主站（地调或中调）联系**

先与主站加密管理值班（地调或中调）电话/工单联系，确认本站装置的登记信息，包括：装置名称、设备 ID、证书、管理 IP、归属关系等，并约好联调时间窗口。

**2. 配置远程管理通道**

在加密装置上配置指向主站加密管理装置的管理通道：

```
管理通道方式   ：专用管理网口 或 调度数据网管理 VLAN
主站管理装置IP ：由主站提供
本端管理IP     ：按主站分配
```

确保该管理通道与主站加密管理装置网络可达，且不与业务加密隧道冲突。

**3. 完成注册与证书对接**

配合主站把本站装置注册进主站加密管理装置，完成证书对接，使主站侧能看到本站装置并显示"在线/正常"状态。

**4. 与主站核对状态**

与主站值班共同核对装置状态、策略版本、证书有效期是否一致，确认远程管理建立成功并留档。

### 特殊情况处理

- 远程管理建立涉及主站、厂站双方配合，需提前约好时间窗口，尤其涉及策略/证书下发时要避开业务高峰并报备。
- 管理通道与业务通道可能共用调度数据网，配置时注意区分管理 VLAN/管理口，避免与业务隧道互相影响。
- 装置证书校验对时间敏感，先确认装置时间与主站时钟同步，避免时间偏差导致证书校验失败。
- 建立主站集中管理后，站内再改本地策略前要先与主站沟通，否则本地改动可能被主站统一下发的策略覆盖。
- 不同厂家（南瑞、科东、东土等）的管理通道配置界面差异较大，联调时按主站下发的联调指导书操作，不要自行摸索。

### 📌 加固后的验证

```bash
# 1. 在主站加密管理装置上确认本站装置状态为"在线/正常"
# 2. 主站可远程读取本站装置状态、策略版本
# 3. 与主站核对后，双方对装置状态、策略版本记录一致
```

期望结果：主站（地调或中调）加密管理装置上能看到本站加密装置且状态为"在线/正常"；主站可远程读取装置状态与策略版本；与主站核对后双方记录一致，远程管理通道建立成功。
