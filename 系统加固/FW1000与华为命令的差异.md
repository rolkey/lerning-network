FW1000 和华为防火墙的命令行差异，主要体现在**配置保存机制、视图层级和关键操作命令的写法**上。以下是对比梳理：

### 核心差异一览

| 对比维度 | DPtech FW1000 | 华为防火墙 |
| :--- | :--- | :--- |
| **进入配置视图** | `conf-mode`（系统视图） | `system-view`（系统视图） |
| **保存配置** | `configuration save <文件名>` | `save`（需确认） |
| **查看当前配置** | `show running-config` 或 `show configuration` | `display current-configuration` |
| **查看已保存配置** | 通常直接查看文件内容 | `display saved-configuration` |
| **接口命名示例** | `gige0_7`（下划线分隔） | `GigabitEthernet 0/0/0`（斜杠分隔） |
| **静态路由** | 具体语法需查手册 | `ip route-static 目的网段 掩码 下一跳` |
| **清空下次启动配置** | 相关命令为 `configuration delete` 等 | `reset saved-configuration` |

### 需要特别留意的差异

**1. 配置保存的逻辑完全不同**
这是你最需要适应的点。FW1000 使用 `configuration save <文件名>`，它会把当前运行配置**另存为一个独立文件**，更像一种“快照备份”。而华为的 `save` 是将运行配置**覆盖写入**到设备的下次启动配置文件中，是让配置“固化”的标准动作。简单说，FW1000 的 save 偏向备份，华为的 save 偏向持久化。

**2. 查看命令的“前缀”不同**
FW1000 用 `show`，华为用 `display`。这源于两者底层操作系统的差异。你在 FW1000 上需要习惯 `show configuration`，而在华为上则是 `display current-configuration`。

**3. 接口命名规则**
FW1000 的接口名通常带下划线，如 `gige0_7`（千兆以太口 0/7），这和华为的 `GigabitEthernet 0/0/0`（槽位/子卡/端口）风格不同。在写命令时需要注意格式。

**4. 配置文件管理思路不同**
华为有一套完整的 `display current-configuration`（当前运行）与 `display saved-configuration`（下次启动）的对比机制，方便确认配置是否已保存。FW1000 则更依赖你手动管理保存出来的配置文件，命令如 `configuration save`、`configuration delete`、`configuration rollback save` 等构成了它的文件管理体系。

### 总结

从华为设备迁移到 FW1000，最需要改变的习惯是**配置保存的思维**：华为是“改完记得 save 一下”，FW1000 是“改完后可以考虑 save 成一个备份文件”。同时，把 `display` 换成 `show`，并适应下划线式的接口名即可。
