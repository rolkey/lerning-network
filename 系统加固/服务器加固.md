# 服务器加固

## 登录限制

### 限制终端密钥登录

- 修改配置文件`/etc/ssh/sshd_config`

```shell
# 禁止root用户登录
PermitRootLogin prohibit-password
```

- 在主机上可以密码登录

**可以。** `PermitRootLogin prohibit-password` 这个配置**只限制 SSH 远程登录**，不影响你在主机本地通过物理终端或控制台直接登录。

### 关键区分

| 登录方式 | 是否受影响 | 说明 |
|---|---|---|
| **SSH 远程登录**（密码） | **禁止** | 这是 `prohibit-password` 明确要拦截的 |
| **SSH 远程登录**（密钥） | 允许 | 这是该配置保留的唯一远程入口 |
| **本地终端/控制台登录** | **不受影响** | `sshd_config` 只管 SSH，管不到主机键盘或虚拟控制台 |

### 为什么本地登录不受影响？

`PermitRootLogin` 是 `sshd` 服务（SSH 守护进程）的配置项，其作用域仅限于 **SSH 连接**。当你坐在主机前直接敲键盘登录，或者通过云服务商的控制台（如 VNC）访问时，走的是 `login`/`getty` 或系统控制台通道，完全不经过 `sshd`，因此这个配置对它无效。

### 唯一例外：`nologin`

如果你之前问的 `nologin` 情况存在（即 root 用户的 Shell 被设为 `/usr/sbin/nologin`），那么**本地登录同样会被拦截**。因为 `nologin` 是账户层面的限制，无论从哪个入口尝试启动交互式 Shell，都会被系统拒绝。
