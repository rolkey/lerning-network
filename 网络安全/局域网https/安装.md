在局域网（LAN）中搭建 HTTPS，核心在于**生成自签名 SSL 证书（或自建 CA）**，并将根证书导入设备以消除浏览器的“不安全”警告。

最方便、标准的方案是使用 **mkcert** 工具。它能自动在本地创建 CA 并生成受信任的证书，无需繁琐的 `openssl` 命令。

1. **安装 mkcert 工具:** 需管理员 / sudo 权限.
在用于搭建 Web 服务的服务器或开发机上安装 mkcert。

* **Windows (Chocolatey / Scoop):**

```bash
choco install mkcert
# 或
scoop install mkcert

```

* **macOS (Homebrew):**

```bash
brew install mkcert
brew install nss # 如果使用 Firefox 浏览器

```

* **Linux (Ubuntu/Debian):**

```bash
sudo apt install libnss3-tools
# 下载 mkcert 二进制文件并赋予执行权限
curl -JLO "https://dl.filippo.io/mkcert/latest?for=linux/amd64"
chmod +x mkcert-v*-linux-amd64
sudo mv mkcert-v*-linux-amd64 /usr/local/bin/mkcert

```

*验证方式：* 在终端运行 `mkcert -version`，能正常输出版本号即安装成功。


2. **生成根证书与局域网证书:** 明确服务器的局域网 IP.
1. **初始化本地 CA：**

```bash
mkcert -install

```

这会在当前机器上安装根证书。

2. **为局域网 IP（及可选的自定义域名）生成证书：**
替换 `192.168.1.100` 为你服务器的实际局域网 IP：

```bash
mkcert 192.168.1.100 localhost 127.0.0.1

```

命令执行后会在当前目录生成两个文件：

* `192.168.1.100+2.pem`（证书文件）
* `192.168.1.100+2-key.pem`（私钥文件）

*验证方式：* 检查目录下是否成功生成 `.pem` 和 `-key.pem` 文件。


3. **配置 Web 服务器（以 Nginx 为例）:** 配置 443 端口与证书路径.
将生成的证书文件放置在服务器的合适位置（如 `/etc/nginx/certs/`），并在 Nginx 中进行配置：

```nginx
server {
    listen 443 ssl;
    server_name 192.168.1.100;

    ssl_certificate     /etc/nginx/certs/192.168.1.100+2.pem;
    ssl_certificate_key /etc/nginx/certs/192.168.1.100+2-key.pem;

    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    location / {
        root /usr/share/nginx/html;
        index index.html index.htm;
    }
}

```

配置完成后重启 Nginx 服务：`nginx -s reload`。

*验证方式：* 在**服务端本机**打开浏览器访问 `[https://192.168.1.100](https://192.168.1.100)`，确认无安全警告且能正常加载页面。


4. **在局域网客户端设备上信任 CA 根证书:** 关键步骤：解决其他设备访问不安全问题.
由于 mkcert 生成的根证书仅安装在服务器本机，局域网内的其他设备（手机、其他 PC）访问时仍会报“不安全”。需要将根证书导入客户端：

1. **获取根证书文件：**
在服务端运行 `mkcert -CAROOT`，找到 `rootCA.pem` 文件的存储路径，将其发送到需要访问的客户端设备上。
2. **客户端导入根证书：**
* **Windows:** 双击 `rootCA.pem` -> 安装证书 -> 当前用户 -> 将所有证书放入下列存储 -> 选择 **“受信任的根证书颁发机构”**。
* **macOS:** 双击 `rootCA.pem` 导入到“钥匙串访问” -> 找到该证书 -> 右键“显示简介” -> 展开“信任” -> 设为 **“始终信任”**。
* **iOS:** 发送文件到设备并安装描述文件 -> 进入“设置” -> “已下载描述文件”进行安装 -> 进入“设置” > “通用” > “关于本机” > “证书信任设置” -> 开启对该根证书的全名信任。
* **Android:** 设置 -> 安全 -> 加密与凭据 -> 安装证书 -> CA 证书。



*验证方式：* 在客户端设备浏览器打开 `[https://192.168.1.100](https://192.168.1.100)`，地址栏显示绿色的锁头图标/正常 HTTPS 状态，无拦截警告。
