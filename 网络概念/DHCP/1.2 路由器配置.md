在 **eNSP (Enterprise Network Simulation Platform)** 中模拟动态IP分配的场景，最经典且最常用的方案是配置 **DHCP（Dynamic Host Configuration Protocol）服务**。通常有两种实现方式：

1. **路由器作为 DHCP 服务器**（适合局域网终端自动获取IP）。
2. **交换机（如三层交换机）作为 DHCP 服务器**（适合多VLAN环境）。

以下为你整理一个完整的实战演练方案：**使用华为路由器作为 DHCP 服务器，为局域网内的PC动态分配IP地址、网关和DNS**。

---

### 一、 拓扑结构设计

* **设备准备**：
* **AR1**（路由器，充当 DHCP 服务器及网关）
* **PC1**（终端设备，模拟动态获取IP的客户端）


* **连接方式**：
* AR1 的 `GigabitEthernet 0/0/1` 连接到 PC1。



---

### 二、 详细配置步骤

#### 步骤 1：配置路由器接口 IP

首先为路由器的接口配置一个IP地址，该地址将作为后续PC的**默认网关**。

```shell
<Huawei> system-view
[Huawei] sysname R1
[R1] interface GigabitEthernet 0/0/1
[R1-GigabitEthernet0/0/1] ip address 192.168.1.1 255.255.255.0
[R1-GigabitEthernet0/0/1] quit

```

#### 步骤 2：全局开启 DHCP 服务

在华为设备中，必须先全局启用 DHCP 功能。

```shell
[R1] dhcp enable

```

#### 步骤 3：创建并配置 DHCP 地址池（IP Pool）

定义一个全局地址池，设置可分配的网段、网关、DNS服务器以及租期。

```shell
# 创建名为 mypool 的地址池
[R1] ip pool mypool

# 指定可分配的网段及掩码
[R1-ip-pool-mypool] network 192.168.1.0 mask 255.255.255.0

# 配置网关地址（下发给客户端）
[R1-ip-pool-mypool] gateway-list 192.168.1.1

# 配置DNS服务器地址
[R1-ip-pool-mypool] dns-list 8.8.8.8 114.114.114.114

# 配置IP地址租期（可选，默认通常为1天，这里设置为2天）
[R1-ip-pool-mypool] lease day 2

[R1-ip-pool-mypool] quit

```

#### 步骤 4：在接口上应用全局 DHCP 地址池

将配置好的地址池绑定到连接终端的物理接口上。

```shell
[R1] interface GigabitEthernet 0/0/1
# 启用基于接口的全局 DHCP 地址池选择
[R1-GigabitEthernet0/0/1] dhcp select global
[R1-GigabitEthernet0/0/1] quit

```

---

### 三、 客户端验证与测试

1. **配置 PC 客户端**：
* 在 eNSP 中双击 **PC1**。
* 在“基础配置”或“命令行”选项卡中，将网卡设置为 **DHCP** 模式。
* 点击应用。


2. **查看获取结果**：
* 在 PC1 的命令行中输入以下命令查看获取到的IP信息：
```text
ipconfig

```


* 如果配置正确，PC1 应当成功获取到 `192.168.1.x` 网段的IP地址、网关 `192.168.1.1` 以及 DNS。


3. **路由器端查看 DHCP 状态**：
* 在 R1 上可以通过以下命令查看 IP 地址的分配情况（如租约、已分配IP等）：
```shell
[R1] display ip pool name mypool

```

### 💡 进阶扩展：若需通过三层交换机分配（VLAN DHCP）

如果在实际企业网络中，是由 **交换机** 充当多个 VLAN 的网关并下发动态IP，则需要在三层交换机上配置：

```shell
<S3700/S5700> system-view
[S3700] dhcp enable
[S3700] vlan batch 10 20

# 配置VLANIF接口IP作为网关
[S3700] interface Vlanif 10
[S3700-Vlanif10] ip address 192.168.10.1 255.255.255.0
[S3700-Vlanif10] dhcp select interface   # 开启接口模式的DHCP（直接使用接口IP所在网段下发）
[S3700-Vlanif10] quit

```

*注：交换机直接使用 `dhcp select interface` 可以最快地为对应 VLAN 内的终端提供动态IP服务。*
