以下为你提供一个在 **eNSP** 中使用华为三层交换机（如 S5700）作为 DHCP 服务器，为多个不同 VLAN 的终端动态分配 IP 地址的详细配置实例。

---

### 一、 拓扑规划

* **核心设备**：
* **LSW1**（三层交换机，配置为 DHCP 服务器及各个 VLAN 的默认网关）
* **PC1**、**PC2**（终端设备，分别属于不同 VLAN）


* **VLAN 及网段规划**：
* **VLAN 10**：网段 `192.168.10.0/24`，网关 `192.168.10.1`（连接 PC1）
* **VLAN 20**：网段 `192.168.100.0/24`，网关 `192.168.100.1`（连接 PC2）



---

### 二、 详细配置步骤

在 eNSP 中打开 S5700 交换机（LSW1）的命令行界面（CLI），依次输入以下命令：

#### 步骤 1：全局开启 DHCP 并创建 VLAN

```shell
<Huawei> system-view
[Huawei] sysname LSW1

# 全局启用 DHCP 服务
[LSW1] dhcp enable

# 批量创建 VLAN 10 和 VLAN 20
[LSW1] vlan batch 10 20

```

> **验证方法**：输入 `display vlan`，确认 VLAN 10 和 VLAN 20 已经成功创建。

#### 步骤 2：配置下行接口（连接 PC 的端口）

将连接不同终端的交换机端口加入到对应的 VLAN 中，并设置为 Access 模式。

```shell
# 配置连接 PC1 的端口 (以 GigabitEthernet 0/0/1 为例)
[LSW1] interface GigabitEthernet 0/0/1
[LSW1-GigabitEthernet0/0/1] port link-type access
[LSW1-GigabitEthernet0/0/1] port default vlan 10
[LSW1-GigabitEthernet0/0/1] quit

# 配置连接 PC2 的端口 (以 GigabitEthernet 0/0/2 为例)
[LSW1] interface GigabitEthernet 0/0/2
[LSW1-GigabitEthernet0/0/2] port link-type access
[LSW1-GigabitEthernet0/0/2] port default vlan 20
[LSW1-GigabitEthernet0/0/2] quit

```

#### 步骤 3：配置 VLANIF 接口IP与 DHCP 模式

为每个 VLAN 创建三层虚接口（VLANIF），配置网关 IP，并指定通过接口地址池（Interface 模式）下发 DHCP。

```shell
# 配置 VLAN 10 的网关及 DHCP
[LSW1] interface Vlanif 10
[LSW1-Vlanif10] ip address 192.168.10.1 255.255.255.0
[LSW1-Vlanif10] dhcp select interface
[LSW1-Vlanif10] quit

# 配置 VLAN 20 的网关及 DHCP
[LSW1] interface Vlanif 20
[LSW1-Vlanif20] ip address 192.168.100.1 255.255.255.0
[LSW1-Vlanif20] dhcp select interface
[LSW1-Vlanif20] quit

```

> **验证方法**：输入 `display ip interface brief`，检查 VLANIF10 和 VLANIF20 的 IP 地址是否状态为 `up`。

---

### 三、 客户端验证与测试

1. **PC 设置**：
* 双击 **PC1**，将网卡设置为 **DHCP**，应用后查看其是否获取到 `192.168.10.x` 网段的 IP。
* 双击 **PC2**，同样设置为 **DHCP**，确认其获取到 `192.168.100.x` 网段的 IP。


2. **连通性测试**：
* 在 PC1 的命令行中尝试 `ping 192.168.100.1`（测试跨 VLAN 网关通信）或 `ping` PC2 的获取地址，验证三层交换机的路由与动态分配是否完全正常。
* **验证方法**：在交换机上输入 `display dhcp server ip-in-use`，可查看当前所有通过 DHCP 成功获取 IP 的客户端租约记录。
