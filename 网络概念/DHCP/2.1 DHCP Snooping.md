**DHCP Snooping**（DHCP 监听/窥探）是交换机上的一种安全技术，主要用于**防御针对 DHCP（动态主机配置协议）的各种攻击**，并配合其他安全特性（如 ARP 检查、IP 源防攻击等）保护局域网的安全。

简单来说，DHCP Snooping 的核心作用就是**区分局域网内的合法 DHCP 服务器与非法（伪造的）DHCP 服务器**，并记录合法用户的 IP 与 MAC 地址绑定关系。

---

### 一、 核心作用与防范的攻击

#### 1. 防御 DHCP 欺骗攻击（DHCP Spoofing / Rogue DHCP Server）

* **背景**：在局域网中，任何接入网络的设备都可以私自架设一个 DHCP 服务器（比如某些私接的小路由器、或者攻击者运行的恶意软件）。
* **危害**：非法的 DHCP 服务器会比正规的 DHCP 服务器更快地向客户端响应 IP 地址、默认网关和 DNS。客户端拿到错误的信息后，会导致：
* **断网**：获取到错误网段的 IP 无法上网。
* **中间人攻击（MITM）**：攻击者将网关指向自己，从而窃听、篡改用户的网络流量。


* **DHCP Snooping 的作用**：它允许管理员将交换机的端口划分为 **Trusted（信任端口）** 和 **Untrusted（非信任端口）**。
* **信任端口**：连接正规 DHCP 服务器（或上联交换机）的端口，允许接收 DHCP 服务器的响应报文（DHCPOFFER、DHCPACK 等）。
* **非信任端口**：连接普通终端用户的端口，如果这些端口收到了 DHCP 服务器的响应报文，交换机会**直接丢弃**，从而有效阻止非法 DHCP 服务器的发包。



#### 2. 防御 DHCP 饿死攻击（DHCP Starvation Attack）

* **背景**：攻击者利用伪造的 MAC 地址向 DHCP 服务器发送大量带有不同 MAC 地址的 `DHCP Discover` 请求，耗尽 DHCP 服务器池中的所有 IP 地址。
* **危害**：导致合法的网络终端无法获取 IP 地址，网络瘫痪。
* **DHCP Snooping 的作用**：结合端口速率限制或配合配合其他机制，限制非信任端口上发送 DHCP 请求的报文速率，或者通过检查报文中的源 MAC 地址与客户端实际 MAC 地址是否一致，直接丢弃伪造的请求。

#### 3. 生成 DHCP Snooping 绑定表（Binding Table）

* **作用**：当用户通过合法的 DHCP 服务器成功获取 IP 地址后，DHCP Snooping 会自动拦截并记录一张“IP-MAC-VLAN-端口”绑定表。
* **延伸价值**：这张表是实现其他高级安全功能的基础：
* **DAI（Dynamic ARP Inspection，动态 ARP 检查）**：利用该表防范 ARP 欺骗攻击，丢弃非法的 ARP 映射。
* **IPSG（IP Source Guard，IP 源防攻击）**：防止用户私自修改 IP 地址进行 IP 冒用，确保只有绑定表中的 IP/MAC 组合才能通过交换机。



---

### 二、 工作原理简述

1. **端口划分**：
* 将连接核心 DHCP 服务器的端口设置为 **Trusted**。
* 将连接普通终端电脑的端口设置为 **Untrusted**（默认所有端口均为 Untrusted）。


2. **报文过滤**：
* 对于来自 **Untrusted 端口**的报文，交换机只允许客户端发送的 `DHCP Discover` 和 `DHCP Request` 通过，而**严禁**来自该端口的 `DHCP Offer` 和 `DHCP ACK` 等服务器端应答报文。


3. **表项记录**：
* 当合法的 `DHCP ACK` 报文通过 **Trusted 端口**返回给客户端时，交换机会偷看（Snoop）其中的内容，提取出客户端的 **MAC 地址、分配到的 IP 地址、所属 VLAN 以及接入的交换机端口**，写入 DHCP Snooping 绑定数据库中。



---

### 三、 总结应用场景

DHCP Snooping 几乎是企业级网络、园区网和数据中心交换机中**必配的基础安全特性**。尤其在无线接入点（AP）连接的交换机端口、访客网络或公共网段，开启 DHCP Snooping 可以极大地提升二层网络的健壮性，防止内网出现“假网关”或IP地址盗用问题。
