- 实验编号：test07

在 eNSP 中配置 OSPF（开放式最短路径优先）动态路由协议，可以使多台路由器之间自动发现并学习网络路由，从而实现网络冗余与自动路径切换。以下是在 eNSP 路由器（如 AR1、AR2、AR3）上配置 OSPF 的具体步骤：

**1. 配置路由器接口 IP 地址:** 准备工作.
分别登录各台路由器，进入物理接口（或 LoopBack 接口）配置对应的互联 IP 地址。以 AR1 为例：

```text
<AR1> system-view
[AR1] interface GigabitEthernet 0/0/0
[AR1-GigabitEthernet0/0/0] ip address 192.168.1.1 255.255.255.0
[AR1-GigabitEthernet0/0/0] quit

```

*验证方法*：使用命令 `display ip interface brief` 检查接口，确认 IP 地址已正确配置且状态为 Up。


**2. 启动 OSPF 进程并指定区域:** 核心配置.
在每台路由器上启用 OSPF 进程，并宣告直连网段到对应的区域（通常为 Area 0）。以 AR1 为例：

```text
[AR1] ospf 1 router-id 1.1.1.1
[AR1-ospf-1] area 0
[AR1-ospf-1-area-0.0.0.0] network 192.168.1.0 0.0.0.255
[AR1-ospf-1-area-0.0.0.0] network 192.168.12.0 0.0.0.255

```

*验证方法*：使用命令 `display ospf peer brief` 查看 OSPF 邻居状态，确认邻居关系（Neighbor State）显示为 "Full" 即表示建立成功。


**3. 检查与验证 OSPF 路由表:** 结果确认.
当所有相连设备的 OSPF 邻居关系建立完成后，检查路由表是否已自动同步。
*验证方法*：在路由器上运行 `display ip routing-table protocol ospf` 命令，确认能够看到通过 OSPF 学习到的其他网段路由条目。
