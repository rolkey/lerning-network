针对您在 eNSP 拓扑中的三台华为 AR2220 路由器（AR1、AR2、AR3），以下为您整理了实现多路径互联及 OSPF 动态路由协议的**完整设备配置清单**。

根据您在 eNSP 中的拓扑结构（AR1 与 AR2 相连，AR2 与 AR3 相连），我们为它们规划了如下的 IP 地址方案：

* **AR1 连向 AR2 的接口** (GE0/0/0): `192.168.12.1/24`
* **AR2 连向 AR1 的接口** (GE0/0/0): `192.168.12.2/24`
* **AR2 连向 AR3 的接口** (GE0/0/1): `192.168.23.2/24`
* **AR3 连向 AR2 的接口** (GE0/0/0): `192.168.23.3/24`
* **Loopback 0 回环接口**（作为稳定的 Router ID）：
* AR1: `1.1.1.1/32`
* AR2: `2.2.2.2/32`
* AR3: `3.3.3.3/32`



---

### 1. AR1 完整配置命令

```text
<Sysname> system-view
[Sysname] sysname AR1

# 配置系统回环接口作为 Router ID
[AR1] interface LoopBack 0
[AR1-LoopBack0] ip address 1.1.1.1 255.255.255.255
[AR1-LoopBack0] quit

# 配置连接 AR2 的物理接口
[AR1] interface GigabitEthernet 0/0/0
[AR1-GigabitEthernet0/0/0] ip address 192.168.12.1 255.255.255.0
[AR1-GigabitEthernet0/0/0] quit

# 启动 OSPF 进程并宣告网段
[AR1] ospf 1 router-id 1.1.1.1
[AR1-ospf-1] area 0
[AR1-ospf-1-area-0.0.0.0] network 1.1.1.1 0.0.0.0
[AR1-ospf-1-area-0.0.0.0] network 192.168.12.0 0.0.0.255
[AR1-ospf-1-area-0.0.0.0] quit
[AR1-ospf-1] quit

```

[AR2-GigabitEthernet0/0/0] ip address 192.168.12.2 255.255.255.0

[AR2-GigabitEthernet0/0/1] quit

# 启动 OSPF 进程并宣告所有直连网段
[AR2] ospf 1 router-id 2.2.2.2

[AR2-ospf-1-area-0.0.0.0] network 192.168.12.0 0.0.0.255

### 验证方法

配置完成后，您可以在任一路由器（例如 AR1）上执行以下命令进行检查：

1. **查看邻居状态**：`display ospf peer brief` （如果状态显示为 **Full**，说明 OSPF 邻居建立成功）。
2. **查看路由表**：`display ip routing-table protocol ospf` （确认 AR1 能够通过 OSPF 学习到 AR3 上的网段及回环地址）。
3. **连通性测试**：在 AR1 上使用 `ping -a 1.1.1.1 3.3.3.3`，验证全网动态路由是否互通。
