### 二、 中间公网路由器 (AR1) 配置脚本

AR1 作为公网传输设备，主要配置接口 IP 并保证路由可达：

```text
<Huawei> system-view
[Huawei] sysname AR1

[AR1] interface GigabitEthernet 0/0/1
[AR1-GigabitEthernet0/0/1] ip address 10.1.1.1 24
[AR1-GigabitEthernet0/0/1] quit

[AR1] interface GigabitEthernet 0/0/2
[AR1-GigabitEthernet0/0/2] ip address 10.2.1.1 24
[AR1-GigabitEthernet0/0/2] quit

```

*Verification:* 使用 `display ip interface brief` 检查接口状态是否全部为 UP。

### 三、 防火墙 FW1 配置脚本

```text
<USG6000V> system-view
[USG6000V] sysname FW1

# 1. 接口 IP 配置
[FW1] interface GigabitEthernet 0/0/0
[FW1-GigabitEthernet0/0/0] ip address 10.1.1.2 24
[FW1-GigabitEthernet0/0/0] quit

[FW1] interface GigabitEthernet 1/0/0
[FW1-GigabitEthernet1/0/0] ip address 192.168.1.1 24
[FW1-GigabitEthernet1/0/0] quit

# 2. 加入安全区域
[FW1] firewall zone untrust
[FW1-zone-untrust] add interface GigabitEthernet 0/0/0
[FW1-zone-untrust] quit

[FW1] firewall zone trust
[FW1-zone-trust] add interface GigabitEthernet 1/0/0
[FW1-zone-trust] quit

# 3. 配置安全策略（允许VPN流量及本地交互）
[FW1] security-policy
[FW1-security-policy] rule name policy_sec_to_untrust
[FW1-security-policy-rule-1] source-zone trust
[FW1-security-policy-rule-1] destination-zone untrust
[FW1-security-policy-rule-1] action permit
[FW1-security-policy-rule-1] quit
[FW1-security-policy] rule name policy_untrust_to_trust
[FW1-security-policy-rule-2] source-zone untrust
[FW1-security-policy-rule-2] destination-zone trust
[FW1-security-policy-rule-2] action permit
[FW1-security-policy-rule-2] quit
[FW1-security-policy] rule name local_to_zone
[FW1-security-policy-rule-3] source-zone local
[FW1-security-policy-rule-3] destination-zone untrust
[FW1-security-policy-rule-3] action permit
[FW1-security-policy-rule-3] quit
[FW1-security-policy] rule name untrust_to_local
[FW1-security-policy-rule-4] source-zone untrust
[FW1-security-policy-rule-4] destination-zone local
[FW1-security-policy-rule-4] action permit
[FW1-security-policy-rule-4] quit
[FW1-security-policy] quit

# 4. 配置缺省路由指向公网路由器
[FW1] ip route-static 0.0.0.0 0.0.0.0 10.1.1.1

# 5. IPsec VPN 配置
# 定义感兴趣流（ACL）
[FW1] acl number 3000
[FW1-acl4-adv-3000] rule permit ip source 192.168.1.0 0.0.0.255 destination 192.168.2.0 0.0.0.255
[FW1-acl4-adv-3000] quit

#ike 安全提议
[FW1] ike proposal 1
[FW1-ike-proposal-1] encryption-algorithm aes-256
[FW1-ike-proposal-1] dh group 2
[FW1-ike-proposal-1] authentication-algorithm sha2-256
[FW1-ike-proposal-1] quit

#ike peer
[FW1] ike peer peer2
[FW1-ike-peer-peer2] phase-1-mode main
[FW1-ike-peer-peer2] ike-proposal 1
[FW1-ike-peer-peer2] remote-address 10.2.1.2
[FW1-ike-peer-peer2] pre-shared-key cipher Huawei@123
[FW1-ike-peer-peer2] quit

#ipsec 安全提议
[FW1] ipsec proposal 1
[FW1-ipsec-proposal-1] transform esp
[FW1-ipsec-proposal-1] esp encryption-algorithm aes-256
[FW1-ipsec-proposal-1] esp authentication-algorithm sha2-256
[FW1-ipsec-proposal-1] quit

#ipsec 安全策略
[FW1] ipsec policy p1 1 isakmp
[FW1-ipsec-policy-isakmp-p1-1] security acl 3000
[FW1-ipsec-policy-isakmp-p1-1] ike-peer peer2
[FW1-ipsec-policy-isakmp-p1-1] proposal 1
[FW1-ipsec-policy-isakmp-p1-1] quit

# 在外网接口应用 IPsec 策略
[FW1] interface GigabitEthernet 0/0/0
[FW1-GigabitEthernet0/0/0] ipsec policy p1
[FW1-GigabitEthernet0/0/0] quit

```

*Verification:* 在 FW1 上执行 `display ipsec sa`，检查安全联盟是否成功建立。
