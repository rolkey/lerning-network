# 特殊功能脚本

## 移动nat-policy策略顺序

- **原因**：先配置了通用策略nat_rule_general，后面配置了no-nat的策略no_nat_vpn

```bash
nat-policy
 rule name nat_rule_general
  source-zone trust
  destination-zone untrust
  action source-nat easy-ip
 rule name no_nat_vpn
  source-zone trust
  destination-zone untrust
  source-address 192.168.10.0 mask 255.255.255.0
  destination-address 192.168.20.0 mask 255.255.255.0
  action no-nat
```

- 配置方法

```bash
nat-policy
  rule move no_nat_vpn before nat_rule_general
```

- **结果**

```bash
nat-policy
 rule name no_nat_vpn
  source-zone trust
  destination-zone untrust
  source-address 192.168.10.0 mask 255.255.255.0
  destination-address 192.168.20.0 mask 255.255.255.0
  action no-nat
 rule name nat_rule_general
  source-zone trust
  destination-zone untrust
  action source-nat easy-ip
```

- **验证路径**

```bash
display firewall session table verbose source global 192.168.10.2
```

- **查询脚本汇总**

```bash
display ipsec policy brief
display ipsec proposal brief

```
