eNSP（Enterprise Network Simulation Platform，企业网络模拟平台）是华为官方推出的免费图形化网络仿真工具，用于模拟路由器、交换机、防火墙等真实网络设备，是学习华为网络技术和备考认证的核心工具。

### 🛠️ 安装要点（避坑指南）

eNSP本身只是一个“壳”，它的运行依赖三个必须提前装好的底层软件。安装时最容易出问题的就是版本兼容性。

**必须按以下顺序安装，且注意版本：**

1. **VirtualBox**：虚拟机软件，用于承载路由器的操作系统。**必须使用 5.2.x 版本**，这是 eNSP 官方兼容版本，装新版会导致设备无法启动。
2. **WinPcap**：提供底层网络抓包能力，**版本 4.1.3**，安装时保持默认即可。
3. **Wireshark**：报文分析软件。安装时**不要勾选**它自带的 Npcap 或 WinPcap 组件，避免与第2步冲突。
4. **eNSP**：最后安装，安装路径中**不要包含中文字符**，否则可能出现异常。

### 🖥️ 界面与核心操作流程

打开 eNSP，左侧是**设备区**（按路由器、交换机、终端等分类），中间是**工作台**，右侧是**接口状态区**。

一个标准实验的搭建流程如下：

**1. 拖拽设备**
从左侧设备区把需要的路由器、PC 拖到工作台。

**2. 连接线缆**
点击顶部工具栏的“设备连线”按钮（闪电图标），选择线缆类型。**Copper** 是双绞线（以太网），**Serial** 是串口线，**Auto** 会自动匹配接口。

**3. 启动设备**
框选所有设备，点击顶部绿色“启动”按钮。设备图标颜色变浅、连线红点变绿，表示启动完成。

**4. 进入命令行配置**
双击设备图标，弹出 CLI 命令行窗口，即进入华为 VRP 操作系统的配置界面。

### 💻 VRP 命令行基础（华为设备的“语言”）

华为设备使用 VRP（通用路由平台）操作系统，你与设备交互的方式就是敲命令。

**核心的四个视图：**

| 视图 | 提示符 | 作用 |
|---|---|---|
| **用户视图** | `<设备名>` | 查看状态，不能改配置 |
| **系统视图** | `[设备名]` | 配置全局参数（如改主机名） |
| **接口视图** | `[设备名-接口名]` | 配置具体接口（如 IP 地址） |
| **协议视图** | `[设备名-协议名]` | 配置路由协议（如 OSPF） |

**视图切换：**
- 用户视图输入 `system-view` 进入系统视图。
- 系统视图输入 `interface GigabitEthernet 0/0/0` 进入接口视图。
- 任何时候用 `quit` 退回上一级，用 `return` 或 `Ctrl+Z` 直接回到用户视图。

**两个必备的救命命令：**
- `?`：忘记命令怎么拼，敲 `?` 会列出当前可用的所有命令。
- `Tab`：敲命令前缀后按 Tab 键自动补全。

### 📦 抓包与查看

在设备启动状态下，**右键点击链路或接口**，选择“数据抓包”，即可自动调用 Wireshark 捕获流经该接口的报文。这是理解协议交互过程最直观的方式。

### ⚠️ 常见注意事项

- **内存占用**：每台虚拟设备都会消耗真实内存，拓扑设备多时建议**逐个启动**，避免电脑卡死。
- **Hyper-V 冲突**：Windows 的 Hyper-V 或 WSL2 功能可能与 VirtualBox 冲突，导致 eNSP 设备启动失败。如果遇到问题，需关闭 Hyper-V。
- **与真实环境的差距**：eNSP 跳过了真实插拔线缆、设备故障等环节，且部分高级特性与真实设备有差异。建议有条件时结合真机练习。
