国内网络设备市场主要由华为、新华三、锐捷等厂商主导，各家的命令集（操作系统）自成体系。核心结论是：**不存在统一的“国内命令集”**，配置时需严格区分厂商，尤其是华为与新华三这对“神似而细节不同”的体系。

### 国内主要厂家与对应命令集

以下是按产品线梳理的主要厂商及其使用的命令集/操作系统：

**路由器与交换机**
*   **华为**：使用 **VRP**（Versatile Routing Platform）。在企业路由器市场份额领先，交换机市场同样位居前列。关键命令特征如 `port default vlan`。
*   **新华三（H3C）**：使用 **Comware**。企业网交换机份额领先，路由器市场位居第二。命令与华为高度相似，但细节不同，如划VLAN用 `port access vlan`。
*   **锐捷（Ruijie）**：使用 **RGOS**。交换机市场排名第三，在互联网数据中心领域有优势。命令风格偏向思科，如 `switchport access vlan`，但基础视图命令又类似华为（如 `system-view`），属于混合风格。
*   **迈普（Maipu）**：使用 **MyPower**（自有网络操作系统）。在企业级路由器市场有一定份额。命令风格也偏向思科/锐捷体系，如 `switchport access vlan`。

**防火墙**
*   **华为**：防火墙同样运行于 **VRP** 体系（如 USG 系列）。在国内防火墙市场份额位居第一。
*   **新华三**：防火墙运行 **Comware** 体系（如 SecPath 系列）。官方提供完整的 Comware 命令参考。
*   **深信服（Sangfor）**：在下一代防火墙细分市场有较高份额。其具体命令集名称在公开资料中不如华为/华三明确，通常为自有体系。

### 总结与分类修正

基于以上信息，你原先的“思科系/华为系/华三系”分类可以进一步精确化：

1.  **华为与华三必须严格区分**：虽然都使用 `system-view` 进入配置，但**接口划VLAN是最高频的踩坑点**。华为是 `port default vlan`，华三是 `port access vlan`，混用会报错。
2.  **锐捷与迈普的“归属”**：它们的基本操作（如进入全局配置）带有华为风格的烙印（使用 `system-view`），但在接口、VLAN等具体业务命令上，又大量借鉴了思科的语法（如 `switchport`）。因此，简单把它们归为“思科系”不够准确，它们属于**混合风格的自有体系**。
3.  **防火墙通常随厂商体系**：主流厂商（华为、华三）的防火墙命令与其路由交换设备同属一个操作系统（VRP / Comware），学会一个方向，另一个方向的上手成本较低。
