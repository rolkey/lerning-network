在电力二次系统（如调度自动化、变电站自动化/IEC 61850 系统）中，**A平面与B平面**指的是两套在物理和逻辑上完全隔离的双冗余骨干通信网络。两平面采用“双轨并行、互为备用”的工作模式，确保单点甚至单侧网络瘫痪时，保护信号、遥测遥信及控制指令依然能无缝传输。

## 一、 A平面与B平面在故障时的处理流程

当电力网络系统中某一平面发生故障时，系统处理流程分为**故障检测、流量切换、告警与隔离、恢复与回切**四个阶段：

```
+-------------------+      +-------------------+      +-------------------+      +-------------------+
| 1. 故障检测       | ---> | 2. 冗余切换       | ---> | 3. 告警与隔离     | ---> | 4. 恢复与自愈     |
| 链路中断/丢包率高  |      | 报文自动走备用平面|      | 网管告警，物理隔离|      | 修复后恢复主备平衡|
+-------------------+      +-------------------+      +-------------------+      +-------------------+

```

### 1. 故障检测与感知（毫秒级）

终端设备（如保护装置、测控终端、IED）或网络设备通过以下机制实时监测网平面状态：

* **链路层检测**：通过 PHY 芯片检测光信号丢失（Loss of Signal, LOS）。
* **协议层心跳检测**：
* 使用 **BFD（双向转发检测）**，实现微秒~毫秒级（如 10ms–30ms）故障感知。
* 在 IEC 61850 PRP/HSR 协议下，终端设备接收端通过报文序列号检测是否丢失单侧报文。


* **业务层超时**：应用层通信协议（如 IEC 60870-5-104、DNP3）检测 TCP 协议栈超时。

### 2. 流量自动切换与冗余处置

故障被感知后，根据网络层冗余机制的不同，执行相应的切换逻辑：

* **双发选收（PRP/HSR 模式）**：
* **零切换时间（0 ms）**：终端设备同时向 A、B 平面发送相同的报文。正常时接收端丢弃后到达的重复报文；当 A 平面故障时，B 平面的报文早已到达，**无需任何切换过程，业务零中断**。


* **主备路由/生成树（RSTP/VRRP 模式）**：
* 当检测到 A 平面不可用时，协议控制平面更新转发表或将网关浮动至 B 平面，流量重定向至 B 平面（切换耗时通常在 20ms–50ms 内）。



### 3. 告警定位与故障隔离

* **告警上报**：网管系统（NMS）产生红警（如“A平面通信中断”），向调度员或运维人员提示故障位置（如具体交换机端口或光缆段）。
* **故障隔离**：网关或防火墙自动关闭故障端口，防止广播风暴或异常链路震荡（Flapping）影响 B 平面的正常运行。

### 4. 链路修复与自愈回切

* **状态恢复**：光纤修复或设备重启后，A 平面重新建立心跳与链路连接。
* **抑制回切震荡**：开启 Hold-off 定时器（通常等待 30s–60s 链路持续稳定），确认无误后再恢复 A 平面流量，或恢复双发并行状态。

## 二、 如何通过冗余保证数据传输

电力网络通过**物理层、网络协议层、终端业务层**的三维冗余设计，实现高可靠的数据传输。

```
                  +-----------------------------------+
                  |      业务终端 (如 IED / 保护)     |
                  +-----------------------------------+
                       /                         \
            [A网络接口]                             [B网络接口]
                /                                     \
    +-----------------------+             +-----------------------+
    |       A 平面网络      |             |       B 平面网络      |
    | (独立交换机/光缆/电源)|             | (独立交换机/光缆/电源)|
    +-----------------------+             +-----------------------+
                \                                     \
                 \------------------+------------------/
                                    |
                  +-----------------------------------+
                  |      对端终端 (双发选收/主备)     |
                  +-----------------------------------+

```

### 1. 物理层与硬件冗余（基础保障）

* **双网卡双上行（Dual-Homing）**：所有二次设备（保护、测控、调度主站）均配置独立的主卡与备卡（或独立光口），分别连接至 A 平面和 B 平面交换机。
* **完全物理隔离**：
* **独立设备与管道**：A、B 平面的网络交换机、光纤配线架（ODF）、传输光缆路径完全独立，甚至走不同的电缆沟或光缆路由。
* **独立供电**：A 平面设备接入站内直流Ⅰ段/所用电Ⅰ路，B 平面设备接入直流Ⅱ段/所用电Ⅱ路，防止单点电源故障失效。



### 2. 网络层与协议冗余（核心机制）

在电力系统中，冗余传输协议根据业务实时性要求（如 GOOSE/SV 组帧与 104 规约）分为以下几类：

#### ① PRP（并行冗余协议，IEC 62439-3 Clause 4）—— **无缝零切换**

* **原理**：发送端设备把原始数据包复制两份，分别加上包含序列号的 RCT（冗余控制尾部），同时在 A 平面和 B 平面发送；接收端收到第一份后立即交给上层处理，随后到达的第二份直接丢弃。
* **优势**：单平面发生任何故障，均**不会丢包，无恢复时间（0ms 冗余）**，常用于变电站过程层和间隔层网络（IEC 61850）。

#### ② HSR（高可用性串行冗余，IEC 62439-3 Clause 5）—— **环网结构冗余**

* **原理**：设备通过两个端口连成双向环网。报文加上 HSR 头部后同时向顺时针和逆时针两个方向发送。当环路任意一点断开，数据仍能通过另一侧通路送达。

#### ③ VRRP / BFD + 动态路由（OSPF/ISIS）—— **调度网/广域网冗余**

* **原理**：在电力调度数据网（如 Core/Aggregation 层）中，A、B 平面运行独立的路由拓扑。
* 当 A 平面链路中断时，BFD 快速感知，路由协议重新计算（或 VRRP 网关切换），引导数据包切换至 B 平面。

### 3. 应用层与数据同步冗余

* **双发双收/双发选收逻辑**：调度主站与厂站端（RTU/测控）建立两条独立的 104 通道（面向 A 平面与 B 平面）。
* **双发选收**：主站同时接收 A、B 通道数据，对数据包进行去重与校验。
* **主备切换**：正常时仅使用 A 通道，当 A 通道超时或报文错误率超过阈值时，自动平滑切至 B 通道。


* **数据防重与防乱序**：利用传输层 TCP 序号或应用层递增序号（如 104 规约的发送/接收序号），保证切换过程中不发生数据遗漏或重复触发（特别是控制指令/遥控）。

## 总结：电力网冗余保障架构

| 冗余维度 | 关键技术 / 机制 | 解决的问题 |
| --- | --- | --- |
| **物理冗余** | 独立光缆路由、双电源、独立交换机架构 | 消除单点物理损坏（断纤、设备烧毁、停电） |
| **协议冗余** | PRP（并行冗余）、HSR（无缝环网）、BFD+VRRP | 解决链路中断时的流量无缝重定向（毫秒级或 0ms） |
| **数据冗余** | 双发选收、应用层序列号去重与重传 | 保证控制指令与保护信号的准确性、抗丢包与防重发 |
