## 交换机

光开服务端还不够，SSH 比 Telnet 多一个**密钥对**的要求：

```
# 1. 开启 STelnet 服务端
stelnet server enable

# 2. 生成 RSA 密钥对（SSH 加密必需）
rsa local-key-pair create

# 3. VTY 放行 SSH 协议
user-interface vty 0 4
 authentication-mode aaa
 protocol inbound ssh
 quit

# 4. 配置 AAA 用户，服务类型要包含 ssh
aaa
 local-user sshuser password cipher 你的密码
 local-user sshuser privilege level 15
 local-user sshuser service-type ssh
 quit

# 5. 配置用户的 SSH 登录方式
ssh user sshuser authentication-type password
ssh user sshuser service-type stelnet

# 6. 在端口上开放服务
interface GigabitEthernet0/0/0
 undo shutdown
 service-manage ssh permit
```

## 防火墙

**第一步：在接口上放行 SSH 服务**

```bash
[USG6000V1] interface GigabitEthernet0/0/0
[USG6000V1-GigabitEthernet0/0/0] service-manage ssh permit
[USG6000V1-GigabitEthernet0/0/0] quit
```
*这一步非常关键，很多 SSH 连不上的问题都源于接口没有显式放行 SSH 服务。*

**第二步：启用 SSH 服务并生成密钥**

```bash
[USG6000V1] stelnet server enable
[USG6000V1] rsa local-key-pair create
```
*执行最后一条命令时，系统会提示你输入密钥长度（默认 2048 位），直接回车即可。如果设备已有密钥，可能会提示是否覆盖，选择 `y`。*

**第三步：创建本地管理员用户**

```bash
[USG6000V1] aaa
[USG6000V1-aaa] manager-user your_username
[USG6000V1-aaa-manager-user-your_username] password cipher your_password
[USG6000V1-aaa-manager-user-your_username] service-type ssh
[USG6000V1-aaa-manager-user-your_username] level 3
[USG6000V1-aaa-manager-user-your_username] quit
[USG6000V1-aaa] bind manager-user your_username role system-admin
[USG6000V1-aaa] quit
```
*这里创建了管理员账户并绑定了管理员角色，权限级别设为 3（配置级）通常足够日常管理。*

**第四步：配置 VTY 虚拟终端**

```bash
[USG6000V1] user-interface vty 0 4
[USG6000V1-ui-vty0-4] authentication-mode aaa
[USG6000V1-ui-vty0-4] protocol inbound ssh
[USG6000V1-ui-vty0-4] quit
```
*这步是告诉设备，远程登录必须通过 AAA 认证，且只接受 SSH 协议。*
