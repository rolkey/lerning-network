# sojson子网计算器各计算功能对应的网络计算规则（不含UI界面描述）
> 全部运算均在浏览器本地完成，仅支持IPv4，不支持IPv6；输入会做合法性校验，拒绝非连续1的非法掩码、超出0‑255的IP分段、格式错误字符串。

## 1、基础子网解析计算（核心主计算功能）
**输入源**：IP+点分十进制掩码 / IP+CIDR前缀（`x.x.x.x/n`）
**底层运算规则**
1. 将IPv4、子网掩码全部转为32位无符号整数；
2. **网络地址**：IP整数 `按位与` 掩码整数，将主机位全部清零，得到网段基准地址；
3. **广播地址**：网络地址整数 `按位或` 反掩码（掩码二进制全部按位取反），主机位全部置1；
4. **反掩码（通配符）**：子网掩码每8bit逐位取反；用于ACL、匹配规则；
5. **CIDR与掩码互转**：统计掩码二进制中连续前置1的位数得到CIDR前缀；由前缀生成连续1、后续补0的32位掩码，校验掩码必须是连续前置1，非连续直接判定输入非法；
6. **地址总量** = $2^{32\(2^{32‑前缀长度}\)}$；
7. **常规可用主机** = $2^{32\(2^{32‑前缀长度}\)}‑2$；扣除网络地址、广播地址两个保留地址；
8. 特殊边界处理：
    - /32：主机位0，总地址1，可用主机1，不生成网络、广播地址，代表单主机路由；
    - /31：遵循RFC3021，点对点链路可用2个地址，普通局域网场景不适用该规则；
9. **可用IP区间**：起始=网络地址+1；结束=广播地址‑1；
10. 输出IP地址分类（A/B/C类）：根据IP首字节判断传统有类网络。

## 2、网段划分（子网分割/Subnet拆分）功能
**输入源**：父网段（IP/CIDR）+目标子网段前缀
**运算规则**
1. 校验目标子前缀必须大于父网段前缀（子网络位更多，子网更小）；否则参数非法；
2. 计算每个子网段的块大小：$2^{32\(2^{32‑子前缀}\)}$；
3. 以父网段网络地址作为起始，按块大小步进循环生成每一个子网段网络地址；
4. 对每一个生成的子网段，复用上面基础子网算法，计算各自广播、可用IP范围；
5. 所有子网段严格对齐子网块边界，不允许跨边界碎片化网段；输出全部完整子网段列表，不会输出部分截断网段。

## 3、网段聚合（超网Supernet，多个小网段合并）功能
**输入源**：多条子网CIDR列表
**运算规则**
1. 输入网段必须是连续、数量为2的整数次幂，否则无法无损聚合；
2. 寻找所有输入网段共同最长前缀，将前缀位数减少N位（N=log₂网段数量）得到聚合后超网前缀；
3. 聚合后的超网网络地址，必须对齐新前缀对应的地址块边界；
4. 聚合完成后输出超网CIDR，同时校验：聚合后的范围必须刚好完整包含全部输入子网，不能包含输入以外的额外网段，不满足则判定无法聚合。

## 4、判断IP是否属于指定网段功能
**输入源**：待测IP + 目标网段（IP/CIDR）
**运算规则**
1. 使用目标网段掩码对待测IP做按位与运算，得到待测IP对应的网络地址；
2. 将结果和目标网段的标准网络地址做整数比对；
3. 两者完全相等：IP属于该网段；不相等：不属于该网段。

## 5、掩码与CIDR互相转换独立计算
**输入源**：子网掩码（点分十进制）或者CIDR前缀
- 掩码→CIDR：解析掩码32位二进制，统计前置连续1；若1出现中断，判定掩码非法；
- CIDR→掩码：生成32位二进制，前N位为1，剩余位0，转为点分十进制。

## 6、二进制展开转换
**输入源**：IP或者掩码
运算规则：把4段十进制分别转为8位二进制，补齐8位前导零，拼接完整32位二进制串，用于校验位运算。

## 输入校验统一规则（所有计算功能共用）
1. IPv4四组十进制数值范围0‑255；出现大于255、负数、非数字字符直接报错；
2. 子网掩码二进制必须为左侧全部连续1，右侧全部连续0，不满足判定非法掩码；
3. CIDR前缀合法取值范围0‑32，超出直接拒绝计算；
4. 所有网段网络地址强制对齐地址块边界；输入IP落在网段中间，工具自动归一化到该IP归属的网段网络地址。

## 工具不具备的计算逻辑
1. 不支持VLSM不等长子网自动规划，需要手动多次调用网段划分；
2. 不支持IPv6整套子网运算；
3. 不做网关、路由可达性、真实网络连通性检测，仅纯数学位运算。
