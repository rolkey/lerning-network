下面这套伪代码，对应前面 sojson 子网计算器的核心逻辑（IPv4，纯位运算，不含界面、输入校验UI，只保留计算逻辑）。
> 约定：
> - ip_int、mask_int、wildcard_int：32位无符号整数
> - 函数 `ipv4_to_int(a,b,c,d)`：`a<<24 | b<<16 | c<<8 | d`
> - 函数 `int_to_ipv4(n)`：拆成 4 字节 `(n>>24)&0xFF`、`(n>>16)&0xFF`、`(n>>8)&0xFF`、`n&0xFF`
> - 所有输入提前校验：0~255、掩码是连续1、cidr ∈ [0,32]

## 1. CIDR ↔ 掩码转换
```plaintext
# cidr 转 mask_int
FUNCTION cidr_to_mask(cidr):
    IF cidr == 0:
        RETURN 0
    IF cidr == 32:
        RETURN 0xFFFFFFFF
    shift = 32 - cidr
    mask_int = (0xFFFFFFFF << shift) & 0xFFFFFFFF
    RETURN mask_int

# mask_int 转 cidr
FUNCTION mask_to_cidr(mask_int):
    cidr = 0
    temp = mask_int
    WHILE (temp & 0x80000000) != 0:
        cidr = cidr + 1
        temp = (temp << 1) & 0xFFFFFFFF
    # 校验：后面必须全0，否则非法掩码
    IF temp != 0:
        RETURN ERROR "非法掩码，非连续1"
    RETURN cidr
```

## 2. 基础子网解析（IP + mask_int / cidr）
```plaintext
FUNCTION subnet_calc(ip_int, mask_int):
    # 网络地址：IP & mask
    net_int = ip_int & mask_int
    # 反掩码（通配符）：~mask，32位截断
    wildcard_int = (~mask_int) & 0xFFFFFFFF
    # 广播地址：net | wildcard
    broadcast_int = net_int | wildcard_int

    host_bits = 32 - mask_to_cidr(mask_int)
    total_addr = 2 ^ host_bits

    IF host_bits == 0:
        # /32，单主机路由
        usable_start = NULL
        usable_end = NULL
        usable_count = 1
    ELSE IF host_bits == 1:
        # /31 RFC3021
        usable_start = net_int
        usable_end = broadcast_int
        usable_count = 2
    ELSE:
        usable_start = net_int + 1
        usable_end = broadcast_int - 1
        usable_count = total_addr - 2

    RETURN {
        net_int: net_int,
        broadcast_int: broadcast_int,
        wildcard_int: wildcard_int,
        usable_start: usable_start,
        usable_end: usable_end,
        usable_count: usable_count,
        total_addr: total_addr
    }
```

## 3. 判断IP是否在网段内
```plaintext
FUNCTION ip_in_subnet(ip_int, net_int, mask_int):
    ip_net = ip_int & mask_int
    RETURN ip_net == net_int
```

## 4. 子网划分（父网段切分成更小的子网）
```plaintext
FUNCTION split_subnet(parent_net_int, parent_cidr, child_cidr):
    result_list = []
    IF child_cidr <= parent_cidr:
        RETURN ERROR "子前缀必须大于父前缀"

    child_mask = cidr_to_mask(child_cidr)
    host_bits_child = 32 - child_cidr
    block_size = 2 ^ host_bits_child

    current_net = parent_net_int
    parent_wildcard = (~cidr_to_mask(parent_cidr)) & 0xFFFFFFFF
    parent_broadcast = parent_net_int | parent_wildcard

    WHILE current_net <= parent_broadcast:
        sub = subnet_calc(current_net, child_mask)
        ADD sub TO result_list
        current_net = current_net + block_size

    RETURN result_list
```

## 5. 网段聚合（超网聚合，简单版本）
> 限制：只支持聚合**连续、数量是2的幂、对齐边界**的同前缀子网
```plaintext
FUNCTION aggregate_subnet(net_list):
    # net_list: [ {net_int, cidr}, ... ]
    count = LENGTH(net_list)
    IF count NOT IN {1,2,4,8,16,32...}:
        RETURN ERROR "网段数量不是2的幂，无法聚合"

    # 找最小网络地址
    min_net = MIN( item.net_int FOR item IN net_list )
    # 原始前缀
    base_cidr = net_list[0].cidr
    shift = LOG2(count)
    new_cidr = base_cidr - shift

    new_mask = cidr_to_mask(new_cidr)
    agg_net = min_net & new_mask

    # 校验：聚合后的网段必须刚好包住所有输入子网
    agg_wildcard = (~new_mask) & 0xFFFFFFFF
    agg_broadcast = agg_net | agg_wildcard
    FOR item IN net_list:
        IF item.net_int < agg_net OR item.net_int > agg_broadcast:
            RETURN ERROR "无法聚合，超出范围"

    RETURN {
        agg_net_int: agg_net,
        agg_cidr: new_cidr
    }
```

## 6. IPv4 字符串 <=> int 转换辅助函数
```plaintext
FUNCTION str_ip_to_int(ip_str):
    arr = split(ip_str, ".")
    a = INT(arr[0]), b = INT(arr[1]), c = INT(arr[2]), d = INT(arr[3])
    RETURN (a << 24) | (b << 16) | (c << 8) | d

FUNCTION int_to_str_ip(n):
    a = (n >> 24) & 0xFF
    b = (n >> 16) & 0xFF
    c = (n >> 8) & 0xFF
    d = n & 0xFF
    RETURN CONCAT(a,".",b,".",c,".",d)
```
