主存容量为 16 MB，按字节编址，表示地址至少需要 **24 位**。

计算方法：

1. **明确单位换算**  
   16 MB = 16 × 1024 × 1024 字节  
   因为 1 MB = 2²⁰ 字节，所以：  
   16 MB = 2⁴ × 2²⁰ 字节 = 2²⁴ 字节

2. **按字节编址的含义**  
   按字节编址表示每一个字节都有一个独立地址。  
   因此，地址总数 = 字节总数 = 2²⁴ 个。

3. **计算地址位数**  
   若有 N 个地址，需要 n 位地址线，则满足：  
   2ⁿ = N  
   所以：  
   2ⁿ = 2²⁴  
   n = 24

因此，表示该主存地址至少需要 **24 位二进制数**。

也可以简单记为：

\[
\log_2(16 \times 1024 \times 1024)=\log_2(2^{24})=24
\]

所以答案是：**24 位**。
