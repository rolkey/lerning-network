### ping之后，output不增加的？

- 现象

```text
[FW1]display interface GigabitEthernet 1/0/1 | include packets
2026-10-10 04:34:22.380 
Last 300 seconds input rate 71  bytes/sec, 0  packets/sec
Last 300 seconds output rate 0  bytes/sec, 0  packets/sec
    Input: 441 packets, 71885 bytes
    Output: 19 packets, 2090 bytes
[FW1]ping 100.1.1.1
  PING 100.1.1.1: 56  data bytes, press CTRL_C to break
    Reply from 100.1.1.1: bytes=56 Sequence=1 ttl=255 time=15 ms

    5 packet(s) transmitted
    5 packet(s) received

[FW1]display interface GigabitEthernet 1/0/1 | include packets
2026-10-10 04:34:41.080 
Last 300 seconds input rate 71  bytes/sec, 0  packets/sec
Last 300 seconds output rate 0  bytes/sec, 0  packets/sec
    Input: 450 packets, 73518 bytes
    Output: 19 packets, 2090 bytes
```

- 解释

```text
因为你的 ping 流量根本不从这个接口出去。

你观察到的现象是：

在 GigabitEthernet 1/0/1 上执行 ping 100.1.1.1

ping 能通，5 发 5 收

但该接口 Output 计数几乎不变（19 packets 没动）

Input 反而增加了 9 个包（450 - 441）

这说明：ping 的请求报文不是从 GE1/0/1 发出去的，但回复报文可能从 GE1/0/1 进来了，或者反过来，取决于你的设备和路由。
```
