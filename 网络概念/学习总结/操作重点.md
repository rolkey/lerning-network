# 配置网络操作重点

## 二层交换机

- 配置VLAN

  - 创建VLAN

    - `vlan 10`
    - `vlan batch 10 20`

  - 将端口加入VLAN

    - `interface FastEthernet0/1`
    - `switchport mode access`
    - `switchport access vlan 10`

  - 配置Trunk
  - 配置Hybrid

## 三层交换机

- 配置VLAN
- 配置Trunk
- 配置Hybrid
- 配置路由
- 配置DHCP
- 配置NAT

## 路由器

- 配置VLAN
- 配置Trunk
- 配置Hybrid
- 配置路由

## 防火墙
