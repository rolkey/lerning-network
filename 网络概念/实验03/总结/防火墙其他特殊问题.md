## 安全域

- 可以创建新的zone吗？如何创建

```bash
# 进入系统视图
system-view

# 创建新的zone并设置安全优先级（优先级范围通常为1~100，不可与默认zone冲突）
firewall zone name zone_name
 set priority 10

# 将接口加入该zone
 add interface GigabitEthernet 0/0/1

# 查看所有zone的信息
display firewall zone

# 查看特定zone的详细信息
display firewall zone name zone_name

# 删除自定义zone（需先在系统视图下执行，且zone内不能有接口）
undo firewall zone name zone_name
```

## Nat转发地址池

- 一个地址池可以创建多个session吗？如何创建

```bash
# 进入系统视图
system-view

# 创建NAT地址池并进入地址池视图
nat address-group addresspool_name group-id 1

# 方式1：配置连续的IP地址段
 section 0 202.1.1.10 202.1.1.20

# 方式2：在同一地址池中继续添加另一段IP（实现多个IP/段共存）
 section 1 202.1.2.50 202.1.2.60

# 查看NAT地址池配置
display nat address-group

# 删除NAT地址池
undo nat address-group addresspool_name
```
