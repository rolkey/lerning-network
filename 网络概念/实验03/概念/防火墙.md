在 eNSP 中配置防火墙，核心思路是：先让防火墙“能通信”，再通过安全策略精细控制“谁能访问谁”。配置流程通常分为基础网络设置、接口划入安全区域、配置安全策略三步。

### 🛠️ 基础网络配置（让接口和路由工作）

先把接口的 IP 地址配好，这是通信的基础。

```bash
<USG6000V> system-view
[USG6000V] interface GigabitEthernet 1/0/0
[USG6000V-GigabitEthernet1/0/0] ip address 192.168.1.1 24
[USG6000V-GigabitEthernet1/0/0] quit
[USG6000V] interface GigabitEthernet 1/0/1
[USG6000V-GigabitEthernet1/0/1] ip address 2.2.2.1 24
[USG6000V-GigabitEthernet1/0/1] quit
```

如果拓扑里有跨网段通信的需求，还需要配路由，比如 `ip route-static`。

### 📋 把接口放进安全区域

防火墙靠“区域”来管理安全级别。通常把内网口划到 **trust**（高信任），外网口划到 **untrust**（低信任）。

```bash
[USG6000V] firewall zone trust
[USG6000V-zone-trust] add interface GigabitEthernet 1/0/0
[USG6000V-zone-trust] quit
[USG6000V] firewall zone untrust
[USG6000V-zone-untrust] add interface GigabitEthernet 1/0/1
[USG6000V-zone-untrust] quit
```

### 🛡️ 配置安全策略（放行流量）

防火墙默认拒绝所有跨区域的流量，必须手动配置策略放行 。比如允许内网用户访问外网：

```bash
[USG6000V] security-policy
[USG6000V-policy-security] rule name trust_to_untrust
[USG6000V-policy-security-rule-trust_to_untrust] source-zone trust
[USG6000V-policy-security-rule-trust_to_untrust] destination-zone untrust
[USG6000V-policy-security-rule-trust_to_untrust] action permit
[USG6000V-policy-security-rule-trust_to_untrust] quit
[USG6000V-policy-security] quit
```

如果需要做 NAT（让内网访问互联网），还得配上 **NAT 策略**和**地址池**：
```bash
[USG6000V] nat address-group 1
[USG6000V-address-group-1] section 2.2.2.10 2.2.2.20
[USG6000V-address-group-1] quit
[USG6000V] nat-policy
[USG6000V-policy-nat] rule name snat
[USG6000V-policy-nat-rule-snat] source-zone trust
[USG6000V-policy-nat-rule-snat] destination-zone untrust
[USG6000V-policy-nat-rule-snat] action source-nat address-group 1
```

### 🔍 验证与排错

配置完保存后，可以试试从内网 PC ping 外网地址。如果不通，按顺序排查：
1.  **接口状态**：`display ip interface brief` 看接口是不是 `Up`。
2.  **路由表**：`display ip routing-table` 看有没有去往目标网段的路由。
3.  **会话表**：`display firewall session table` 能直观看到流量有没有被防火墙放行 。
4.  **策略匹配**：检查安全策略的方向（源/目的区域）和动作是不是写反或漏配了。
