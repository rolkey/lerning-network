## 一、VLAN（Access / Trunk / Hybrid）

### 练习目标

掌握基于端口的 VLAN 划分；理解 Access 接口的收发规则；掌握 Trunk 接口如何通过 `allow-pass` 控制放行 VLAN；理解 Hybrid 接口的 `tagged/untagged` 差异及适用场景（如 IP 电话、服务器多 VLAN 共存）。

### 参考脚本

**交换机 SW1（Access + Trunk 核心配置）**

```
system-view
sysname SW1
undo info-center enable
vlan batch 10 20 30

# 连接终端：Access 模式
interface GigabitEthernet0/0/1
 port link-type access
 port default vlan 10

interface GigabitEthernet0/0/2
 port link-type access
 port default vlan 20

# 连接另一台交换机：Trunk 模式
interface GigabitEthernet0/0/24
 port link-type trunk
 port trunk allow-pass vlan 10 20 30
```

**Hybrid 接口示例（连接 IP 电话 / 服务器双 VLAN 场景）**

```
interface GigabitEthernet0/0/3
 port link-type hybrid
 port hybrid pvid vlan 30
 port hybrid untagged vlan 30
 port hybrid tagged vlan 10 20
```

> Hybrid 的关键区别：`pvid` 决定入口无标签流量的归属；`untagged` 表示出接口时剥离标签；`tagged` 表示出接口时保留标签 。

## 二、SSH / Telnet / HTTP 登录

### 练习目标

配置本地用户和 VTY 终端；开启 Telnet 和 SSH 服务；在路由器或三层交换机上启用 HTTP 服务，实现 Web 登录管理。SSH 需生成 RSA 密钥对 。

### 参考脚本

```
system-view
sysname R1
undo info-center enable

# 配置三层接口 IP（用作管理地址）
interface GigabitEthernet0/0/0
 ip address 192.168.1.1 24
 quit

# 创建本地用户，支持 telnet / ssh / http
aaa
 local-user admin password cipher Huawei@123
 local-user admin privilege level 15
 local-user admin service-type telnet ssh http
 quit

# 开启 Telnet 服务（默认开启，确认即可）
telnet server enable

# 生成 RSA 密钥并开启 SSH
rsa local-key-pair create
stelnet server enable
ssh user admin authentication-type password
ssh user admin service-type stelnet

# VTY 使用 aaa 认证，允许 telnet 和 ssh
user-interface vty 0 4
 authentication-mode aaa
 protocol inbound all
 quit

# 开启 HTTP 服务
http server enable
http server port 80
```

验证方式：用 eNSP 中的 PC 通过 Cloud 桥接到虚拟机，或直接用 `telnet`/`stelnet` 命令测试 。

## 三、路由（静态路由、默认路由）

### 练习目标

理解直连路由、静态路由、默认路由的区别；掌握 `ip route-static` 的语法；在边缘路由器上配置默认路由指向核心方向，在核心路由器上配置明细静态路由 。

### 参考脚本

**拓扑假设**：PC1 — R1 — R2 — PC2

**R1（边缘，配置默认路由）**

```
system-view
sysname R1
undo info-center enable

interface GigabitEthernet0/0/0
 ip address 192.168.1.1 24
interface GigabitEthernet0/0/1
 ip address 10.0.12.1 24

# 默认路由：所有未知流量交给 R2
ip route-static 0.0.0.0 0.0.0.0 10.0.12.2
```

**R2（核心，配置指向 PC1 网段的静态路由）**

```
system-view
sysname R2
undo info-center enable

interface GigabitEthernet0/0/0
 ip address 10.0.12.2 24
interface GigabitEthernet0/0/1
 ip address 192.168.2.1 24

# 回程静态路由
ip route-static 192.168.1.0 255.255.255.0 10.0.12.1
```

验证：PC1 ping PC2，抓包观察 R1 使用默认路由转发。

## 四、NAT 地址转换

### 练习目标

掌握 Easy IP（出接口方式）和 NAT 地址池方式的配置；通过 ACL 匹配需要转换的内网流量；验证内网主机访问外网时源 IP 被转换 。

### 参考脚本

**Easy IP（NAPT，最常用）**

```
system-view
sysname R1
undo info-center enable

# 内网接口
interface GigabitEthernet0/0/1
 ip address 192.168.10.1 24
# 公网接口（连接 Cloud / 外网）
interface GigabitEthernet0/0/0
 ip address 200.1.1.1 24

# ACL 匹配内网需要 NAT 的流量
acl number 2000
 rule 5 permit source 192.168.10.0 0.0.0.255
 quit

# 在公网接口上配置 Easy IP
interface GigabitEthernet0/0/0
 nat outbound 2000
 quit
```

**NAT 地址池方式**

```
# 定义公网地址池
nat address-group 1 200.1.1.10 200.1.1.20

# 在公网接口上引用地址池
interface GigabitEthernet0/0/0
 nat outbound 2000 address-group 1
 quit
```

验证：内网 PC ping 外网地址，在 R1 上抓包观察源地址是否变为公网 IP 。

## 五、防火墙安全基础与安全策略

### 练习目标

熟悉 eNSP 中 USG6000V 防火墙的基本操作；将接口加入安全区域（trust / untrust / dmz）；配置安全策略实现区域间流量的精细化控制（如仅允许某网段访问 Web 服务，禁止 Ping 等）。

### 参考脚本

> eNSP 中防火墙首次启动需加载设备包，默认账号 `admin`，密码 `Admin@123` 。

**基础配置：接口 IP + 安全区域**

```
system-view
undo info-center enable

interface GigabitEthernet0/0/1
 ip address 192.168.1.254 24
interface GigabitEthernet0/0/2
 ip address 200.1.1.1 24

# 将接口加入安全区域
firewall zone trust
 add interface GigabitEthernet0/0/1
firewall zone untrust
 add interface GigabitEthernet0/0/2
```

**安全策略：放行 trust → untrust 的 HTTP，禁止其他**

```
security-policy
 rule name allow_http
  source-zone trust
  destination-zone untrust
  destination-address 172.16.1.10 32
  service http
  action permit
 rule name deny_all
  source-zone trust
  destination-zone untrust
  action deny
```

**NAT 与安全策略的配合**

在防火墙场景中，NAT 策略和安全策略是分开配置的。源 NAT 使用 `nat-policy`，安全策略使用 `security-policy` 。

```
nat-policy
 rule name snat
  source-zone trust
  destination-zone untrust
  source-address 192.168.1.0 mask 255.255.255.0
  action source-nat easy-ip
```

验证：trust 区域 PC 可以访问 untrust 区域指定的 Web 服务器，但 Ping 不通，说明安全策略生效 。
