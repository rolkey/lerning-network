三个概念：

| 名称 | 对应配置 | 物理/逻辑形态 |
|---|---|---|
| **COM 口 / Console 口** | `user-interface console 0` | 交换机面板上的**物理串口**，用 Console 线直连 |
| **维护口 / 管理口** | 通常是 `MEth0/0/0` 或 `Vlanif` 接口 | 交换机上的**网络管理接口**，有 IP 地址 |
| **Telnet / SSH 登录** | `user-interface vty 0 4` | **虚拟终端线路**，走网络访问上面的管理 IP |

### 关键点

- **`console 0`** 里的 "console" 就是“控制台”的意思，专指那个**物理串口**。它只有一条，编号固定为 0。
- **维护口**是网络侧的接口，比如华为交换机常见的 `MEth0/0/0`（Management Ethernet）或某个 `Vlanif` 接口。你给它配了 IP，才能被 Telnet/SSH 访问。
- **VTY** 才是 Telnet/SSH 登录时真正对应的用户界面线路，它绑定的是“通过网络进来的远程会话”，而不是某个物理口。

### 所以对应关系是：

```
COM 口（物理串口）      → user-interface console 0
维护口（管理 IP 网络口） → 被 Telnet/SSH 访问
Telnet/SSH 登录本身      → user-interface vty 0 4
```

**一句话：`console 0` = COM 口；维护口是那个有 IP 的管理接口；Telnet 登录走的是 VTY，不是 console 0。**
