## 一、实验目标回顾

在 eNSP 上搭建三台路由器的 MPLS 基础环境，实现：

1. **底层 IP 可达**：OSPF 打通，R1 能 ping 通 R3 的 Loopback0。
2. **MPLS/LDP 启用**：互联接口上启用 MPLS 和 LDP。
3. **LSP 建立**：R1 到 R3 的 Loopback0 有标签交换路径，`ping lsp` 成功。

你现在已经全部完成。

## 二、拓扑与地址规划

```text
R1(1.1.1.1) --- 10.0.12.0/24 --- R2(2.2.2.2) --- 10.0.23.0/24 --- R3(3.3.3.3)
```

| 设备 | Loopback0 | 互联接口 | 地址 |
|---|---|---|---|
| R1 | 1.1.1.1/32 | GE0/0/0 | 10.0.12.1/24 |
| R2 | 2.2.2.2/32 | GE0/0/0 | 10.0.12.2/24 |
| R2 | — | GE0/0/1 | 10.0.23.2/24 |
| R3 | 3.3.3.3/32 | GE0/0/0 | 10.0.23.3/24 |

**规划原则：**
- Loopback0 全网唯一，用 32 位掩码。
- 互联链路用 `10.0.12.0/24`（R1-R2）和 `10.0.23.0/24`（R2-R3），网段名体现两端设备编号。
- LSR-ID 与 Loopback0 一致，便于管理。

## 三、配置详细步骤

### 第 1 步：配置接口 IP 与 Loopback0

**R1：**
```text
[R1] interface GigabitEthernet0/0/0
[R1-GigabitEthernet0/0/0] ip address 10.0.12.1 255.255.255.0
[R1-GigabitEthernet0/0/0] quit
[R1] interface LoopBack0
[R1-LoopBack0] ip address 1.1.1.1 255.255.255.255
[R1-LoopBack0] quit
```

**R2：**
```text
[R2] interface GigabitEthernet0/0/0
[R2-GigabitEthernet0/0/0] ip address 10.0.12.2 255.255.255.0
[R2-GigabitEthernet0/0/0] quit
[R2] interface GigabitEthernet0/0/1
[R2-GigabitEthernet0/0/1] ip address 10.0.23.2 255.255.255.0
[R2-GigabitEthernet0/0/1] quit
[R2] interface LoopBack0
[R2-LoopBack0] ip address 2.2.2.2 255.255.255.255
[R2-LoopBack0] quit
```

**R3：**
```text
[R3] interface GigabitEthernet0/0/0
[R3-GigabitEthernet0/0/0] ip address 10.0.23.3 255.255.255.0
[R3-GigabitEthernet0/0/0] quit
[R3] interface LoopBack0
[R3-LoopBack0] ip address 3.3.3.3 255.255.255.255
[R3-LoopBack0] quit
```

---

### 第 2 步：配置 OSPF

每台路由器只宣告**自己直连的网段**。

**R1：**
```text
[R1] ospf 1 router-id 1.1.1.1
[R1-ospf-1] area 0
[R1-ospf-1-area-0.0.0.0] network 1.1.1.1 0.0.0.0
[R1-ospf-1-area-0.0.0.0] network 10.0.12.0 0.0.0.255
[R1-ospf-1-area-0.0.0.0] quit
[R1-ospf-1] quit
```

**R2：**
```text
[R2] ospf 1 router-id 2.2.2.2
[R2-ospf-1] area 0
[R2-ospf-1-area-0.0.0.0] network 2.2.2.2 0.0.0.0
[R2-ospf-1-area-0.0.0.0] network 10.0.12.0 0.0.0.255
[R2-ospf-1-area-0.0.0.0] network 10.0.23.0 0.0.0.255
[R2-ospf-1-area-0.0.0.0] quit
[R2-ospf-1] quit
```

**R3：**
```text
[R3] ospf 1 router-id 3.3.3.3
[R3-ospf-1] area 0
[R3-ospf-1-area-0.0.0.0] network 3.3.3.3 0.0.0.0
[R3-ospf-1-area-0.0.0.0] network 10.0.23.0 0.0.0.255
[R3-ospf-1-area-0.0.0.0] quit
[R3-ospf-1] quit
```

**验证底层 IP：**
```text
<R1> ping 3.3.3.3
```
能通即进入下一步。

---

### 第 3 步：全局启用 MPLS 与 LDP

**R1：**
```text
[R1] mpls lsr-id 1.1.1.1
[R1] mpls
[R1] mpls ldp
```

**R2：**
```text
[R2] mpls lsr-id 2.2.2.2
[R2] mpls
[R2] mpls ldp
```

**R3：**
```text
[R3] mpls lsr-id 3.3.3.3
[R3] mpls
[R3] mpls ldp
```

**注意：**
- `mpls lsr-id` 必须手动指定，且全网唯一，通常用 Loopback0 地址。
- 三条命令的顺序：先 `mpls lsr-id`，再 `mpls`，最后 `mpls ldp`。

---

### 第 4 步：在互联接口上启用 MPLS 与 LDP

**R1（GE0/0/0）：**
```text
[R1] interface GigabitEthernet0/0/0
[R1-GigabitEthernet0/0/0] mpls
[R1-GigabitEthernet0/0/0] mpls ldp
[R1-GigabitEthernet0/0/0] quit
```

**R2（GE0/0/0 和 GE0/0/1 都要配）：**
```text
[R2] interface GigabitEthernet0/0/0
[R2-GigabitEthernet0/0/0] mpls
[R2-GigabitEthernet0/0/0] mpls ldp
[R2-GigabitEthernet0/0/0] quit
[R2] interface GigabitEthernet0/0/1
[R2-GigabitEthernet0/0/1] mpls
[R2-GigabitEthernet0/0/1] mpls ldp
[R2-GigabitEthernet0/0/1] quit
```

**R3（GE0/0/0）：**
```text
[R3] interface GigabitEthernet0/0/0
[R3-GigabitEthernet0/0/0] mpls
[R3-GigabitEthernet0/0/0] mpls ldp
[R3-GigabitEthernet0/0/0] quit
```

**注意：**
- 只对**参与 MPLS 转发的互联接口**启用，Loopback 和连接 PC 的接口不需要。
- `mpls` 和 `mpls ldp` 两条都要配，缺一不可。

---

## 四、验证步骤（按顺序）

### 1. 检查 LDP 会话

```text
<R1> display mpls ldp session
```

**看点**：`Status` 为 `Operational` 表示会话建立成功。

### 2. 检查 LSP 是否生成

```text
<R1> display mpls lsp
```

**看点**：在 `LDP LSP` 区域中，找到 `FEC` 为 `3.3.3.3/32` 的条目，`In/Out Label` 不是 `NULL/NULL`。

### 3. 用 MPLS Ping 验证

```text
<R1> ping lsp ip 3.3.3.3 32
```

**看点**：收到回复，丢包率 0%。你已经验证成功。

### 4. 抓包看标签（可选）

在 R1 的 GE0/0/0 接口右键抓包，执行 `ping lsp`，在 Wireshark 中应能看到 MPLS 标签头。

---

## 五、常见排错

| 现象 | 可能原因 | 排查命令 |
|---|---|---|
| LDP 会话不 `Operational` | 接口未启用 LDP、LSR-ID 冲突、IP 不通 | `display mpls ldp peer` |
| LSP 不生成 | LDP 会话未建立、Loopback 未宣告进 OSPF | `display mpls lsp` |
| `ping lsp` 报 LSP 不存在 | LSP 未生成 | `display mpls lsp` |
| `ping lsp` 语法报错 | 命令格式错误 | 华为用 `ping lsp ip`，不是 `ping mpls ipv4` |

## 六、命令速查表

| 操作 | 命令 |
|---|---|
| 全局启用 MPLS | `mpls lsr-id X.X.X.X` → `mpls` → `mpls ldp` |
| 接口启用 MPLS | `mpls` → `mpls ldp` |
| 查看 LDP 会话 | `display mpls ldp session` |
| 查看 LDP 邻居 | `display mpls ldp peer` |
| 查看 LSP | `display mpls lsp` |
| 查看接口 MPLS 状态 | `display mpls interface` |
| MPLS Ping | `ping lsp ip 3.3.3.3 32` |
| MPLS Tracert | `tracert lsp ip 3.3.3.3 32` |

## 七、一句话总结

整个实验分三步：**OSPF 打通底层 IP → 全局和接口启用 MPLS/LDP → 验证 LSP 生成**。你现在 `ping lsp` 成功，说明 MPLS 标签转发路径已经完整建立，实验目标达成。
