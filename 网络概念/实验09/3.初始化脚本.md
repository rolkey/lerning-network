## 二、 宿主机（Windows）环境准备（**关键步骤**）

跨平台桥接的成败完全取决于宿主机的虚拟网卡配置。

1. **准备 3 块虚拟网卡**：在 Windows 中准备 3 块 `VirtualBox Host-Only Network`（如 #2, #3, #4）。
2. **配置“激活 IP”**：**必须**为这 3 块网卡配置 IP，否则底层驱动不转发数据。
   * **VirtualBox #2** (用于 B面上行)：`192.168.251.1 / 255.255.255.0` (网关留空)
   * **VirtualBox #3** (用于 心跳链路)：`192.168.250.1 / 255.255.255.0` (网关留空)
   * **VirtualBox #4** (用于 PC双上联)：`192.168.252.1 / 255.255.255.0` (网关留空)
   * *注意：千万不要配成模拟器内部的 10.x 或 192.168.10.x 网段。*
3. **关闭外部干扰**：**强烈建议关闭电脑的 Wi-Fi 和物理有线网卡**，防止真实网络中的设备（如幽灵 IP 172.16.0.1）抢占流量。
4. **以管理员身份运行**：务必右键 eNSP 和 HCL，选择**“以管理员身份运行”**。

## 三、 eNSP 侧设备配置

### 1. Cloud 配置
*   **Cloud 1**：绑定 `VirtualBox #2`，增加端口映射（1 ↔ 2，勾选双向）。
*   **Cloud 2**：绑定 `VirtualBox #3`，增加端口映射（1 ↔ 2，勾选双向）。
*   **Cloud 3**：绑定 `VirtualBox #4`，增加端口映射（1 ↔ 2，勾选双向）。

### 2. SW_A (S5700)
```text
<Huawei> system-view
[Huawei] sysname SW_A
[SW_A] vlan batch 10 100 200

# 1. 业务网关配置
[SW_A] interface Vlanif 10
[SW_A-Vlanif10] ip address 192.168.10.2 24
[SW_A-Vlanif10] vrrp vrid 1 virtual-ip 192.168.10.1
[SW_A-Vlanif10] vrrp vrid 1 priority 120
[SW_A-Vlanif10] vrrp vrid 1 preempt-mode timer delay 10
[SW_A-Vlanif10] quit

# 2. 上行接口配置
[SW_A] interface Vlanif 100
[SW_A-Vlanif100] ip address 10.0.1.1 24
[SW_A-Vlanif100] quit

# 3. 心跳接口配置
[SW_A] interface Vlanif 200
[SW_A-Vlanif200] ip address 10.255.255.1 24
[SW_A-Vlanif200] quit

# 4. BFD 及 VRRP 联动
[SW_A] bfd
[SW_A-bfd] quit
[SW_A] interface Vlanif 200
[SW_A-Vlanif200] bfd to_sw_b bind peer-ip 10.255.255.2 interface Vlanif 200
[SW_A-bfd-session-to_sw_b] discriminator local 10
[SW_A-bfd-session-to_sw_b] discriminator remote 20
[SW_A-bfd-session-to_sw_b] commit
[SW_A-bfd-session-to_sw_b] quit
[SW_A] interface Vlanif 10
[SW_A-Vlanif10] vrrp vrid 1 track bfd-session to_sw_b
[SW_A-Vlanif10] quit

# 5. 默认路由
[SW_A] ip route-static 0.0.0.0 0.0.0.0 10.0.1.254

# 6. 物理端口绑定
[SW_A] interface GigabitEthernet 0/0/1
[SW_A-GigabitEthernet0/0/1] port link-type access
```

## 五、 分阶段测试与验证步骤

### 阶段一：底层物理与链路连通性测试
**目标**：证明跨平台桥接打通，心跳与上行互通。
1. 在 **SW_A** 上执行：`ping 10.255.255.2` （测试心跳）和 `ping 10.0.0.2`（测试到SW_B的上行）。
2. 在 **Core Router** 上执行：`ping 10.0.0.2`（测试B面上行）。
3. **失败排查**：若不通，去宿主机用 Wireshark 抓对应 VirtualBox 网卡的包，看是否有 ARP 请求，确认是否被 Windows 防火墙拦截。

### 阶段二：协议状态检查
**目标**：证明冗余协议生效。
1. 在 **SW_A** 上执行 `display vrrp`，确认状态为 `Master`。
2. 在 **SW_B** 上执行 `display vrrp`，确认状态为 `Backup`。
3. 在 **SW_A** 上执行 `display bfd session all`，确认 BFD 状态为 `Up`。

### 阶段三：路由与连通性测试
1. 在 **Core Router** 上执行 `display ip routing-table`，确认去往 `192.168.10.0/24` 的路由下一跳为 `10.0.1.1`。
2. 在 **模拟PC** 上 `ping 10.0.1.254`（Core Router），确保能通。
3. 在 **终端 PC** 上 `ping 192.168.10.1`，确保能通网关。

### 阶段四：故障转移测试（终极验证）
1. 在模拟 PC 上保持持续 Ping：`ping -t 10.0.1.254`。
2. 在 **SW_A** 上关闭上行接口：`interface Vlanif 100` -> `shutdown`。
3. **预期现象**：
   * SW_A 的 VRRP 降为 `Backup`，SW_B 升为 `Master`。
   * 模拟 PC 的静态路由切换至 `192.168.10.3`。
   * Core Router 的路由切换至 `10.0.0.2`。
   * Ping 测试短暂丢包 1-3 个后恢复连通。
