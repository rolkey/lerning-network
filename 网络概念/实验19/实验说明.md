# 实验项目

## 实验编号：test19

## 实验目的：

- 加入一个企业需要搬迁，老的企业设备都不用了。要想购买一批华为的设备。他们的需求是：有文件服务器、应用服务器（发布ERP系统的80端口）使得在家办公也可以访问、公司全体人员需要上互联网、有监控设备（有必要时，需要用电脑调取监控，不需要上互联网）、有访客（访客网段只能上互联网不能访问公司内网的资源）、有两根宽带（一根是拨号的或者DHCP的，另外一根是固定IP的）拨号的给员工访问互联网，固定公网IP地址的给服务器发布的应用去使用以及领导上网也走那一根固定公网IP的宽带。

## 基本规划：

- 设备选择

```text
出口路由/防火墙 + 核心交换 + 接入交换
出口网关	AR6100/AR6300系列 或 USG6500E系列	必须支持双WAN、策略路由（PBR）、NAT Server、ACL流策略。若预算允许，带防火墙功能的USG更佳。
核心交换机	S5731-H/S6730系列	三层交换机，支持VLANIF、ACL、DHCP。若终端数量多，建议堆叠。
接入交换机	S5735-L系列	千兆到桌面，监控区建议使用带PoE的型号（若摄像头支持PoE）。
```

- VLAN划分

```
VLAN 10（员工区）、VLAN 20（服务器区）、VLAN 30（访客区）、VLAN 40（监控区）
```
