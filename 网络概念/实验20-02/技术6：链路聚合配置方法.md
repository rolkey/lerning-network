在 FW-01（USG6000V1）与 SW-01（S5700）之间配置链路聚合，最稳妥的方案是使用**手工负载分担模式（Manual Load Balance）**。防火墙作为安全设备，其逻辑接口承载安全策略与区域划分，手工模式能避免因 LACP 协商波动导致防火墙接口状态震荡，也符合华为官方对防火墙与交换机对接的推荐配置方式。

### 🛠️ 配置步骤

#### 1. 配置 SW-01（交换机侧）
建议使用 `trunkport` 命令在 Eth-Trunk 视图下批量加入成员接口，这样操作更简便且不易出错。

```
<SW-01> system-view
[SW-01] interface eth-trunk 1
[SW-01-Eth-Trunk1] mode manual load-balance
[SW-01-Eth-Trunk1] trunkport gigabitethernet 0/0/23 to gigabitethernet 0/0/24
[SW-01-Eth-Trunk1] port link-type trunk
[SW-01-Eth-Trunk1] port trunk allow-pass vlan all
[SW-01-Eth-Trunk1] quit
```

#### 2. 配置 FW-01（防火墙侧）
防火墙侧需要将物理接口加入 Eth-Trunk，并将 Eth-Trunk 逻辑接口加入安全区域，然后配置 IP 地址。从你的拓扑图看，FW-01 与 SW-01 之间是三层连接，因此 Eth-Trunk 接口需要配置 IP 地址（例如 192.168.100.x 网段）。

```
<FW-01> system-view
[FW-01] interface eth-trunk 1
[FW-01-Eth-Trunk1] mode manual load-balance
[FW-01-Eth-Trunk1] ip address 192.168.100.1 24
[FW-01-Eth-Trunk1] quit

[FW-01] interface gigabitethernet 1/0/0
[FW-01-GigabitEthernet1/0/0] eth-trunk 1
[FW-01-GigabitEthernet1/0/0] quit

[FW-01] interface gigabitethernet 1/0/1
[FW-01-GigabitEthernet1/0/1] eth-trunk 1
[FW-01-GigabitEthernet1/0/1] quit

[FW-01] firewall zone trust
[FW-01-zone-trust] add interface eth-trunk 1
[FW-01-zone-trust] quit
```

### 🔍 验证与排错
配置完成后，可以在两端设备上分别执行 `display eth-trunk 1` 命令，确认以下信息：
*   **Working Mode** 显示为 `Normal`（手工模式）。
*   **Operating Status** 为 `UP`。
*   成员接口（GE0/0/23、GE0/0/24）状态均为 `UP`。

如果聚合口无法 UP，请检查物理接口是否已通过 `undo shutdown` 开启，且两端接口的双工模式和速率保持一致。

### 💡 关键注意事项
*   **清空物理接口配置**：在将物理接口加入 Eth-Trunk 之前，必须确保这些物理接口上**没有**任何业务配置（如 IP 地址、静态 MAC 等），否则会导致加入失败。
*   **模式必须一致**：两端的 Eth-Trunk 工作模式必须匹配。如果一侧是手工模式，另一侧也必须是手工模式，否则链路无法正常协商。
*   **安全区域与策略**：防火墙侧将 Eth-Trunk 加入安全区域后，记得放行对应的安全策略，否则 SW-01 下的流量无法通过 FW-01。
