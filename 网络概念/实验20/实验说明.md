### 综合项目一：双网物理隔离的“医院核心网络”设计（贴合张工要求）

**背景要求：**
某中型医院需要进行网络改造。要求严格按照等保要求，实现**“内外网物理隔离”**。现有的单套设备无法满足需求，需要重新规划。
*   **内网（医疗业务网）：** 包含挂号、HIS系统、医生工作站、护士站。要求极高稳定性和安全性，绝不允许直接连接互联网。
*   **外网（互联网访问网）：** 供患者、家属以及行政办公人员访问互联网。需要做严格的限速和流控。

**练习任务：**
1.  **物理隔离架构搭建：** 在模拟器中再拉出一套核心交换机和防火墙/路由器，与原有网络完全分开（不共用任何物理链路和设备）。
2.  **内网架构设计：**
    *   划分 VLAN：服务器区（VLAN 10）、医生办公区（VLAN 20）、护士站（VLAN 30）。
    *   内网不配置默认路由指向互联网，只在内网核心交换机上配置到内部服务器的路由。
    *   在防火墙上配置严格的安全策略：**只允许**医生办公区访问服务器区的特定端口（如数据库 3306 或 Web 80），**拒绝**护士站访问服务器区，**禁止**内网任何设备Ping外网。
3.  **外网架构设计：**
    *   划分 VLAN：行政办公（VLAN 40）、患者访客（VLAN 50）。
    *   外网防火墙连接运营商（用现有的 R 路由器模拟）。
    *   做 NAT 转换，但要求**患者访客 VLAN 50** 限制带宽（可以使用 QoS 或限速策略，模拟器不支持可用 ACL 限制部分 IP 上网）。
4.  **无线网络接入（拓展）：** 在外网区域接入一个模拟的 AC+AP（或胖AP），设置两个 SSID：`Hospital-Staff`（绑定 VLAN 40，需密码）和 `Hospital-Guest`（绑定 VLAN 50，免密，但访问受限）。

### 综合项目二：企业双出口链路与高可用性改造（HA）

**背景要求：**
目前的拓扑是单线连接互联网（R路由器），单防火墙。如果防火墙宕机或主线路断开，整个企业将断网。企业申请了第二条宽带线路，并要求核心设备具备冗余能力。

**练习任务：**
1.  **双防火墙 HA（主备模式）：** 增加一台防火墙，配置 **VRRP（虚拟路由冗余协议）**，或者配置防火墙的 **双机热备（Active/Standby）**。确保主防火墙 down 掉后，备防火墙能在 1-2 秒内接管网络，内网用户无感知。
2.  **双 ISP 链路负载均衡与故障切换：**
    *   增加一台出口路由器，模拟两个运营商（ISP1 和 ISP2）。
    *   在防火墙上配置**策略路由（PBR）**：让内网服务器区的流量走 ISP1，员工区（VLAN 10）的流量走 ISP2。
    *   配置 **NQA 或 BFD 联动**：当 ISP1 的线路断掉时，服务器区流量能自动切换到 ISP2 上。
3.  **NAT 地址池：** 将现有的 Easy IP (PAT) 转换方式，改为 **NAT 地址池** 方式，让不同的 VLAN 映射到不同的公网 IP 进行上网，方便在 ISP 端做溯源。

### 综合项目三：多层园区网及服务器安全发布（DMZ 区建设）

**背景要求：**
企业现在需要向外网发布一个 Web 服务器（供客户查询资料）和一个邮件服务器。现有的服务器区直接放在内网非常危险，需要划分出 **DMZ 区（隔离区）**。

**练习任务：**
1.  **拓扑改造：** 在防火墙（FW1）上增加一个物理接口，连接一台新的交换机作为 DMZ 区，将 Web 服务器挂载到该交换机下（VLAN 100）。
2.  **NAT Server 配置：** 修改原有的 `nat server` 配置，将公网 IP 的 80 端口映射到 DMZ 区的 Web 服务器，将 25 端口映射到邮件服务器。
3.  **安全策略精细化：**
    *   **外网 -> DMZ：** 允许外网用户访问 Web 服务器的 80 端口和邮件服务器的 25 端口。
    *   **DMZ -> 内网：** **严格禁止** DMZ 区的任何设备主动访问内网（防止服务器被黑后作为跳板攻击内网）。
    *   **内网 -> DMZ：** 允许内网管理员（仅限核心交换机上的某个特定 IP）通过 SSH 或 RDP 远程管理 DMZ 的服务器。
4.  **防环与路由协议（进阶）：**
    *   放弃现有的静态路由，在核心交换机（SW-LC03）和出口 R 路由器之间运行 **OSPF 协议**。
    *   要求：内网的所有网段（VLAN 10-40）都能通过 OSPF 传递给 R 路由器，实现动态路由收敛。
