## 二、本目录覆盖的交付范围

本目录只整理**通信专业**与**电力二次系统安全防护**两条线，不含一次电气、继电保护、GIS 组合电器本体等内容。

通信专业交付内容：

| 子系统 | 主要设备 |
| --- | --- |
| 光传输 | 省网 A 光传输设备、保底网光传输设备，华为 E6616（ASON） |
| 调度数据网 | 第一平面接入路由器（华为 AR6710）、第二平面接入路由器（华三 MSR3620-X1） |
| 配线 | 光纤配线柜（ODF）、综合配线柜（DDF + BDF） |
| 通信电源 | 通信高频开关电源屏、直流配电屏、阀控式密封铅酸蓄电池组 |
| 话音 | VOIP 电话、公网市话 |
| 光缆路由 | 站用变至通信电源屏的光缆引接、电缆平台与导引光缆（属一次专业图纸） |

二次安防交付内容：

| 子系统 | 主要设备 |
| --- | --- |
| 互联交换 | 控制区互联交换机、非控制区互联交换机、远动专线交换机 |
| 边界防护 | 横向互联防火墙、纵向加密认证装置 |
| 检测审计 | 态势感知、入侵检测、运维堡垒机、安全审计、主机加固、防病毒 |
| 辅助 | 杀毒/安全 U 盘、杀毒电脑、专用调试电脑、屏柜、等级保防测评服务 |
