# 通信系统总体结构

> 来源：`220kV植护元创专用变电站工程通信及二次安防设备清单.xlsx`（Sheet1、通信、二次安防）、`SG-B25041S-U0101-28 系统通信设备材料清册.xls`、`SG-B25041S-U0101-29 系统通信电缆清册.xls`、`贵港植护元创施工图-通信部分-20260423.pdf`（P3 光缆路由和通信系统组织图、P4 调度数据网拓扑图、P7 光纤通信设备连接图）

## 一、总体分层

本项目通信系统按纵向分五层，横向按平面分两套。

```text
┌──────────────────────────────────────────────────────────────┐
│ 业务层    调度自动化 / 继保信息 / 稳控 / 图像监控（不在本目录）      │
└──────────────────────────────────────────────────────────────┘
┌───────────────────────────────┬──────────────────────────────┐
│ 调度数据网 第一平面            │ 调度数据网 第二平面           │
│ 华为 AR6710（124P 机柜）       │ 华三 MSR3620-X1（125P 机柜）  │
│ 网管：华为                     │ 网管：新华三，须支持 SDN      │
├───────────────────────────────┼──────────────────────────────┤
│ 省网 A 光传输 E6616（120P）    │ 保底网光传输 E6616（121P）    │
│ ASON，STM-16，光口 2×(≥4口)    │ ASON，STM-16，光口 2×(≥1口)  │
├───────────────────────────────┴──────────────────────────────┤
│ 配线层  ODF 6×4×12芯 → DDF 2×16系统 → BDF 4×24口             │
├──────────────────────────────────────────────────────────────┤
│ 电源层  1#通信高频开关电源屏（118P）│ 2#通信高频开关电源屏（119P）│
│        48V/4×50A，双路交流 380V/63A 自动切换，1#、2# 蓄电池组  │
└──────────────────────────────────────────────────────────────┘
```

一次安防不接入调度数据网平面，而是通过二次安防专用的互联交换机与横向/纵向防护设备构成独立分区，详见 [07-二次安防系统.md](07-二次安防系统.md)。

## 二、光传输层

| 平面 | 设备 | 机柜端子 | 光接口配置 | 备注 |
| --- | --- | --- | --- | --- |
| 省网 A | 华为 E6616 | 120P | 不少于 4 端口/块，L-16.1，2 块 | 每端口 1 发 1 收 |
| 保底网 | 华为 E6616 | 121P | 不少于 1 端口/块，L-16.1，2 块 | 每端口 1 发 1 收 |

两套设备的 STM-16 基本单元要求一致：主控交叉、时钟、二次电源冗余，交叉能力 1024×1024 VC4 / 8064×8064 VC12，20 英寸挂耳安装，含公务、告警、系统辅助，具备 ASON 功能。省网 A 侧另配 2M 电接口板不少于 16 口/块（Sheet1 为 2 块，材料清册为 1 块）。

双平面的差异在于光口数量：省网 A 每个子框配满 4 个光口以满足与骨干多路由互联，保底网只要求最少 1 个光口，其余业务走电口。

## 三、调度数据网层

双平面结构与既有通用做法一致，原理参考 [../../网络概念/双平面结构/1.基础概念.md](../../网络概念/双平面结构/1.基础概念.md)。

| 项目 | 第一平面 | 第二平面 |
| --- | --- | --- |
| 型号 | 华为 AR6710 | 华三 MSR3620-X1 |
| 机柜端子 | 124P | 125P |
| 转发性能 | ≥1Mpps | ≥1Mpps |
| 机箱槽数 | ≥4 | ≥4 |
| 端口 | 2×E1 接口板 2 块；8×10/100/1000M 电口板 2 块（通信 sheet 为 1 块） | 8×10/100/1000M 电口板 2 块（通信 sheet 为 1 块） |
| 电源 | DC -48V 双路，电源板冗余 | DC -48V 双路，电源板冗余 |
| 网管 | 华为网管 | 新华三网管，明确要求支持 SDN |
| 网管许可 | 1 套 | 1 套 |

每个平面的电口板至少保留 2 个上行端口，用于接入调度主站方向。以太网业务与 E1 业务在同一台路由器上共存，是本项目调度数据网的基本形态。

## 四、配线层

| 设备 | 规格 | 内容 |
| --- | --- | --- |
| 光纤配线柜（ODF） | 6×4×12 芯，含 2 个盘纤盒 | 光缆侧与设备侧的光纤转接 |
| 综合配线柜 DDF | 2×16 系统，西门子头 | 2M 数字信号转接 |
| 综合配线柜 BDF | 4×24 口，保安型（防雷） | 音频/模拟接口转接，含防雷保护 |

两台配线柜均为 2200mm×800mm×600mm，含接地电缆，备注"胜为综合配线系统"。柜体尺寸与光传输机柜、路由器机柜一致，可同列布置。

## 五、电源层

### 供电拓扑

```text
站用变 1D1-08 ──4×35── 1QF1 ┐
站用变 2D2-08 ──4×35── 1QF2 ┤
                            ├── 1# 通信高频开关电源屏（118P）
站用变 1D1-09 ──4×35── 2QF1 ┤        │
站用变 2D2-09 ──4×35── 2QF2 ┘        ├─ 48V/4×50A 整流模块 ×4
                                    ├─ 48V/300Ah 蓄电池组（圣阳）
                                    └─ 118P 端子排引出至各设备柜
```

交流侧共 4 路引电，来自两台站用变（1D1、2D2），每台站用变分别供 1#、2# 屏各一路，构成双路交流自动切换。屏内断路器编号规律：`1QA1`/`1QA2`/`1QA4` 为整流模块输入开关，`1QF1`/`1QF2` 为交流进线，`1QF3`/`1QF4` 为屏面 48V+ 接线排引出开关，`1QF5` 为蓄电池侧开关。

### 直流输出

每面屏直流输出 25 路，每路经 `1TK` 空开引出（`1TK1`～`1TK25`）。通信设备柜的引电对应关系：

| 设备柜 | 端子号 | 输入端 | 1# 屏引出 | 2# 屏引出 |
| --- | --- | --- | --- | --- |
| 省网 A 光传输 | 120P | 1 号/2 号输入端，32A 空开 | 118P `1TK25` 63A 空开 | 119P `2TK25` 63A 空开 |
| 保底网光传输 | 121P | 1 号/2 号输入端，32A 空开 | 118P `1TK24` 63A 空开 | 119P `2TK24` 63A 空开 |
| 调度数据网一平面 | 124P | 1 号/2 号输入端，32A 空开 | 118P `1TK23` 63A 空开 | 119P `2TK23` 63A 空开 |
| 调度数据网二平面 | 125P | 1 号/2 号输入端，32A 空开 | 118P `1TK22` 63A 空开 | 119P `2TK22` 63A 空开 |

四台设备柜均采用双路 -48V 直流输入，任一屏或任一路失电都不影响设备运行。四台设备的空开编号正好连续占用 22～25 号，符合先给光传输、再给数据网的分配顺序。

### 蓄电池

| 项目 | 内容 |
| --- | --- |
| 规格 | 48V/300Ah，单体 2V/300Ah，2V/只共 24 只 |
| 数量 | 2 组 |
| 厂家组合 | 1# 圣阳，2# 理士（原理图标明），两组必须不同厂家 |
| 安装 | 独立蓄电池架，带巡检仪 1 套和集油盆 |
| 监测 | 蓄电池监测装置 PND-24Z；电池巡检模块 PND-24T |
| 连接 | NHA-VV22-1×70，每组 2 根并联、30 米/根 |

两组蓄电池厂家不同是刻意设计，用于验证供电独立性，不是配置错误。Sheet1 主表中另有 48V/500Ah、26 只的配置，属另一版本，详见 [09-文件间参数差异对照.md](09-文件间参数差异对照.md)。

### 屏面布置与防雷

屏面布置图显示每面屏配 2 只电源监控单元 `PN070G-T48`，带 RUN/ALM/RST/ENT 指示与复位、故障告警；屏内配防雷器 `HYS4-C`（GB18802.1T2，Uc:385VAC，Imax:40kA，In:20kA，Up:<1.8kV），防雷器接至 48V+ 接线排，即屏内 -48V 输出侧做二级防雷。

## 六、二次安防层

二次安防独立成网，不占用调度数据网平面资源：

| 层次 | 设备 |
| --- | --- |
| 交换层 | 控制区互联交换机、非控制区互联交换机、远动专线交换机，各 2 台 |
| 边界层 | 横向互联防火墙 2 台、纵向加密认证装置 6 台 |
| 检测层 | 态势感知装置、入侵检测装置 |
| 审计层 | 运维堡垒机、安全审计系统、主机加固、防病毒 |
| 载体 | 二次安全防护设备柜 1 套、屏柜 2 面 |

详见 [07-二次安防系统.md](07-二次安防系统.md)。

## 七、编号与标识约定

整理本项目资料时反复出现以下编号体系，后续看图、接线、录资产台账都依赖它：

| 前缀 | 含义 | 示例 |
| --- | --- | --- |
| 118P / 119P | 1# / 2# 通信电源屏端子排 | 118P `1TK25` |
| 120P | 省网 A 光传输设备柜 | 120P 1 号输入端 32A 空开 |
| 121P | 保底网光传输设备柜 | 121P 1 号输入端 32A 空开 |
| 124P | 调度数据网第一平面设备柜 | 124P 1 号输入端 32A 空开 |
| 125P | 调度数据网第二平面设备柜 | 125P 2 号输入端 32A 空开 |
| 1QAx / 2QAx | 整流模块输入开关 | 1QA1、1QA2、1QA4 |
| 1QF1、1QF2 | 交流进线开关 | 1QF1 ← 站用变 1D1-08 |
| 1QF3、1QF4 | 屏面 48V+ 接线排引出开关 | 1QF3、1QF4 |
| 1QF5 | 蓄电池侧开关 | 1QF5 |
| 1TKx / 2TKx | 直流输出回路空开，1～25 | 1TK22～1TK25 |
| 1AKx / 2AKx | 直流充馈电柜馈线回路，1～10 | 1AK1～1AK10 |
| 1LDx / 2LDx | 直流输出回路指示 | 1LD1、1LD2、1LD25 |
| 1HDx | 交流输出指示 | 1HD1、1HD6、1HD7、1HD10 |
| 1MKx | 交流输出开关 | 1MK1、1MK2、1MK4 |
| 1PV / 1PA | 电压表 / 电流表 | 1PA 0～200A，1PV 0～100V |

同柜不同设备的编号靠柜号区分：`1LD1` 与 `2LD1` 分属 1#、2# 屏，`1AK1` 与 `2AK1` 分属 1#、2# 直流充馈电柜。
