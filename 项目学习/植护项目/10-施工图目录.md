## 四、版本与日期问题

| 问题 | 说明 |
| --- | --- |
| 日期为 Excel 序列值 | 各卷册目录日期字段 46233，材料清册封面 46113，需换算：46113 = 2026-04-01，46233 = 2026-07-30 |
| 文件名日期与目录日期不一致 | `SG-B25041S-D0210`、`SG-B25041S-D0213` 目录文件名标 2026.07.15，目录内日期字段为 2026-07-30 |
| 版本标识混用 | 部分卷册目录未标版本号，无法判断是否为最新版本 |
| 图纸编号缺失 | 通信施工图第 2～28 页图号未在文字层标注 |

## 五、图纸使用注意

| 事项 | 说明 |
| --- | --- |
| 矢量图纸 | PDF 中图形为矢量对象，文字层只包含标题与标注，需打开原文件查看图形 |
| 文字层为空页 | 第 8、12、18 页无文字或仅一个字符，不代表空白图 |
| 版本核对 | 引用图纸前核对图框中的版本号与出图日期，C0/C1/C4 版本并存 |
| 图号完整性 | 通信图第 2～28 页图号缺失，现场引用建议同时写页码 |
| 图纸与清册对应 | 材料清册与电缆清册在 PDF 第 29～37 页，与 xls 可编辑版内容一致 |
