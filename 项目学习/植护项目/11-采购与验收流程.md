## 重要提示

**这份采购合同的项目名称不是本项目。** 合同第 1 条写的是"广西南宁华润怡宝分布式光伏项目采购"，而本项目是植护元创生活用纸全产业链项目（220kV植护元创专用变电站）工程。

但合同双方与本项目存在明确关联：

| 供方 | 广西联翔科技有限责任公司 | 防火墙供货商 |
| 交付联系人 | 黄涛 19977663564 | 设备签收单"发货联系人 黄涛 19977663564" |
| 标的 | 华为 USG6000E-S12-AC 防火墙 | 设备签收单序号 3，华为 USG6000E-S12-AC，2 台 |

交付联系人姓名与手机号与本项目设备签收单的发货联系人完全一致，供方又是本项目防火墙的供货方，因此这份合同极可能就是在为本项目采购防火墙，只是合同项目名称栏填了另一个项目。

两种可能：合同填写时套用了模板未改项目名称，或该合同确实用于另一个项目而巧合由同一联系人发货。核对方式：向广西比安能源科技有限公司确认合同 `GXLXXS20260630002` 的实际标的用途，并索取本项目防火墙的正式采购合同。

本目录收录这份合同，是因为它的**交付与验收条款可作为流程参考**，不代表其标的属于本项目。

## 防火墙技术规格

合同对防火墙的技术要求比本项目设备清单详细得多，可作为同类设备的技术参考。

### 硬件配置

| 项目 | 合同要求 |
| --- | --- |
| 型号 | 华为 USG6000E-S12-AC 交流主机 |
| 接口 | 2×GE RJ45 + 8×GE COMBO + 2×10GE SFP+ |
| 电源 | 1 个交流电源，后加一个电源 |
| 芯片与操作系统 | 需采用国产芯片及操作系统 |

"后加一个电源"对应双电源冗余要求，与本项目清单"含双电源"一致。

### 性能指标

| 指标 | 要求 |
| --- | --- |
| 吞吐量 | ≥2Gbps |
| 应用层吞吐量 | ≥1.6Gbps |
| 开启全功能威胁防护吞吐量 | ≥1.4Gbps |
| IPSec 吞吐量 | ≥1.5Gbps |
| 最大并发连接数 | ≥250 万 |
| 每秒新建连接数 | ≥6 万 |
| IPSec 隧道数 | ≥4000 |
| SSL VPN 最大并发用户数 | ≥800 |
| SSL VPN 授权 | 含 ≥100 用户 |
| 虚拟防火墙数 | ≥50 个 |

三个吞吐量指标的关系值得注意：硬件吞吐量 2Gbps ≥ 应用层 1.6Gbps ≥ 开启全功能威胁防护 1.4Gbps。差值就是协议封装与威胁检测的开销，通常在 15%～30% 量级。验收测试时应按"开启全功能威胁防护"这一档实测，而不是按 2Gbps 标称值判定。

IPSec 隧道数 ≥4000 与本项目纵向加密装置的通道数相关：纵向加密一般部署在 IPSec 隧道上，4000 条隧道容量对应本项目 6～7 台纵向加密装置的通道规模有余量。

"国产芯片及操作系统"与本项目设备清单"国产设备"要求一致，同时合同把国产化要求写到了芯片和操作系统层面，更严格。

## 验收流程

合同第 6 条分三款规定了验收流程，这是本篇最值得复用的部分。

| 步骤 | 内容 | 依据 |
| --- | --- | --- |
| 1. 数量与外观验收 | 设备到达交货地点后，供需双方对设备数量及外观质量进行验收 | 6.2 |
| 2. 异常处理 | 设备缺、损或与合同约定不符时，供方应在 3 日内补足或更换，由双方确认 | 6.2 |
| 3. 签署初步验收记录 | 数量及外观符合合同约定的，双方代表签署该部分设备的初步验收记录（交接单） | 6.2 |
| 4. 最终用户验收 | 供方确认已知悉需方非产品最终用户，货物质量验收以最终用户的验收为准 | 6.3 |
| 5. 签署最终验收确认单 | 验收通过后，供需双方签署 | 6.3 |
| 风险转移 | 未进行产品验收前风险责任由供方承担 | 6.1 |
| 供方义务 | 供方有义务协助需方验收 | 6.2 |

关键设计是"两段式验收"：先做数量与外观验收并签署交接单，再以最终用户验收为准签署最终验收确认单。风险在产品验收前由供方承担。

本项目设备签收单正是这种交接单的形式：单据上有"接货单位盖章或收货人签字"栏，但"收货日期"栏空白，说明初步验收记录尚未签署，最终验收更未完成。

## 付款与开票

| 项目 | 条款 | 内容 |
| --- | --- | --- |
| 付款方式 | 4（D 其他约定） | 货到 14 天内支付全额货款 |
| 开票 | 5 | 开具 13% 的合法有效且符合需方所在地税务机关要求的增值税专用发票 |

合同列出了四种付款方式备选：A 签收即开支票（全额，日期未定）、B 分期付款（比例空白）、C 收到增值税专用发票后付款、**D 货到 14 天内支付全额货款**。最终勾选 D，即无预付款、货到后 14 天付清。

需方无预付款且需在收货后付款，意味着需方承担资金占用风险；配合第 6 条"未验收前风险由供方承担"，风险分配上对需方有利。相应地，供方在第 12.3 条约定"需方未按约定时间支付货款，供方有权延迟发货，并不承担违约责任"。

## 质保与售后

| 条款 | 内容 |
| --- | --- |
| 9.1 保修期 | 原厂免费保修 1 年，自合同签订之日起计算 |
| 9.2 保修处理 | 保修期内出现质量问题，需方有权根据故障大小或损坏程度要求供方维修或更换 |
| 12.5 响应时限 | 保修期内出现问题，供方接到通知后未在 24 小时内到达现场处置，由此造成的损失供方全额赔偿 |

保修期 1 年，自 2026-06-30 起算，即到 2027-06-30。合同签订到设备实际进场之间有间隔，实际保修起算是否以进场日为准，资料未说明，需在到货后书面确认。

24 小时到场是硬性时限要求，超时需赔偿全部损失（含向第三方支付的赔偿、合理费用支出）。这条对本项目的设备跟踪有直接价值：应记录每台设备的保修起止日期与供方联系方式。

| 条款 | 内容 |
| --- | --- |
| 12.1 逾期罚则 | 逾期付款或逾期交货按逾期金额 0.1% 逐日赔偿，上限为总价款 20% |
| 12.2 无故拒收 | 需方无故拒收或无正当理由退货，支付相应部分货款的 30% 作为违约金，并赔偿供方损失；已付预付款不予退还 |

| 12.4 保管损坏 | 供方未提出明确仓储保管要求，或需方按供方要求保管期间设备损坏，供方承担补充、修理、更换的一切费用 |

0.1%/日、上限 20% 的罚则意味着罚则封顶时间约 200 天，对交付争议的约束力有限，实际维权仍依赖 12.5 的 24 小时到场条款和 6.2 的 3 日补足条款。

## 数量差异

| 项目 | 数量 |
| --- | --- |
| 本合同 | 3 台 |
| 本项目设备清单（二次安防 sheet 序号 4） | 2 台 |
| 本项目设备签收单（序号 3） | 2 台 |

合同订 3 台，本项目需求与到货均为 2 台，多订 1 台。可能是备用机，也可能是套用其他项目数量未改。结合合同项目名称本身就填错的情况，多订 1 台更可能是填写疏漏而非刻意备用。

核对方式：向供方确认第 3 台的用途与去向。
