### 2 用户帐号与口令安全

| 编号 | 作业内容 | 标准要求与加固方法 | 依据 |
| --- | --- | --- | --- |
| A2 | 操作系统的用户进行身份标识和鉴别 | 逐个尝试登录系统账号，判断是否存在空口令用户，存在则右键设置密码。路径：控制面板 → 管理工具 → 计算机管理 → 系统工具 → 本地用户和组 | 标准 5 |

| A4 | 启用账户锁定策略 | 复位账户锁定计数器 **3 分钟**；账户锁定时间 **5 分钟**；账户锁定阈值 **5 次无效登录** | 标准 1 |

| A8 | 应用软件的账户权限设置 | 禁用或删除无用、过期用户；用户设置最小化权限；密码复杂度最少 8 位，含大小写字母、数字、特殊字符中的两种；不存在空口令或弱密码 | 标准 5 |

### 4 服务优化

| 编号 | 作业内容 | 标准要求与加固方法 | 依据 |
| --- | --- | --- | --- |
| A11 | 禁用不必要服务 | 根据业务需求禁用，包括但不限于 e-mail、telnet、rlogin、ftp、NetBIOS、UPnP。`services.msc` 逐个停止并将启动类型改为"禁用"，清单见下 | 标准 1 |
| A12 | 加固 SNMP 服务、配置 SNMP TRAP | 若启用 SNMP，默认 `public` 团体名已修改并设为 8 位以上字串，**改为 `GXhmrjsw-q3`**；选择"接受来自这些主机的 SNMP 包"并设置合法主机 IP（如态势感知采集装置 IP、堡垒机 IP 等）。路径：`services.msc` → SNMP Service → 属性 → 安全选项卡 | 标准 1 |
| A13 | 文件共享 | 原则上禁止配置文件共享；必须配置共享时须设置账户与口令，只将权限授权于指定账户。`net share` 查看 | 标准 1 |
| A14 | 关闭默认共享 | 删除 IPC$、ADMIN$、C$、D$ 等：`net share ipc$ /delete` 等；注册表 `HKEY_LOCAL_MACHINE\System\CurrentControlSet\Services\LanmanServer\Parameters` 下新增/修改 REG_DWORD 类型 `AutoShareServer` = 0、`AutoShareWKS` = 0 | 标准 1 |
| A15 | 禁用匿名远程连接 | 本地策略 → 安全选项："网络访问: 可匿名访问的共享""网络访问: 可匿名访问的命名管道"值设置为空；不允许枚举 SAM 帐号和共享。设置后 `secedit /refreshpolicy machine_policy` | 标准 1 |
| A16 | 启用交互式登录 | 安全选项中启用"交互式登录: 不显示上次的用户名" | 标准 1 |
| A17 | 关闭 Windows 自动播放功能 | `gpedit.msc` → 计算机配置 → 管理模板 → Windows 组件 → 自动播放策略 → 关闭自动播放 → 启用；关闭自动播放类型选"所有驱动器" | 标准 1 |
| A18 | 控制在蓝屏后自动启动机器 | 我的电脑 → 属性 → 高级 → 启动和故障恢复 → 设置 → 取消"系统失败"下的自动重启勾选 | 标准 1 |
| A19 | 禁止用户开机自动登录 | 注册表 `HKEY_LOCAL_MACHINE\Software\Microsoft\WindowsNT\CurrentVersion\Winlogon` 新增或修改 REG_DWORD 类型 `AutoAdminLogon` = 0 | 标准 5 |
| A20 | 检测 DDOS 攻击保护设置 | 注册表 `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters` 下添加：`SynAttackProtect=2`、`TcpMaxPortsExhausted=5`、`TcpMaxHalfOpen=500`、`TcpMaxHalfOpenRetried=400`、`EnableICMPRedirect=0` | 标准 1 |
| A21 | 检测网络服务挂起时间 | 安全选项："网络服务器: 暂停会话前所需的空闲时间"设为 **5 分钟（300 秒）**。原表"完成情况"写 5 分钟、"加固方法"写 15 分钟，见文末说明 | 标准 1 |
| A22 | 配置登录终端的操作超时锁定 | 启用网络安全"超过登录时间后强制注销"；Microsoft 网络服务器"启用登录时间用完时自动注销用户"；屏幕保护程序等待时间（原表两列不一致，见文末说明），启用"在恢复时使用密码保护" | 标准 1 |
| A23 | 禁止多余 USB 接口的使用 | 除鼠标键盘等必要外设接入 USB 外，其余 USB 口用封条封死（原则上保留一个数据拷贝接口） | 标准 5 |
| A24 | 系统时间同步 | 系统时间与 NTP 服务器同步。桌面右下角时间 →"Internet 时间"→ 更改配置；或注册表 `W32TIME\TimeProviders\NTPCLIENT\SpecialPollInterval` 设为 **900（15 分钟）**，`W32TIME\Parameters\NtpServer` 键值修改为 NTP 服务器 IP | 标准 3 |
| A25 | 禁用可远程访问的注册表路径和子路径 | 本地策略 → 安全选项："网络访问: 可远程访问的注册表路径"与"可远程访问的注册表路径和子路径"均配置为空 | 标准 5 |
