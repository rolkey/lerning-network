## 四、开始之前必须知道的三件事

**1. 项目名称有四种写法。** 通信图纸写"植护元创生活用纸全产业链项目（220kV植护元创专用变电站）工程"，一次二次卷册写"植护元创生活用纸全产业链项目一期工程 / 220kV植护纸业专用变电站"，电缆清册说明又写"植护元创"，签收单写"220kv植护元创专用变电站工程通讯设备部分"。设计证书号也不一致（A245010429 与 乙252024010097）。引用资料时写图号前缀 `SG-B25041S` 加卷册号，不要只靠站名检索。

**2. 资料之间有 20 项待澄清差异。** 配线柜数量、2M 电接口板数量、通信电源架构、蓄电池规格、电缆编号重复、交换机数量等都存在互相矛盾。全部列在 [09-文件间参数差异对照.md](09-文件间参数差异对照.md)，含核对方法与澄清请求清单。多数差异中材料清册与施工图互相印证、Sheet1 与二者不一致，但倾向不等于结论，仍需设计变更单。

**3. 采购合同的项目名称不是本项目。** `比安-联翔2026.6.30_20260630104507_.pdf` 第 1 条写的是"广西南宁华润怡宝分布式光伏项目采购"。合同双方与交付联系人却与本项目防火墙供货吻合（供方广西联翔科技有限责任公司，交付联系人黄涛与设备签收单发货联系人一致），且合同订 3 台、本项目只需 2 台。使用该合同前先确认标的用途。详见 [11-采购与验收流程.md](11-采购与验收流程.md)。
