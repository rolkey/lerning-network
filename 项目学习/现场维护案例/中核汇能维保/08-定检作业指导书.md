## 三、作业层文件（5 份）

### 3.1 省传输网年度定检作业指导书（广西电网，2011-03）

**术语**：年度定检是传输网络维护的一项重要工作，通过对设备现场检查、网管设备配置、性能参数等的检查，及时发现隐患，将故障消除在萌芽阶段，防止影响业务的重大故障的发生。

**职责分工（4.1）**：

| 定检方式 | 组织方 |
| --- | --- |
| 通过传输设备网管系统检查的项目 | 传输网络网管管理单位 |
| 现场检查的项目 | 设备运行单位 |

**每年开展一次。**

**时限（4.2、4.3）**：

| 时限 | 动作 |
| --- | --- |
| 每年 5 月前 | 开展定检 |
| 每年 6 月 | 针对定检结果进行整改 |
| 每年 6 月 5 日前 | 通信网络管理单位编制年度定检报告并提交中调 |

> 该文件的"6 月 5 日前报中调"早于 2026 版业务指导书的"6 月 30 日前报中调"。以现行 2026 版为准（见 [07](./07-通信年度定检工作.md#43-逐级报送时限)）。

**定检定位（4.4）**：**以通过网管检查设备运行状况为主，以设备现场检查为辅。**

**作业安全要求（4.5、4.6）**：

- 必须编制年检方案，进行**危险点分析**，制定预防措施、应急预案，确保年检期间通信网络安全稳定运行
- 应按规定办理相关工作手续，工作期间**必须服从通信调度值班员指挥**

**缺陷处置（4.7）**：定检期间发现的网络或设备缺陷应**及时整改**；暂不能整改的应制定预防措施，确保网络正常运行。

**定检内容（5.1）**：

| 类别 | 检查项 |
| --- | --- |
| 5.1.1 网管系统本身 | 网管服务器环境检查、网管系统硬件运行状态检查、网管软件运行状态检查、数据库及备份检查 |
| 5.1.2 利用网管对传输设备 | 网络告警检查、设备配置检查（网元 IP(OSI) 号、ID 号、各板卡配置、板卡软件版本）、设备工作状态检查、设备板卡状态检查（所有板卡工作状态、板卡保护）、光接口（光卡、功放）光功率检查、同步状态检查、电路配置检查、SNCP 保护检查 |
| 5.1.3 现场侧传输设备 | 机房环境检查、电源和接地检查、机房配套设施检查、机架检查、设备面板检查、设备接口检查、光缆检查 |

**检查表六要素格式（可复用）**：每个检查项按"项目 / 目的 / 标准 / 操作 / 安全风险 / 预控措施"六栏成表。示例：

| 要素 | 内容 |
| --- | --- |
| 项目 | 网管服务器环境检查 |
| 目的 | 为网管设备提供合格外部环境，提高网管运行可靠性和稳定性，预防网管由于环境而发生当机，明确连接线和标签，便于日常维护，延长服务器使用寿命 |
| 标准 | 外部环境符合要求的规范、电源供电需配置 UPS、计算机接地良好、网线连接标签和外设连接清晰、正确 |
| 操作 | 检查网管计算机外观及卫生条件，做好防尘、防潮、防磁、散热措施；检查是否配置 UPS、机壳接地；检查标签，明确系统信息（系统名称、连接类型、IP 地址等） |
| 安全风险 | 1. 在做除尘等操作时，可能误碰电源线造成网管计算机掉电。2. 在检查标签时，用手触摸标签可能会造成接头松动、接触不良。 |
| 预控措施 | 操作前，做好数据备份。对于 UNIX 系统，操作前按正常关机步骤先关闭服务器。 |

其他检查项要点：

| 检查项 | 标准 |
| --- | --- |
| 网管系统硬件运行状态 | 服务器无硬件错误提示，终端软件运行正常 |
| 网管软件运行状态 | 系统启动正常、无错误提示；网络设置正确；图形终端运行正常 |
| 网管软件网络连接 | 一般包含两个网卡：一块绑定 TCP/IP 协议，与上层网络及远程图形终端连接；另一块与设备网管连接，其 IP 或 OSI 地址必须正确。须设定不同用户及密码 |

**第 6 章**：年度检查报告编写要求。**附录**：主干通信传输网定检记录表格。

### 3.2 主干调度数据网年度定检作业指导书（试行）（南网，2011-05）

**背景**：根据 2011 年调度工作会议、通信专业会议安排，要求 6 月 30 日前完成网、省、地三级数据网络定检工作。

**职责分工（4.1）**：

| 定检内容 | 执行方 |
| --- | --- |
| 网管系统检查 | 总调通信处 |
| 设备状态检查 | 总调通信处 |
| 机房环境检查 | 主干调度数据网各运行维护单位 |

**作业安全要求（4.2、4.3）**：

- 网管操作一般**不影响设备运行状态**；若认为需要执行改变设备运行状态的操作，应按规定办理相关工作手续，确保定检工作安全性
- 运维单位可根据实际情况完成机房环境检查；若需改变设备运行状态，应按规定办理工作手续，工作期间**必须服从通信调度员指挥**

**定检内容三部分**：

| 部分 | 内容 |
| --- | --- |
| 1 网管系统的检查 | 网管服务器的软硬件状态、网络服务器的运行环境等 |
| 2 设备状态的检查 | 设备硬件状态、软件版本、系统配置、安全配置、接口配置、路由配置与运行状态、配置合理性、链路性能 |
| 3 机房现场的检查 | 机房环境、机房配套设施、机架、设备面板、设备接口 |

**附录**：A 网管系统检查表格、B 设备状态检查表格、C 机房现场检查表格（均为规范性附录）。
