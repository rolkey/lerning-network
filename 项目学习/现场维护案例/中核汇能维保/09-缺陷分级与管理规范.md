# 09 缺陷分级与管理规范

本文依据《通信线路及设备缺陷定级标准（运行分册）（试行）》与《中国南方电网有限责任公司设备缺陷管理办法》编写。定检作业要求见 [08-定检作业指导书.md](./08-定检作业指导书.md)。

> **脱敏说明**：本文不出现联系人姓名、电话、邮箱。

## 一、两份文件的分工

| 文件 | 作用 |
| --- | --- |
| 《通信线路及设备缺陷定级标准（运行分册）（试行）》 | 给出通信专业各类缺陷部位的**表象与严重等级对照表**，即"什么现象算几级" |
| 《中国南方电网有限责任公司设备缺陷管理办法》 | 给出**管理流程、处理时限与考核指标**，即"发现后怎么办、多久消完、考核怎么算" |

两份文件的严重等级名称**不完全一致**，须注意：

| 定级标准（运行分册） | 设备缺陷管理办法 |
| --- | --- |
| 紧急 / 重大 / 一般 / **轻微** | 紧急 / 重大 / 一般 / **其他** |

定级标准多一档"轻微"，管理办法多一档"其他"。核对方法：以现场使用的定级标准为准，并在缺陷台账中固定所用标准名称。

## 二、业务影响术语（判级的基础）

定级标准的判级依据是"对业务的影响程度"，四个术语必须精确理解：

| 术语 | 定义 |
| --- | --- |
| **业务中断** | 业务的所有通信方式和通信电路中断，例如**主备用路由全部中断** |
| **业务可靠性降低** | 业务未中断，承载业务的**部分**通信方式或通信电路中断 |
| **重要信息业务** | 南方电网公司总部、分（子）公司本部、地区供电局（含超高压分局、调峰调频公司电厂）、容灾中心、区（县）供电局、网省地二级单位（分子公司及地市局除外）等**关键站点**的信息业务 |
| **一般信息业务** | 35kV 及以上变电站、电厂、各乡（镇）供电所、营业网点等站点的信息业务 |

> **本项目场站的归属**：17 个场站均为发电企业（风电场、光伏电站、储能站）。按定义，电厂属**一般信息业务**范围。但调度控制区内的通信设备同时承载生产实时控制业务，后者不属于"信息业务"，须单独判断。判级时须先确认该设备承载的是生产实时控制业务、重要信息业务，还是一般信息业务。

## 三、通信专业缺陷定级对照（运行分册）

定级标准表格统一为四列：**缺陷部位 | 缺陷类型 | 缺陷表象 | 严重等级**。

### 3.1 光纤复合架空地线光缆（OPGW）本体

| 缺陷表象 | 严重等级 |
| --- | --- |
| 断芯导致传输网络开环 | **紧急** |
| 断芯导致生产实时控制业务或重要信息业务可靠性降低，或一般信息业务中断 | **重大** |
| 纤芯故障未影响生产实时控制业务和信息业务、未造成传输网开环 | **一般** |
| 空闲纤芯衰耗异常 | **轻微** |

> OPGW 四档齐全，是判级基准表。关键分界：**是否造成传输网开环**决定紧急与重大的分界；**是否影响生产实时控制业务**决定重大与一般的分界。

### 3.6 判级速查（按表象反查等级）

| 表象关键词 | 等级 |
| --- | --- |
| 传输网络**开环**（光缆断芯、尾纤故障） | 紧急 |
| 生产实时控制业务或重要信息业务**中断** | 紧急 |
| 危及电网运行安全或人身安全 | 紧急 |
| 主备用路由全部中断（业务中断的完整形态） | 紧急 |
| 业务**可靠性降低**（部分通信方式中断） | 重大 |
| 一般信息业务**中断** | 重大 |
| 风扇**故障停运** | 重大 |
| 部件/软件**一般**异常或告警 | 一般 |
| 未造成开环、未影响业务 | 一般 |
| 空闲纤芯衰耗异常 | 轻微 |

> 三条最关键的分界线：**开环 → 紧急**；**生产实时控制业务或重要信息业务中断 → 紧急**；**一般信息业务中断 → 重大**。

## 四、缺陷处理流程

管理办法规定的处理环节为：**发现和报送 → 确认和定级 → 消缺和验收 → 反馈**。

### 4.1 处理原则

缺陷处理应做到：**及时发现、正确定级、按时消除、原因清晰、责任明确、措施到位**，坚持**闭环管控与持续改进**原则。

配套要求：设备全生命周期各阶段的缺陷信息应通过信息管理系统实现信息交互，建立详细、准确的设备缺陷信息档案；设备缺陷信息要及时更新至设备台帐。

### 4.2 发现和报送

| 要求 | 内容 |
| --- | --- |
| 记录与报送 | 发现缺陷或收到其他信息源提供的缺陷信息后，缺陷管理人员应及时记录，并将缺陷信息报送至对应的缺陷受理部门 |
| 立即消除的补登 | 巡维和检修过程发现并**在现场立即消除**的缺陷，应在 **5 个工作日内**进行补登 |
| 报调度 | 运维阶段发现的**紧急缺陷**及可能随时导致设备停运的缺陷，应及时**报调度部门** |
| 技术分析 | 发现**重大、紧急缺陷**，应立即组织技术分析，需要前往现场确认的应及时赶赴现场 |

**缺陷报送信息必含字段**：

1. 缺陷发现时间
2. 设备名称 / 资产编号 / 设计编号
3. 缺陷部件 / 部位
4. 缺陷表象
5. 缺陷类别
6. 缺陷原因
7. 严重等级
8. 缺陷发现来源

> 第 2 项的"资产编号 / 设计编号 / 设备编号对应关系"是易漏项。管理办法明确要求物资编码、设计编号与设备编号的对应关系须在投运前验收。本项目进场前应先建立三编号对照表，否则缺陷台账无法与资产系统对接。

### 4.3 确认和定级

- 每一条缺陷都需要根据公司《设备缺陷定级标准》进行**认真分析比对，正确定级**
- 设备制造运输、基建阶段缺陷的严重等级可与运行阶段有所差异，但**启动验收阶段缺陷严重等级的判定，要按照运行阶段执行**
- 出现界定不清的情况，需经有关部门或上级部门研究确定

> "界定不清需上级部门研究确定"意味着判级有争议时不能自行降级，应上报定级。

### 4.4 消缺和验收

| 要求 | 内容 |
| --- | --- |
| 质量要求 | 缺陷处理人员应严格按照缺陷处理质量要求，在规定时限内及时组织消缺，确保**"一次做对、消必消好"** |
| 验收 | 缺陷消除后，应按照设备制造运输、施工安装、运行维护等阶段相应的验收标准进行验收 |
| **降级处理** | 重大、紧急缺陷通过临时处理降低了严重程度，但**未完全消除**的，应进行降级处理；**原缺陷应视为已处理完毕**，降级后的缺陷应作为**新缺陷**进行登记 |
| 工程遗留缺陷 | 项目移交时仍未处理完毕的一般缺陷将作为**工程遗留缺陷**，由建设单位（业主项目部）跟踪处理并对相关责任单位考核处罚 |

> **降级处理规则对本项目意义重大**：紧急缺陷经临时处理后降级，原缺陷即视为处理完毕。这意味着**"降级"就是消缺完成的标志之一**，而降级后产生的新缺陷须重新登记并重新计时。若仅对原缺陷做了临时处理而未登记新缺陷，将同时构成"消缺未闭环"与"台账缺失"两项问题。

### 4.5 反馈

缺陷消除后，缺陷原因应**填报完整**，并根据缺陷原因分类，将缺陷反馈至相关责任方进行改进。

#### 通信设备重大缺陷时限：两读并存，须核对原件

本次提取时 `catdoc` 对该表"重大缺陷"行的单元格合并处理，**通信设备**列存在两种可能读法：

| 读法 | 通信设备重大缺陷时限 | 依据 |
| --- | --- | --- |
| 读法 A | **7 天** | 该列与安自设备同为"7 天"，"72 小时"归自动化设备 |
| 读法 B | **72 小时** | 该列与安自设备同为"7 天"，"72 小时"归通信设备 |

两种读法差 3 倍，直接影响缺陷考核，因此**本文不作裁决**。

已确认无歧义的两项：**通信设备紧急缺陷 24 小时**、**通信设备一般缺陷 90 天**（这两行均为四列齐整的单行记录）。

**核对方法**：打开原件 `附件1：中国南方电网有限责任公司设备缺陷管理办法.doc` 的附录 1"二次设备缺陷处理时限"表，直接读取"通信设备"列的"重大缺陷"单元格。

> 若按读法 A（7 天），则通信设备重大缺陷时限与一般设备运维阶段一致；若按读法 B（72 小时），则通信专业实行比保护、安自更严的时限。这一差异须在编制本项目缺陷考核细则前确认。

### 5.3 本项目适用的时限口径

本项目服务对象为通信设备（传输设备、光缆、调度数据网、综合数据网、电力专线等），属**二次设备中的通信设备**专业，同时须服从技术规格书与合同的管理要求：

| 约束来源 | 时限口径 |
| --- | --- |
| 南网缺陷管理办法 | 紧急 24 小时；一般 90 天；重大待核对（7 天或 72 小时） |
| 技术规格书应急服务条款 | 接到紧急通知 **30 分钟内响应**并立即提供问题应急处置方案；南宁市内 **4 小时**到现场；区内其他地方 **8 小时**到现场 |
| 合同第 17 条 | 未及时响应甲方要求，按本月合同结算价 3% 计违约金；进度延误每延期一日按合同暂定总价 3% |
| 合同第 8 章 | 服务不合格须返工至合格标准 |

> **三套时限是并行的，取最严者执行**：应急服务的 4 小时 / 8 小时到现场要求远严于缺陷处理的 24 小时时限。即通信类故障必须按应急服务条款在 4 小时内到场，而不能等 24 小时。

## 六、缺陷管理考核指标

运维阶段的消缺考核指标：

| 缺陷等级 | 消缺率 | 消缺及时率 |
| --- | --- | --- |
| 重大及以上缺陷 | 应为 **100%** | 应为 **100%** |
| 一般缺陷 | 不低于 **85%** | 不低于 **85%** |

> 重大及以上缺陷的消缺率与及时率**必须达到 100%**，无容错空间。这意味着紧急与重大缺陷不能"带到下个考核周期"。

## 七、缺陷分级定义（设备缺陷管理办法）

管理办法按**制造运输 / 施工安装 / 运行维护**三个阶段分别定义同一等级的含义。以下为运行维护阶段的定义（本项目适用）：

### 紧急缺陷（运行维护阶段）

生产设备运行维护阶段中发生的，**不满足运行维护标准，随时可能导致设备故障**，对人身安全、电网安全、设备安全、经济运行造成严重影响，**需立即处理**的设备缺陷。

### 重大缺陷（运行维护阶段）

生产设备运行维护阶段中发生的，不满足运行维护标准，对人身安全、电网安全、设备安全、经济运行造成重大影响，**设备在短时内还能坚持运行，但需尽快处理**的设备缺陷。

重大缺陷在制造运输阶段还细分为：

| 细分 | 含义 |
| --- | --- |
| **A 类** | 人身安全或会引起严重后果的项目 |
| **B 类** | 严重安全隐患或长期运行会造成严重经济损失的项目 |

### 一般缺陷（运行维护阶段）

基本不对设备使用安全、主要功能及工期造成影响，可现场处理的设备缺陷。在制造运输阶段细分为 **C 类**：符合国家设备监理（监造）和检测标准，但不符合南网招标技术规范的项目。

### 其他缺陷

管理办法列出该等级但未给出处理时限（时限表中为"—"）。

## 八、定检与维保的缺陷接口

| 环节 | 定检 | 维保 |
| --- | --- | --- |
| 发现 | 年度定检作业中检查发现 | 周期性维护与故障处理中发现 |
| 定级依据 | 《通信线路及设备缺陷定级标准（运行分册）（试行）》 | 同左；设备类另可参照设备缺陷管理办法 |
| 处理流程 | 发现和报送 → 确认和定级 → 消缺和验收 → 反馈 | 同左 |
| 时限 | 同左（通信设备口径） | 技术规格书应急服务的 4 / 8 小时到现场要求优先 |
| 记录 | 定检记录表格 + 缺陷清单（附件 3 格式） | 维保记录 + 验收单、验收报告 |
| 交付 | 年度定检报告（6-30 前逐级上报） | 半年度 / 年度维保报告（12-30 前、次年 6-31 前，待澄清） |

> 两条流程的**定级依据与管理流程相同**，差别在发现来源与响应时限。定检发现的缺陷若影响业务，同样须按应急服务条款响应，不能因"是定检发现的"而延后。

| 序号 | 事项 | 依据 | 频次 |
| --- | --- | --- | --- |

| 4 | 重大、紧急缺陷立即组织技术分析，需现场确认的及时赶赴 | 管理办法发现和报送 | 发生时 |
| 5 | 缺陷报送填全 8 项字段 | 管理办法发现和报送 | 每条缺陷 |
| 6 | 每条缺陷按定级标准比对正确定级，界定不清的上报定级 | 管理办法确认和定级 | 每条缺陷 |

| 9 | 消缺后填全缺陷原因并按原因分类反馈责任方 | 管理办法反馈 | 每条缺陷 |

| 11 | 应急类故障 30 分钟响应、南宁市内 4 小时到场、区内 8 小时到场 | 技术规格书 | 发生时 |
| 12 | 核对通信设备重大缺陷时限（7 天或 72 小时） | 管理办法附录 1 | 待确认后固化 |
