# 项目技能

电力通信与二次安防岗位的**知识点地图**。

本文不按项目罗列流水，而是回答一个问题：**哪些知识点必须放在一起理解，才能完成一项真实工作？**

单点技术都能查到文档，但现场出问题往往出在知识点之间的接缝处：光缆衰耗超标是传输层的事，可根因在金具安装；消缺率不达标是运维的事，可卡点在合同没写判定口径。所以下面每个知识域都带「关联」小节，最后用四条端到端链路把知识点串成可执行路径。

业务文档作为各知识点的出处索引列在第十二节，按知识域组织，仅作引用，不作为本文骨架。

---

## 一、知识分层总览

| 层 | 解决什么 | 核心知识点 |
| --- | --- | --- |
| **A 物理层** | 信号从哪里来 | 光缆类型、配线柜成端、通信电源、蓄电池、机房环境 |
| **B 传输层** | 信号怎么传 | SDH/ASON 传输设备、通道开通、衰耗与空余纤芯、载波高频 |
| **C 数据网层** | 多个站点怎么互联 | 双平面、VLAN、路由、LoopBack、MPLS、调度/综合数据网 |
| **D 安全层** | 怎么划边界、防外泄 | 安全分区四原则、横向防火墙、纵向加密、检测审计、主机加固 |
| **E 运维层** | 怎么按制度保持可用 | 定检计划与执行、缺陷判级、消缺时限、考核指标 |
| **F 管理层** | 怎么把项目做完 | 图纸清册、到货签收、采购响应、合同条款、版本差异 |

**层间关系**：A 是 B 的物理基础，B 是 C 的承载通道，C 是 D 的保护对象，E 是 A—D 全链路的周期性验证，F 贯穿全部并对结果负责。

**一个常见误解**：把 E（运维）和 A—D（技术）分开学。实际上定检就是 A—D 的周期性复测 —— 蓄电池核容属 A 层、衰耗测试属 B 层、路由器配置核对属 C 层、策略有效性检查属 D 层，考核指标再回压到 E 层。

## 二、A 物理层

**知识点**

- **光缆类型与适用场景**：OPGW（架空地线复合）、ADSS（自承式）、管道光缆、OPPC、地埋光缆、法兰盘。类型决定敷设方式、检修方式与故障定位手段。
- **配线柜成端**：ODF（光纤）、DDF（数字）、BDF（综合），成端、跳线、标签管理。
- **通信电源**：高频开关电源屏、直流配电屏、整流模块、监控模块、交流输入切换。
- **蓄电池**：阀控式密封铅酸蓄电池组、容量测试（放电倍率）、核容作业。
- **机房环境**：温湿度、接地。

**关联（本层最容易出事的地方）**

| 关联对 | 为什么会出事 |
| --- | --- |
| 光缆类型 × 检修方式 | OPGW 与 ADSS 的故障点分布完全不同：OPGW 断纤多在接续盒与金具，ADSS 多在弧垂段。检修方案要按类型定，不能通用 |
| 配线成端 × 衰耗指标 | 衰耗超标常源于端面污染、弯曲半径超限、跳线老化，而非光缆本体。**测试不达标时先查配线，不查光缆** |
| 蓄电池容量 × 通信负载功耗 | 容量是否够，不是看电池铭牌，而是算负载功耗 × 后备时间。核容结果要与负载计算对账，单看容量合格会漏掉负载超限 |
| 通信电源 × 蓄电池 | 电源整流模块异常会直接表现为蓄电池放电异常。两者的缺陷表常合并填报，判级时须区分根因 |

**掌握标准**：给一条衰耗超标告警，能按"先配线、后本体"的顺序列出排查点；给一组负载功耗与后备时间，能算出所需蓄电池容量，并说明为什么不看铭牌就下结论。

**文档**：光缆与金具判据见 [光缆本体判据（OPGW）](./现场维护案例/中核汇能维保/09-缺陷分级与管理规范.md) · 蓄电池核容作业见 [蓄电池远程核容作业](./现场维护案例/中核汇能维保/08-定检作业指导书.md) · 电源结构与负载见 [电源层结构与负载](./植护项目/02-通信系统总体结构\(电源层\).md)

## 三、B 传输层

**知识点**

- **SDH 光传输设备**：机架、端口、板卡；发射功率、接收灵敏度等参数核对。
- **ASON 与保护倒换**：主备通道自动切换机制，决定了故障时业务是否中断。
- **通道开通与联调**：需与调度端配合完成。
- **衰耗与空余纤芯**：单纤衰耗指标、空余纤芯资源、接续盒断点。
- **载波高频通道**：高频电缆、尾纤、结合设备、差接网络。

**关联**

| 关联对 | 为什么会出事 |
| --- | --- |
| 保护倒换 × 通道数量 | 单通道时倒换等于业务中断。倒换机制的保护价值依赖冗余通道是否存在，需与数据网层的双平面一起核对 |
| 衰耗测试 × 光纤本底 | 单点衰耗高与全程衰减率高的含义不同：前者多为局部事件（接续盒），后者多为老化或接头累积。判级口径须区分 |
| 空余纤芯 × 光缆段 | 空余纤芯必须按光缆段而非按纤芯统计。跨段纤芯的纤芯编号在不同段可能重复，统计时须按段核对 |
| 载波高频 × 结合设备 | 高频通道故障常出在结合设备与差接网络，而非载波机本身。这部分属于结合类设备，判级走另一套规则 |

**掌握标准**：拿到一块到货板卡，能说出它在设备中的定位、与其他板卡的硬差异、以及到货该核对什么；给一段高频通道异常，能判断该查载波机还是结合设备。

**文档**：传输设备板卡与参数见 [光传输设备板卡配置与到货核对](./植护项目/03-光传输设备.md) · 衰耗与空余纤芯判据见 [光纤复合架空地线光缆判据](./现场维护案例/中核汇能维保/09-缺陷分级与管理规范.md) · 高频电缆与结合设备判据见 [高频电缆与尾纤判据](./现场维护案例/中核汇能维保/09-缺陷分级与管理规范.md) · 传输设备判级见 [传输设备按制式判据](./现场维护案例/中核汇能维保/09-缺陷分级与管理规范.md)

## 四、C 数据网层

**知识点**

- **双平面**：第一平面、第二平面接入路由器，为调度数据网提供冗余。三篇配套文档（基础概念 / 处理流程 / 接线方案）。
- **VLAN**：端口划分、Access/Trunk/Hybrid 的选择、VLAN 间路由（Vlanif）。
- **基础协议**：ARP 表、ICMP、LoopBack 口、字节计算与带宽换算。
- **MPLS**：标签交换与隧道。
- **网络业务划分**：调度数据网（连接调度主站与厂站）、综合数据网（厂站内部信息）。

**关联**

| 关联对 | 为什么会出事 |
| --- | --- |
| 双平面 × VLAN 划分 | 双平面是**冗余**概念，不是**隔离**概念。两个平面的 VLAN 划分若不一致，冗余在故障切换时会变成业务不通。核对时须逐平面比对 |
| Access/Trunk/Hybrid × 设备管理 | 端口类型配错的表现是"能通但不通"或"通但带错 VLAN"。三者选择取决于对端设备类型，不能凭习惯 |
| LoopBack × 路由协议 | LoopBack 口是路由 ID 与管理地址的来源，不配则协议不建邻。排查"路由不通"应先确认 LoopBack 而非物理口 |
| 调度数据网 × 纵向加密 | 调度数据网的跨区访问必须经加密认证装置，**直连即违规**。这是 C 层与 D 层的硬耦合点 |
| VLAN 间安全策略 × 防火墙 | 策略要按最小必要开放，过宽则失去分区意义；过窄则业务不通。这一对需同时设计 |

**掌握标准**：给两个平面的配置清单，能找出不一致处并说明不一致在切换时如何变成业务不通；给一条"路由不通"告警，能按 LoopBack → 物理口 → VLAN → 策略的顺序定位，而不是盲改配置。

**文档**：[双平面结构 · 基础概念](../网络概念/双平面结构/1.基础概念.md) · [处理流程](../网络概念/双平面结构/2.处理流程.md) · [接线方案](../网络概念/双平面结构/3.接线方案.md) · [VLAN间安全策略](../网络概念/vlan间安全策略.md) · [Vlanif 10 说明](../网络概念/nterface%20Vlanif%2010说明.md) · [MPLS](../网络概念/MPLS.md) · [LoopBack口](../网络概念/LoopBack口.md) · [ARP表](../网络概念/ARP表.md) · [ICMP说明](../网络概念/ICMP说明.md) · [字节计算](../网络概念/字节计算.md)

## 五、D 安全层

**知识点**

- **总体原则（四条）**：安全分区、网络专用、横向隔离、纵向认证。
- **横向隔离**：横向互联防火墙、互联交换机（控制区 / 非控制区 / 远动专线）。
- **纵向认证**：纵向加密认证装置，按平面与安全区配置（如 A/B 平面安全 I 区、II 区、中调专线、地调专线）。
- **检测审计**：态势感知、入侵检测、运维堡垒机、安全审计。
- **主机侧**：主机加固、防病毒（新增服务项常见于年度维保）。
- **设备差异**：国产防火墙与主流厂商的命令、插槽、特性差异。

**关联**

| 关联对 | 为什么会出事 |
| --- | --- |
| 四原则 × 实际拓扑 | 四条原则是**设计约束**，不是设备清单。现场常见问题是设备齐全但分区不完整 —— 少一条纵向加密链路即形成缺口 |
| 横向防火墙 × 互联交换机 | 二者是同一隔离点的不同实现：防火墙做访问控制，交换机做二层隔离。只配其一不构成完整隔离 |
| 纵向认证 × 双平面 | 加密装置要**逐平面逐安全区**部署。漏配一个平面的结果是：切换后加密失效，业务明文通过 |
| 检测审计 × 合规取证 | 审计日志是等保测评的直接证据。设备开通了但日志没留存或留存不足，测评仍判不合规 |
| 主机加固 × 防病毒 | 两者都属主机侧，纳入同一服务项时常被合并执行，但技术手段不同。防病毒是软件安装与更新，加固是基线配置 |
| 设备品牌差异 × 运维手册 | 国产设备与主流厂商命令不兼容，等保加固与策略下发须按**实际品牌**查手册，不能套用默认命令 |

**掌握标准**：给一份设备清单，能判断分区是否**完整**（而非仅数设备数量），并指出缺哪条纵向链路；给一个业务访问需求，能得出最小必要策略，并说明加密装置须覆盖哪些平面与安全区。

**文档**：[加固实测要点汇总](../系统加固/加固信息索引.md) · [服务器系统加固实施](../系统加固/服务器加固.md) · [FW1000特性](../系统加固/FW1000特性.md) · [FW1000与华为命令的差异](../系统加固/FW1000与华为命令的差异.md) · [FW1000对比华为插槽](../系统加固/FW1000对比华为插槽.md) · [vlan间安全策略](../网络概念/vlan间安全策略.md) · [防火墙 port-type 配置](../网络概念/实验03/概念/防火墙配置port-type.md) · [局域网 https 安装](../网络安全/局域网https/安装.md)

## 六、E 运维层

**知识点**

- **定检周期**：年度定检每年 6 月 30 日前完成；月度定检每月 28 日前完成。
- **定检计划**：次年计划每年 12 月底前制订完成，报年度检修计划发布后 5 个工作日内上报，需调管单位批准。**计划编制比执行早半年**。
- **逐级报送**：定检报告逐级上报，各层有独立时限。
- **缺陷判级**：紧急 / 重大 / 一般 / 其他；分专业判据（光纤光缆、金具、高频电缆与尾纤、传输设备、结合设备与差接网络）。
- **处理时限**：分阶段（设备、物资、施工、安装、运维），二次设备按专业区分。
- **处理流程**：处理原则 → 发现报送 → 确认定级 → 消缺验收 → 反馈。
- **考核指标**：重大及以上缺陷消缺率与及时率须达 100%，一般不低于 85%。

**关联**

| 关联对 | 为什么会出事 |
| --- | --- |
| 定检 × 缺陷判级 | 定检产出缺陷，判级决定时限。**判级口径不统一是最大的内控风险** —— 不同文件对等级名称、档数、时限可能给出不同取值，须先确认按哪份文件 |
| 判级 × 时限 × 考核 | 三者闭环：判级 → 时内消缺 → 考核校验。重大及以上要求 100%，意味着不能"带到下个周期"，没有容错空间 |
| 计划编制 × 检修窗口 | 定检计划须与年度检修计划协同，且跨地区协调的通道定检计划要**互相通报**后统一排布，不能各自申报 |
| 时限 × 合同条款 | 合同里的消缺率、响应时限、违约金比例若与技术规范的判级口径不一致，执行时会出现"技术已消缺但考核不认"或反之。**签约前须对齐判级口径** |
| 报送时限 × 层级分工 | 源文件常由下级代为上传总调系统，不是逐级直传。误按"自行上传"操作会走错流程 |

**掌握标准**：给一条缺陷，能说明判级依据、适用时限、以及超时对考核指标的影响；给一份填报模板，能指出模板自身与标准不一致之处（如定级档数、字段错写、示例年份过期）。

**文档**：定检周期、计划与报送见 [定检周期与计划管理](./现场维护案例/中核汇能维保/07-通信年度定检工作.md) · 分专业判据见 [通信专业缺陷定级对照](./现场维护案例/中核汇能维保/09-缺陷分级与管理规范.md) · 考核指标挂钩见 [缺陷管理考核指标](./现场维护案例/中核汇能维保/09-缺陷分级与管理规范.md#六缺陷管理考核指标) · 合同条款见 [违约与考核条款](./现场维护案例/中核汇能维保/05-合同模板与关键条款.md)

## 七、F 管理层

**知识点**

- **图纸与卷册**：施工图目录、一次二次施工图卷册、图号前缀。
- **清册与签收**：电缆清册、材料清册、到货签收（核对型号、数量、厂商、合同标的归属）。
- **采购响应**：资格条款、评分算法、价格基准价与修正规则、报价模板结构、平台流程与时限。
- **合同条款**：服务范围、考核指标、违约责任、终止条件、附件构成、生效条件。
- **版本差异管理**：跨年度规格书逐条比对、报价文件是否按旧版编制、场站清单增减。

**关联**

| 关联对 | 为什么会出事 |
| --- | --- |
| 图纸 × 清册 × 现场 | 三者任一不一致都会导致缺料错料。清册对不上图纸是设计问题，清册对不上现场是变更未同步 |
| 签收 × 合同标的归属 | 同型号设备可能分属不同项目。签收单不区分标的归属，会出现数量对账无解 |
| 资格条款 × 技术规格内嵌 | 询比文件常内嵌技术规格书，导致同一要求在两处出现且**取值可能不一致**。须逐条比对，而非只读一处 |
| 评分算法 × 报价策略 | 基准价修正规则（去掉高价、去掉最低价、仅修正一次）决定报价策略。规则本身可能明显偏向某一方向，须读懂再定价 |
| 版本差异 × 响应有效性 | **服务项总数可能巧合不变而构成已变**（新增一项、取消一项，总数不变）。只核对总数看不出变化，须逐条比对 |
| 合同判级口径 × 技术判级 | 见 E 层关联。两套口径不一致时以合同为准执行，但须在签约前消解 |
| 源文件缺陷 × 台账 | 原始文件中的无效日期、空白条款、附件名称不一致、字段复制粘贴错误，须原样记录并标注待澄清，**不擅自"修正"成看似合理的值** |

**掌握标准**：给两版规格书，能逐条列出差异而不是只对总数；给一份合同，能找出与技术规范判级口径不一致的条款并提出澄清要求，而不是自行选定一种解释。

## 八、四条端到端能力链路

上面是分层，下面把跨层知识点串成**可执行路径**。这四条是岗位能力的实际考核单位 —— 单层都会但串不起来，仍然交付不了。

### 链路 1：通道开通（新建交付主线）

```
光缆类型与敷设(A)
  → 配线柜成端与标签(A)
  → 传输设备安装与参数核对(B)
  → 保护倒换与通道联调(B)
  → 双平面接入与 VLAN 划分(C)
  → 纵向加密认证部署(D)
  → 调度端联调(F)
```

**最易断点**：C→D（双平面与加密装置的平面配置不一致）、B→C（VLAN 划分与传输通道不匹配）。
**贯通要求**：能同时看图纸（A/F）、设备配置（B/C）与加密装置（D），定位是"链路不通"还是"策略不通"。

### 链路 2：安全分区落地

```
安全分区四原则(D)
  → VLAN 与端口类型划分(C)
  → 互联交换机隔离(D)
  → 横向防火墙访问控制(D)
  → 检测审计部署(D)
  → 主机加固与防病毒(D)
  → 等保测评取证(F)
```

**最易断点**：设备到位但分区不完整（缺纵向链路）、审计日志未留存。
**贯通要求**：从"设备清单"视角切换到"分区完整性"视角 —— 清单齐全不等于合规。

### 链路 3：定检与缺陷闭环（存量维保主线）

```
定检计划编制与批准(E)
  → 现场定检作业(A/B/C 分域复测)
  → 缺陷判级(E)
  → 处理时限(E)
  → 消缺与验收(E)
  → 考核指标校验(E)
  → 合同条款兑现(F)
```

**最易断点**：判级口径不统一、合同与技术判级不一致。
**贯通要求**：判级与合同条款要一起读；单项合格不等于闭环，考核看的是**及时率**。

### 链路 4：版本差异识别（存量维保高频）

```
两版规格书逐条比对(F)
  → 服务项构成变化识别(F)
  → 场站清单增减与命名追溯(F)
  → 报价文件版本核验(F)
  → 冲突项并列记录，不裁决(F)
```

**最易断点**：只对总数（总数不变即认为无变化）、只看封面日期（可能整份文件沿用旧版）。
**贯通要求**：核对要落在**字段级** —— 服务项名称、频次、场站数、内部引用文号。

## 九、优先级（按链路而非项目）

| 优先级 | 链路 / 知识域 | 理由 |
| --- | --- | --- |
| 高 | 链路 3 定检与缺陷闭环 | 直接挂钩考核，重大及以上要求 100%，无容错 |
| 高 | 链路 1 通道开通 | 通信专业核心，决定业务是否可用 |
| 高 | D 安全分区完整性 | 四原则是硬性合规要求，缺一项即违规 |
| 高 | 链路 2 安全分区落地 | 同上，且等保测评直接取证 |
| 高 | 链路 4 版本差异识别 | 错版响应与合同风险最高，且最易被漏 |
| 中 | A 物理层与配线 | 基础支撑，故障影响面大但排查路径清晰 |
| 中 | F 管理层 | 图纸清册与合同条款决定项目能否收口 |
| 中 | C 数据网层细节 | VLAN 与双平面概念不难，但配置组合易错 |
